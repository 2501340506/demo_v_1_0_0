# M6 整机验收实施计划（2026-10-16）

开发基线 v0.17.0-m5-local.1（34d7a82），原目录 feature/mountain-escape-classroom；正式回退 v0.16.0。个人问题记录保留原样。

## 本次范围

1. 落实 M5 反馈：普通场景标题/村名/字幕黑色 32px；预警语“立即撤往高地!”居中红色，32/64px 周期缩放，红框保留；卡上 SND4 使用循环警报音。旧 UART 字库颜色和缺资源回退保留。
2. KEY4 短按恢复 AUTO；长按一秒进入/退出场景。场景 KEY1 短按预警切换、长按一秒切换 1/2/4 倍速，长短互斥。KEY2 下一阶段/长按两秒重扫不变。进入场景继承原 AUTO 开关，场景内可切换；预警不自动退出。自动推进必须等 t=239 的完整终态帧显示后再切换，不能由原三秒定时器抢占。
3. 制作示意村 M6 卡和地形、路线、避险点、文字不同的“山洪村”卡，两卡共用同一 bit；换卡后复位。
4. 专项仿真覆盖文字颜色/大小/居中/流水、两卡真实 BRAM、按键长短互斥、自动推进和故障握手；执行相关及整机回归、完整 TD，固定源码、bit、双卡和验证证据。

## 交付及验收门槛

本地合格候选标签 v0.17.0-m6-local.1；失败保留诊断记录，源码或 bit 修订递增候选。要求完整 bitgen、无 ERROR、Setup/Hold 正裕量，资源与审计如实记录。

板测至少连续 40 分钟；测量 Flash 完全断电到首个完整画面、换卡复位到新村首帧，逐项回归原有功能，并检查两卡、放大黑字、缩放红字警报、速度及 AUTO。未实测的秒数、次数、结果均留待测。

用户确认具体候选及实测结果后，记录 board 标签并推送相关分支/标签；复用验收 bit 发布 v0.17.0，归档 docs/history/<完成日期>/mountain-escape-classroom，再合并 main 并核对远程。方案书只回填真实构建/板测数据。本地完成不等于正式发布或板测通过。
