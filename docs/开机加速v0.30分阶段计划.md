# 开机加速（v0.30.0）分阶段计划

基线：v0.29.0（main `ffd8e69`，板测通过，Seed 5，677348 字节）。功能分支 `feature/fast-boot`。回退：烧回 `releases/v0.29.0/demo.bit`。

目标：缩短从上电到屏幕出现第一张图的时间。v0.25 板测记录冷启动出图约 5 s，没有分段实测。

## 现状分析（2026-10-24）

| 阶段 | 估计 | 依据 |
|---|---|---|
| FPGA 从 Flash 加载 | **约 2.2 s** | 位流 677348 B ≈ 5.42 Mbit，x1，TD 默认 `mclk_freq_div` = 2.5 MHz（见下） |
| PLL/复位/SDRAM 初始化 | < 1 ms | |
| SD 卡初始化 | 6 ms（v0.5.4 UART 实测，卡相关） | |
| FAT32 挂载、目录、表头 | 约 10–50 ms | 约 0.39 ms/扇区 |
| 第一张 640×480 BMP | 约 0.7 s | 1801 次单块 CMD17，SPI 16.67 MHz；v0.5.4 实测 701 ms |
| 帧边界提交 | 约 15 ms | |
| 显示器识别 HDMI | 未测，和上面并行 | 取决于显示器 |

TD 配置时钟核实（`diagnostics/output/fb30_cfg_probe`，Seed 7 布线库试生成）：

- EG4 的参数名是 `mclk_freq_div`（PH1/PH2 的 `mclk_freq`、`boot_mode` 在 EG4 上报 BIT-8431 无效）。
- 可选值：2.5、5、7.5、10、12、14.5、16、29、36 MHz；其他值报 BIT-8432。
- 不带参数生成的 bit 与 `mclk_freq_div:2.5MHz` 除 Date 行外逐字节一致，即默认就是 2.5 MHz。
- `set_param bitgen mclk_freq_div` 不生效（生成的 bit 与默认一致），只能用 `bitgen -g {mclk_freq_div:...}`。
- `-compress` 在 EG4 上没有生成压缩文件；x4 模式没有可用参数。
- Seed 5 布线库重新 bitgen（默认参数）与 `releases/v0.29.0/demo.bit` 除 Date 行外逐字节一致（`diagnostics/output/fb30_s5_bitgen`）。

## 实测

板上实测（2026-10-24，诊断 bit `boot_timer_diag_s11`，烧 Flash，1 次读数）：A = 12 ms（复位释放 → 开始读图，含 SD 初始化、FAT32 挂载和表头），b = 941 ms（复位释放 → 首帧 display_valid）。即读第一张图约 929 ms，固件段合计不到 1 s。FPGA 加载和显示器识别 HDMI 没有计时。

用户确认（2026-10-24）：启动慢主要是显示器识别 HDMI 信号的时间；换一台质量更好、尺寸更大的显示器，时间反而更长。FPGA 从 PLL 锁定起就持续输出 TMDS，显示器的识别与固件读图并行，固件侧再提速看不出来。S2（最多省约 0.25 s）、S3 暂不做，等用户决定。

## 阶段与标签

标签：`v0.30.0-plan.1`、`v0.30.0-sN-local.N`、`v0.30.0-sN-board.N`、正式版 `v0.30.0`。

### S1 Flash 加载时钟 2.5 → 16 MHz（RTL 和布局布线不变）

- 用 v0.29.0 Seed 5 的布线库只重新 bitgen，`-g {mclk_freq_div:16MHz}`。预计加载约 2.2 s → 约 0.34 s。
- 选 16 MHz 而不是 29/36 MHz：再提高只能再省约 0.15 s，板上 Flash 走线余量更小。W25Q64 普通读（03h）支持远高于 16 MHz。
- `diagnostics/run_td_build.ps1` 加 `-MclkFreq`，以后的完整构建同样生效；公共的 bitgen 步骤放在 `diagnostics/fast_boot/run_bitgen.ps1`。
- 验证：bit 与 v0.29.0 只差配置寄存器和 CRC（RTL 回归不需要重跑）。上板必须**烧 Flash**（JTAG 下载 SRAM 不经过 MSPI，测不出差别），冷启动 10 次正常；有条件的话用手机录像对比 v0.29.0 和 s1 上电到出图的时间。
- 失败（偶发不启动、花屏）时降到 10 MHz 出 s1-local.2。

### S2 SD 读取加速（RTL，`user_source/hdl_source/SD/`，S1 板测后再做）

- `sd_card_sec_read_write.v` 增加 CMD18 多块连续读 + CMD12，`fat32_file_streamer.v` 在簇内连续扇区使用；缓存当前 FAT 扇区。预计首图 0.7 s → 约 0.45–0.5 s。
- 专项测试（多块读、CMD12、跨簇、文件尾）+ 规定回归（`adjust_panel/run_unit.ps1`、`run_scene_gates.ps1`、`narration_subtitles/run_unit.ps1`、`lut24/run_sd_pin_boot.ps1`、复位审计）+ 7 个种子。LUT 已 89.9%，增量要先评估。
- SD 时钟提到 25 MHz 不做（SD 域时序余量已经很小）。

### S3 首图逐行显示（可选，需用户确认观感）

- 只对开机第一张：写入 SDRAM 的同时就显示，不等整帧。BMP 自下而上存储，观感是从下往上刷出。用户不接受就不做。

## 验收

- 每阶段：本地验证 → 固定到 `releases/v0.30.0/sN-local.N/` → 用户烧 Flash 上板 → board 标签并推送。
- 用户没有给出计时数据时只记录实际反馈，不补造数字。
