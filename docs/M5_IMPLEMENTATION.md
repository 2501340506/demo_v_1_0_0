# M5 实施约定

开发输入：v0.17.0-m4-local.1；用户总体反馈“M4暂无大问题”，记录 m4-board.1。原目录 feature/mountain-escape-classroom 开发，正式版回退 v0.16.0。目标 v0.17.0-m5-local.1。保留现有 TD 工程及个人记录；起始工程备份 diagnostics/output/m5_initial_project.al。

## 文件与显示约定

FONT.BIN 最多 4096 字节，16×16/MSB 左，每字 32 字节，前 13 字逐位保留现有 case 字库。两块 4096×8 双时钟 RAM 分别保存 FONT/TEXT；只在扫描结束后加载，成功后发布有效标志，渲染禁用期间才重写。没有或损坏的 FONT/TEXT 使用既有 OSD，保留 case 字库。

TEXT.BIN v1：TX、版本 1、段数 10；小端 16 位绝对文件偏移、8 位字符数、8 位类型。段 0..7 为四阶段的标题/字幕（类型 0/1），段 8 为预警语（类型 2，预警时替换字幕），段 9 为村名（类型 3）。每段最多 31 字；0..127 为字库槽，F0..F9 为数字 0..9，FA..FF 分别为“空格 : . - / !”，80..EF 非法。字体/文本都成功且校验通过才显示场景文案；普通模式和 UART 字幕兼容。

同步 BRAM 读口使用独立场景 OSD 流水，视频及全部叠加有效信号共同延迟；状态在首有效像素锁存，整帧保持。标题与字幕分行查询同一个 TEXT RAM，中文查询同一个 FONT RAM，不增加复制 RAM。预警 8px 红色闪烁边框，数码管显示阶段 1..4 或 A；场景模式参数条显示速度 1X/2X/4X，仍由 KEY4 短按改变。

标题从 (8,64)、村名从 (8,88) 显示，字幕位于 y=444..459；科普字幕从右侧滚入，预警语在 x=8 固定显示。解析器校验全部描述符及文件字符，仅缓存当前标题、字幕/预警、村名三组描述符；阶段/预警变化时重解析，在标题扫描前完成。TEXT → FONT → RGB 三拍流水同时延迟 hs/vs/de/x/rgb。独立模块置于既有 OSD 链尾，原 status OSD 保留状态与错误信息；有有效场景文本时关闭原滚动字幕，避免重叠。

两块 RAM 显式使用 EG_PHY_BRAM32K 的 DP16K、16 位无输出寄存器配置，分别以 byte lane 写入 4096 字节、以 2048×16 同步读出。FONT 单独有效时也替代 UART 中文字形；TEXT 缺失或无效不影响 FONT 的旧中文路径。case 字库保留作缺文件回退。

资源加载复用音频扇区服务，在 scan_done 后、scan_result 发布前顺序完成 FONT/TEXT，随后释放服务给音频。加载器的 streamer 实例将文件计数收窄至 13 位（已限制 ≤4096）；其他图片/音频实例保持默认 32 位。扫描器将 byte31 的目的写使能和大小最高字节共同寄存一拍，目录数据在下一项 byte20 前稳定；reader 先寄存选中表项再做范围检查，减小索引到大扇出寄存器的时序路径。文件大小小于 54 的比较等价拆成高位为零及低六位比较，避免 32 位常数比较进位链，不改变判断周期。数码管沿用同 PLL 相关时钟的半周期采样方式，未增加时序例外。

## 验证范围

TD 多次构建均在旧 SD 命令 wait_count→片选路径差 7ps。对 sd_card_cmd 的两个超时判断提前一拍预测下一计数的比较值，原状态机在同一拍使用预测结果；1 周期阈值保留直接触发。未改时钟、约束或超时参数。与 M4 原模块逐拍比较全部公开输出，覆盖 1/2 周期边界、不同响应/令牌阈值、复位、命令/数据/读写及超时；物理 SPI 引脚回归另验证初始化和 CRC。

PC 检查格式、字体前 13 字、字符编码、超限拒绝与新目录复现；RTL 验证扫描器、加载/错误回退、TEXT 解析、同步字库像素及流水、阶段/预警/速度和旧卡回归。随后完整 TD，检查实际 BRAM32k 数量、LUT、正 Setup/Hold 与输入字节一致，再固定候选。失败输出保留；不把本地结果写成板测。
