# S2 KEY1 字幕与音频补全（2026-10-18）

## 范围与基线

基线为 `v0.19.0-s2-local.1` / `62c01ba`，分支 `feature/restore-scene-evacuation`。用户反馈 KEY1“立即撤离”文字或闪框异常，随后明确要求直接向 `G:\情景模式` 补字幕和音频。实查四目录各仅含 PIC1–4，无 FONT/TEXT/SND；原 overlay、KEY1 和 FSM 的预警逻辑仍在，缺字库/文本可复现预警无字。

本轮先按用户最新指令补卡：四目录各新增 FONT.BIN、TEXT.BIN、SND1–4.PCM。标题/字幕按灾害类型配套，warning 固定“立即撤离”；音频复用原 v0.18 M6 场景提示音和第4阶段警报，48kHz/单声道/有符号16位小端裸 PCM。KEY1 进入第四阶段预警时选择 SND4。

## 阶段与验收

1. 本地生成四套合法 FONT/TEXT，反解十段文本、校验字库、BMP 类型及四阶段对应关系；PCM 与原固定输入逐字节核对。
2. 使用生产 overlay 和真实 EG4 BRAM 模型对四套新文字执行逐像素回归，包含四阶段、滚动、预警2×/4×红字及闪框、旧字模和非法文件检查。
3. 全部通过再直接新增到卡上，每目录六文件，共24个；已有目标文件时拒绝覆盖。写入后逐字节读回，并比较写入前所有用户媒体文件，确保图片和宣传资源不变。
4. 保留本地资源包、脚本、验证记录及撤回清单。更新交接和修复结论；提交/推送仅限本轮文件。

## 回退与限制

原16张情景图及宣传资源不改写；本轮只加文件，撤回名单为四目录中各六个新增资源。保留用户个人记录、TD GUI 状态及日志。无 RTL/工程/bit 改动，沿用 S2 local.1，不重新 TD、不新增 local/board 标签；资源恢复不等于已完成实板显示/听审。卡补完重新插入并复位，测试四类场景 KEY1 进入/退出预警。若红框仍异常，再继续定位显示时序，不将缺资源当作所有症状的板级定论。

## 实际结果

完成四组字幕/字库和16份原版阶段音频生成；4份真实 EG4 BRAM 文字仿真全部通过，共19116433次像素/视频束比较，包含预警红字和闪框。24文件已新增至 G:\情景模式，逐字节读回一致；原26个媒体文件（40110268字节）逐字节未变。RTL/bit未改，无新TD或local/board标签。

固定资源、实际日志、写入清单和修改工具在 [s2-card.1](../releases/v0.19.0/s2-card.1/README.md)。KEY1 实板显示/警报听审待用户反馈；若补卡后仍有异常，再继续时序定位。
