# v0.5.1 S4 约束审查

状态：审查完成，暂不修改 `timing.sdc`。

## 结论

S3 后剩余 64 个负端点均落在 `U3/sdram_*` 硬核边界路径，fabric 内部 3 个负端点已消除。当前报告不能证明这些路径可以用 `false_path`、`set_max_delay` 或降低不确定性安全处理。

已确认的时钟关系：

- `clk` 为 50 MHz 输入时钟。
- `sys_pll_m0` 输出 `sd_card_clk`、`ext_mem_clk`、`ext_mem_clk_sft`。
- `video_pll_m0` 输出 `video_clk`、`hdmi_5x_clk`。
- SDRAM 硬核使用 `U3/u2_ram/SDRAM_CLK` 与 `U3/u2_ram/u1_init_ref/Sdr_clk`，由 TD 识别为时钟网。
- 当前像素/串行时钟保持并行分析，不恢复课程示例的 exclusive 组。

## 缺失信息

板卡没有提供 SDRAM 芯片 datasheet 时序、FPGA 管脚到存储器的走线延迟、HDMI/SD 外部接口输入输出延迟，因此不能凭课程参数填写 `set_input_delay` 或 `set_output_delay`。厂商硬核是否已携带完整 I/O window 也需要 TD/IP 文档确认。

## 门禁

S4 不新增时序例外，不改变时钟不确定性，不生成新的 Flash bit。只有获得真实板级接口参数或厂商硬核约束说明后，才可形成可审查的约束修改；否则保留 64 个硬核边界负端点并进入板级验证准备。
