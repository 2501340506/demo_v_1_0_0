# v0.5.1 时序收敛与 Flash 启动回归分阶段计划

基线为已验收的 v0.5.0。本版本只改善时序可见性和已定位的内部路径，保持双 PLL、125 MHz 内存、五域三拍高有效复位、SDRAM 就绪门控及 Flash 启动行为不变。

## 阶段门禁

| 阶段 | 内容 | 最小验证 | 状态 |
|---|---|---|---|
| S0 | 冻结 v0.5.0 RTL、TD 工程、约束和报告基线 | ModelSim 现有回归、TD 基线记录 | 基线完成；回归有既有阻塞 |
| S1 | 固定 TD 构建和报告提取参数 | 可重复构建，统计可比较 | 参数已固定；待回归阻塞处理 |
| S2 | 区分 SDRAM 硬核接口与 fabric 内部路径 | 约束审计、全回归 | 审计文档已建立，基线回归阻塞 |
| S3 | 每次处理一个内存内部负路径组 | 专项仿真、异步缓冲回归、TD 构建 | 待实施 |
| S4 | 补充经确认的 generated clock、I/O delay 和有限 CDC 例外 | 约束差异审查、TD 报告 | 待实施 |
| S5 | 最终候选 Flash 固化和独立冷启动 | 用户上板确认首图、编号、音频、MAN/AUTO、复位 | 待实施 |
| S6 | 长稳和反复断电/复位验收 | 用户确认后建立正式 v0.5.1 | 待实施 |
| S7 | 历史归档 | 计划、验收、HANDOFF、证据可追溯 | 待实施 |

每个 RTL 或约束阶段遵循“单项修改→ModelSim 专项→相关回归→TD 完整构建→固定候选→用户上板”。用户确认前不上传 GitHub、不移动正式标签。

## 版本和边界

- 标签：`v0.5.1-plan.1`、`v0.5.1-sN-local.1`、`v0.5.1-sN-board.1`，正式版本为 `v0.5.1`。
- 候选产物放在 `releases/v0.5.1/`，不覆盖 `releases/v0.5.0/`。
- 不直接移植课程的单 PLL、40/80 MHz 参数、低有效两拍复位或整组 `false_path`。
- 不批量删除文件或目录；只新增证据、版本说明和历史索引。

## S0/S1 基线记录

基线使用当前生产 RTL 和约束。v0.5.0 报告保留 67 个负端点，其中 64 个为 SDRAM 硬核接口、3 个为内存内部路径；不得用扩大例外或删除端点制造收敛。Flash 固化、上电自启和已知 SD 恢复边界沿用 v0.5.0。

本轮 S0 回归在 `tb_picture_requests` 的“失败后保留挂起请求”场景触发 Fatal（`pending request lost on failure`，约 1327980 ns）。该问题属于当前基线控制回归，尚未归因于 v0.5.1 文档变更；在修复或明确豁免前不进入 S2。
