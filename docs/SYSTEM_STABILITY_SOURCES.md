# 系统稳定性来源与适配

课程：`D:/My_Program/安路/资料/拓展系列/第五讲：系统稳定性/第4课_系统稳定性增强.md`。

配套代码：同目录下`第4课_系统稳定性/`，主要参考`bmp24_decoder.v`与`media_recovery_fsm.v`。前者依赖文件流/真实文件大小，支持正负高度和额外缩放；后者默认MAX_RETRIES=2，与正文建议1次不同。本项目保持正高度连续扇区，重试固定1次，不直接替换模块。

实际项目已有头失败释放load_busy与双缓冲显示确认；需要补显式成功事件和有限首图恢复，而非照抄课程中对官方原版的描述。课程超时计数不能直接用于整个扫描/整图；后续按无进展计时。BM快跳不能加速普通MP3，像素计数不能判断真实文件EOF或旧扇区内容。

范围/门禁见[阶段计划](系统稳定性分阶段修改计划.md)。SD底层缺陷继续延期，分析见[既有记录](diagnostics/s9_sd_recovery/analysis.md)。
