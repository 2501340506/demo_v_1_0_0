# 系统稳定性来源与适配

课程：`D:/My_Program/安路/资料/拓展系列/第五讲：系统稳定性/第4课_系统稳定性增强.md`。

配套代码：同目录下`第4课_系统稳定性/`，主要参考`bmp24_decoder.v`与`media_recovery_fsm.v`。前者依赖文件流/真实文件大小，支持正负高度和额外缩放；后者默认MAX_RETRIES=2，与正文建议1次不同。本项目保持正高度连续扇区，重试固定1次，不直接替换模块。

实际项目已有头失败释放load_busy与双缓冲显示确认；需要补显式成功事件和有限首图恢复，而非照抄课程中对官方原版的描述。课程超时计数不能直接用于整个扫描/整图；后续按无进展计时。BM快跳不能加速普通MP3，像素计数不能判断真实文件EOF或旧扇区内容。

范围/门禁见[阶段计划](系统稳定性分阶段修改计划.md)。SD底层缺陷继续延期，分析见[既有记录](diagnostics/s9_sd_recovery/analysis.md)。

## v0.5.4 S2修正适配

课程UART发送器思路适配100MHz/868拍；事件采集直接来自本项目播放器事务，不能从数码管显示码推导。队列不反压播放，真实COMMIT确认才更新日志编号。参见[修正版说明](../releases/v0.5.4/v0.5.4-s2-local.2/README.md)。扫描暂停和快启尚未交付。

## S3暂停/续扫适配

课程fast_boot_gate仅门控预加载结果，不能直接替代本项目按需加载调度。S3在bmp_read新增完整扇区边界暂停和独立续扫位置，加载不清扫描计数；生产输入固定关闭。S4再接调度，当前不宣称首图加速。[接口与验证](S3_SCAN_RESUME.md)。

S3 local.2：暂停接口新增编译期ENABLE_SCAN_PAUSE参数，生产设0、专项设1；不是课程模块直接替换。因local.1板测花屏，对照验证后单独隔离生产未启用逻辑；具体物理根因未证实，local.2已获用户确认上板功能正常。

## 2026-10-08 BMP 2.11 独立化


S3 采用本工程原有格式/扇区语义进行抽离，不直接套用课程完赛文件系统。bmp_header_check 统一头字段与格式/长度校验，供扫描适配层和独立 bmp24_decoder 复用；bmp_read 不再拥有解析核心、RGB 组装或像素计数。解码器完成事件映射至原加载接口，正常完成晚一拍。

独立模块支持正高度 24/32 位，生产保持 24 位显示/32 位快跳。保留 3 位错误码、原 SD 超时恢复和双缓冲提交边界。2.12 image 层、8 位错误码、独立恢复 FSM 等尚未实现。原始扇区无真实 EOF 的限制保留。

本地验证、资源/时序与板测门槛见 [S3 报告](../releases/v0.6.0-bmp211/s3-local.1/README.md)；不能将结构完成等同于 S3 已上板。
