# 「山区防灾避险课堂」——平急两用的山区地灾避险可视终端

> 全国大学生嵌入式芯片与系统设计竞赛 2026 · FPGA 创新设计赛道 · 安路科技 选题一（基于安路 EG4S20 的 HDMI 多媒体播放系统）
>
> 版本：v1.0（初版方案，M6 状态补充） 更新：2026-10-16
>
> 当前为 v0.17.0 M6 本地验证阶段，正式版仍为 v0.16.0。下文应用设想与当前实现须区分：示意村/山洪村均为虚构教学图，SND1–3 是节拍音效、SND4 是警报，尚无实录旁白。板测、冷启动及换卡秒数待用户实测；本候选验证入口见 [M6 计划](../M6_IMPLEMENTATION.md)。

---

## 1. 一句话介绍

用一块国产安路 EG4S20 FPGA 板，加一张 SD 卡、一台普通电视，就能搭出一台**开机即用、不依赖电脑和操作系统**的山区地质灾害避险终端：

- **平时**：给村小学生和村民上"灾害推演课"。
- **急时**：一键切换成预警撤离屏。
- **换地方**：每个村换一张"场景卡"就能适配。

## 2. 为什么做：痛点

### 2.1 灾害多发，伤亡集中在山区

- **2025 年全国自然灾害**：死亡失踪 763 人，直接经济损失 2416.17 亿元。
  - 其中**洪涝和地质灾害**造成 568 人死亡失踪，占 **74%**。
  - 西南地区的地质灾害起数约占 40%，死亡失踪和经济损失却约占 **80%**。（[应急管理部，2026-01](https://www.mem.gov.cn/xw/yjglbgzdt/202601/t20260116_592135.shtml)）
- **2025 年上半年地质灾害**：
  - 死亡失踪 84 人，其中 88.1% 集中在川黔滇藏。
  - 筠连县"2·8"滑坡死亡失踪 29 人，大方县"5·22"滑坡死亡失踪 19 人。（[119.gov.cn](https://www.119.gov.cn/qmxfgk/sjtj/2025/50640.shtml)）
- **截至 2024 年底**：
  - 全国登记地灾隐患点 **28.4 万处**，威胁 **1200 万以上**人口。（[中国地质调查局](https://m.cgs.gov.cn/ddyw/202505/t20250519_788184.html)）
  - 威胁百人以上的泥石流隐患点约 4800 处。（[国家林草局](https://www.forestry.gov.cn/lyj/1/kjzrjy/20260830/687011.html)）

### 2.2 "技防"进步快，"人防"是短板

- **监测这一端已经很普及**：群测群防员 27.8 万名，专业监测点 6.7 万个，普适型监测设备覆盖 28 个省 7.5 万处隐患点。2024 年成功预报 42 起，避免伤亡 676 人。（[中国气象局](https://www.cma.gov.cn/2011xwzx/2011xmtjj/202507/t20250716_7213356.html)）
- **人这一端还很薄弱**：地方"十四五"防治规划明确写到"群测群防员年龄偏大、业务能力弱""公众防灾意识淡薄、自救互救能力不足"。（[南康区规划](http://www.nkjx.gov.cn/nkqrmzf/c105201/202305/9403070cace443088fc703f286021b5a.shtml)）
- **预警传到了，人还是不知道往哪跑**：
  - 山区留守的多是**老人和儿童**，用不惯短信和微信。
  - 农村主要靠"大喇叭"，四川就有 4.62 万套村级应急广播。
  - 大喇叭**只有声音，没有画面**：说不清危险区在哪、往哪个方向撤、安置点在哪；线路还容易被灾害冲断。（[华龙网](https://news.cqnews.net/1/detail/1177647183664979968/web/content_1177647183664979968.html)、[中新网四川](https://www.sc.chinanews.com.cn/scxw/2024-10-29/218289.html)）

### 2.3 学校有刚性需求，手段却很初级

- **政策要求**：
  - 《中小学公共安全教育指导纲要》、《中小学幼儿园应急疏散演练指南》：每学期 5 次疏散演练，中学 2 分钟、小学 3 分钟内完成。
  - 《生命安全与健康教育进中小学课程教材指南》。
  - 安全宣传"五进"（进企业、进农村、进社区、进学校、进家庭）。
  - 防灾减灾日。
  - 均对防灾科普提出了明确要求。（[教育部答复](http://www.moe.gov.cn/jyb_xxgk/xxgk_jyta/jyta_jiaocaiju/202209/t20220923_664179.html)、[应急管理部答复](http://www.mem.gov.cn/gk/jytabljggk/zxwytadfzy/2024zx/202408/t20240806_496971.shtml)）
- **现实情况**：乡镇和村小能用的大多只有**挂图和 PPT**，学生看不到"灾害是怎么一步步发生的"。

### 2.4 现有数字化方案用不起、用不住

| 方案 | 价格 | 问题 |
|---|---|---|
| 数字沙盘 / 展厅系统 | 25–100 万元，展厅级 40 万元以上（[行业报价](https://zhuanlan.zhihu.com/p/437557859)） | 乡镇和村级单位买不起，内容定制费高（每分钟 4–12 万元） |
| PC 或安卓多媒体机 | 数千元 | 依赖操作系统：开机慢、会死机、要升级、病毒；无人值守时可靠性差 |
| 村级应急大喇叭 | 约 6700 元/个（开州 370 万元建 555 个） | 只有声音 |

**结论**：山区需要的是一台**便宜、皮实、开机就能用、不同村能快速适配**的"看得懂"的终端。

## 3. 我们做什么：产品定位

**平急两用**：同一台设备，平时做科普，急时做预警，对应国家推进"平急两用"公共基础设施的思路。

| 模式 | 场景 | 功能 |
|---|---|---|
| **平时：科普课堂模式** | 村小教室、村委会、乡镇科普角 | 在本村真实底图上分阶段推演"降雨 → 裂缝 → 滑坡/山洪 → 撤离"，配合旁白、字幕和音效，用于安全课和疏散演练前的讲解 |
| **急时：预警撤离模式** | 村委会、安置点、村口 | 当前显示闪烁红框、居中红色缩放预警语、撤离路线和避险点，循环警报；倒计时和撤离旁白为后续内容。UART 保留原字幕功能，不能替换卡上预警文案 |

**目标用户与采购方**：
- 县级自然资源局和应急管理局（地灾防治、群测群防经费）
- 教育局和学校（安全教育经费）
- 乡镇政府、村委会
- 防灾科普教育基地

## 4. 系统功能与现场演示

### 4.1 演示流程（约 3 分钟）

1. **上电**：出现卡上底图；Flash 完全断电到首个完整稳定画面的秒数待实测，不能先写成约一秒。拨码 00 下长按 KEY4 一秒进入场景。
2. **按键进入阶段 1「降雨预警」**：字幕"连续强降雨，蓝色预警"；雨声；右下角音频波形跳动。
3. **阶段 2「裂缝出现」**：画面淡入淡出，山坡上的**裂缝沿着真实位置一点点"长"出来**；旁白讲"发现裂缝要立即上报"。
4. **阶段 3「滑坡 / 山洪发生」**：**洪水从沟谷向两侧逐步蔓延**，前沿闪烁，并与旁白和山洪音效同步；预警等级升到红色。
5. **阶段 4「避险撤离」**：转场到撤离路线图，**路线一段段点亮**，避险点闪烁，OSD 显示"向北侧高地撤离，距安置点 800m"。
6. **切换到预警模式**：场景内短按 KEY1，红框、居中缩放红字及循环警报；再次短按返回第一阶段。KEY1 长按调速，KEY4 短按控制 AUTO，AUTO 等当前动画完成才推进。
7. **现场换卡**：拔下“示意村”卡，插上“山洪村”卡，**复位后重扫**并进入新村场景，**不重新烧写 FPGA**。

### 4.2 功能清单

| 功能 | 说明 | 实现状态 |
|---|---|---|
| SD 卡场景包读取 | FAT32 扫描、BMP（24/32 位）解析 | 已有，扩展 32 位 |
| SDRAM 帧缓存、四 bank 缓存 | 阶段切换不卡顿 | 已有 |
| HDMI 音视频输出 | 640×480，HDMI 内嵌音频 | 已有 |
| **动态灾害图层** | 基于"到达时间图"，由硬件实时渲染裂缝、洪水和路线的蔓延 | **新增（核心创新）** |
| **音画同步推演** | 以音频播放进度驱动动画时间轴 | **新增** |
| 阶段转场 | 画面淡入淡出，音频同步淡入淡出 | 画面部分已有，音频部分新增 |
| 中文字幕和 OSD | 阶段标题、旁白字幕、预警等级、倒计时 | 已有，新增文案 |
| 音频可视化 | 波形 / 环形电平叠加 | 已有 |
| 参数调节 | 亮度、对比度、音量、推演速度，带 OSD 参数条 | 已有，新增速度 |
| 预警模式和串口预警文字 | 模式切换，UART 下发滚动字幕 | 已有 UART 字幕，新增模式 |
| 换卡后复位 | 复位后重扫，一卡一村 | 双卡已制作，M6 板测待确认 |
| Flash 固化、上电自启 | 不需要 PC | 历史正式版已验收，M6 候选待实测 |

## 5. 一卡一村：怎么适配不同的山村

**原则**：FPGA 逻辑在所有村通用，**每个村的差异全部放在 SD 卡的"场景包"里**。

1. **数据来源，都是公开或政府已有的数据**：
   - 底图：天地图公开影像或自绘示意图。
   - 地形：公开 30m DEM 高程数据。
   - 隐患点、撤离路线、安置点：每处隐患点按要求都有"防灾避险明白卡"或"一点一策"预案，**照着描即可**。
2. **PC 端场景包工具**：工作人员在底图上标出沟谷、裂缝位置和撤离路线，工具自动计算"到达时间图"，合成 32 位图片，再把旁白转成音频，一键导出到 SD 卡。
3. **规模化**：一个村的场景卡大约**半天**做完；县里集中制作、批量下发。换灾种（地震、消防、溺水）也只是换一张卡。

## 6. 创新点

1. **基于"到达时间图"的硬件实时灾害演化渲染**
   - 一般做法是逐帧播放视频，我们只存一张底图加一张 8 位"到达时间"通道。
   - FPGA 在显示扫描时逐像素比较"当前时刻"和"到达时刻"，**实时**生成连续的蔓延动画。
   - 素材量小，推演速度可调；关闭 AUTO 停在本阶段终态，当前未实现任意时刻暂停。
   - 通道放在 SDRAM 像素字原本空闲的 8 位中；加载及缩放通路扩位增加片上缓存，FONT/TEXT 另用两块 BRAM32k，不能宣称完全不增加片上存储。
2. **音频主时钟驱动的视觉时间轴**：动画进度由音频播放的样本数推进，旁白说到哪画面就演到哪，天然做到音画同步。
3. **平急两用**：同一台硬件兼顾科普和预警，补上大喇叭"只有声音、没有画面"的短板。
4. **一卡一村的数据驱动适配**：逻辑通用、内容可换，现场换卡后复位即可换村。
5. **纯国产 FPGA，无处理器，无操作系统**：开机即用，时序确定，适合无人值守；符合信创和自主可控方向。

## 8. 成本与落地

| 项目 | 本方案 | 对比 |
|---|---|---|
| 硬件 | FPGA 板、SD 卡、电源，约千元级（量产后可进一步降低）；显示用村里现有电视 | 数字沙盘 25–100 万元 |

| 运维 | 无系统、无升级、断电自恢复 | PC 方案需要专人维护 |

**推广路径**：
1. 试点：与学校所在地或周边的高风险县联系，拿一个村做场景卡。
2. 县级推广：纳入群测群防、安全宣传"五进"的物资清单。
3. 扩展：地震、消防、防溺水等科普卡，科普基地批量配置。

**商业模式**：硬件低价销售，按村或按灾种收取场景包制作和更新的服务费。

## 10. 后续规划

- 第二阶段：
  - "你往哪跑？"互动答题模式，学生用按键选撤离方向。
  - 适老化：大字号、高对比、方言旁白。
  - 标记点保存到 Flash。
  - 卡损坏时退到内置警示画面（失效安全）。
  - 免复位换卡：换卡后按一下"换卡"键即可，无需重启。
  - 到达时间图 T 也在 FPGA 上生成：卡上只放沟谷位置图，加载时片上算出 T。
- 展望：
  - 接入雨量计、裂缝计和县级预警平台，自动切换到预警模式。
  - 多块同款板组成主从结构，实现多屏同步预警。
