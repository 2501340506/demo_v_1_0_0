# 模式选择阶段3：跨模式 AUTO 与挂起回归

阶段2已完成板级验收。阶段3增加模式变化对AUTO计时的明确行为，图片请求挂起机制继续沿用原实现。

## 本阶段行为

- AUTO在00/01/10/11四种模式均保持有效。
- 模式稳定值变化时仅重置AUTO等待计时，不清除MAN/AUTO状态，也不清除已挂起的上一张/下一张请求。
- AUTO计时到期时，手动方向请求优先；加载期间不计时。
- 加载完成和显示交接后，挂起方向继续按下一张优先、同向合并规则执行，并使用当时的当前图片编号计算目标。
- 切回MAN停止后续自动请求，但正在加载和已有挂起请求继续完成。

## 验证

- `tb_media_player_control`通过模式切换清零计时、手动优先、挂起方向和原自动轮播回归，0 errors、0 warnings。
- 阶段2的模式按键仿真和RTL编译保持通过。

## 上板步骤

1. 下载阶段3 `demo.bit`，确认阶段2的模式显示、方向键门控及KEY4切换仍正常。
2. 在每个模式进入AUTO，等待自动翻图；切换拨码后确认仍处于AUTO，但重新等待完整轮播周期。
3. AUTO加载期间按KEY1/KEY2，确认请求在交接后按原挂起规则执行。
4. AUTO期间切回MAN，确认当前加载和已有挂起请求完成，之后不再自动翻图。
5. 在四种模式重复上述操作，确认图像、图片编号和AUTO小数点一致。

通过后进入阶段4整体回归、最终构建和交接。
