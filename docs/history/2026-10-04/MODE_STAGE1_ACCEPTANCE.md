# 模式选择阶段1：拨码与数码管验收

日期：2026-10-04。基于已验收的 v0.1.9；本文件描述阶段1，不代表全部新按键功能完成。

## 本阶段行为

- SW1=C8、SW2=C7，拨上为1；整体稳定20ms后更新模式。
- 数码管扫描位4（`seg_sel[4]`，E11）显示模式；扫描位5继续显示图片编号/启动状态和自动轮播小数点。物理左右方向以上板为准。
- KEY4=C1已登记为低有效输入，本阶段未接入功能。
- 原按键仍有效：KEY1下一张；KEY2短按释放切换轮播、长按上一张。四种拨码模式均不限制旧按键。
- 旧组合事件仍可在图片位短暂显示计数；原C标记位改为始终显示模式。阶段2再移除组合入口。
- 播放控制器、忙时挂起方向、请求优先级、双缓冲和音视频链路未修改。

## 上板步骤

使用 `TD_project/demo_Runs/phy_1/demo.bit`，不使用旧的 `best_result/demo.bit`。

1. 插入现有测试TF卡，SW2/SW1拨到00，上电确认原图像与音频正常，模式位显示0。
2. 依次切换01、10、11、00，模式位应显示1、2、3、0，图片不因拨码自动切换。
3. 按原KEY1/KEY2操作，检查图片编号和轮播小数点仍正常。AUTO下等待切图属于旧轮播行为。
4. SW2/SW1保持11复位，复位解除后模式恢复显示3；播放器按原流程重新扫描和加载。
5. KEY4此阶段不应产生动作。

请确认四种模式显示、图片编号/轮播小数点、原图像和音频是否正常。通过后进入阶段2的新按键入口实现。
