# v0.27.0 — SW4 独立调节面板正式版

基线 v0.26.0-s1-local.1（对称白色波形，板测通过，已合入 main）。新增拨码开关 SW4：任何模式下拨上，右侧滑出中文调节面板，集中调节画面、声音、波形、场景速度和各项显示开关；去掉 SW1/SW2 原来的调节模式；修复宣讲第 1 页字幕残留。

正式文件：[demo.bit](demo.bit)，677348 字节，直接复用已上板通过的 [s1-local.5](s1-local.5/README.md)（源码 `4a27188`，构建 `adj27f_td_s11`，Seed 11），逐字节一致，不重新构建。SHA-256 `5b0d59f3dcdc45e71bd33033f0c0e76763b7ca6149195529748ff776ca4a46b2`。

**卡不用换**：沿用 v0.25.0 的 s5-card.2。约束新增 SW4 = C5（LVCMOS33，无上拉）。

## 用法

- **SW4（C5）拨上**：面板 8 帧从右侧滑入；拨下滑出，按键恢复原来的作用。面板打开时按键只归面板，不翻页、不重扫、不切 AUTO；SW3 菜单打开时先归菜单。
- **光标态**（左栏蓝底）：K1↑ K2↓ 移动，11 项循环；K4 短按进入编辑。
- **编辑态**（条目蓝底）：K1 减、K2 加（开关项 K1=关、K2=开）；K4 短按返回；K1+K2 同按恢复这一项默认。
- **全部重置**：移到“重置 → 全部重置”，K4 长按 1 s。
- 参数复位后回到默认，不存到卡上。

| 分类 | 条目 | 范围 / 默认 | 作用 |
|---|---|---|---|
| 画面 | 亮度、对比度 | 0..255 / 128 | 全画面 |
| 声音 | 音量 | 0..200%（10% 一档）/ 100% | 超过 100% 削顶 |
| 波形 | 显示 | 开/关 / 开 | 宣讲底部波形 |
| | 高度 | 0..3 / 3 | 柱高 ×(n+1)/4 |
| | 渐变 | 0..3 / 2 | 蓝色渐变深浅 |
| 场景 | 速度 | 1X/2X/4X / 1X | 场景播放速度；不在场景时显示 `--`；KEY1 长按仍可换速 |
| 功能 | 状态栏 | 开/关 / 开 | 旧图片左上状态行；场景右上面板和左下图例 |
| | 字幕 | 开/关 / 开 | 旧图片滚动字幕；场景底部字幕条；宣讲旁白字幕 |
| | 淡入 | 开/关 / 开 | 换图淡入/擦除，关=直接切换 |
| 重置 | 全部重置 | 长按 K4 | 全部恢复默认 |

## 改动

- **SW4 面板**：两栏版式（参考 Pixio OSD 简化），项目原有配色（底色 102030、蓝 3c82f0、白字）；标题“参数调节”居中，底部“K1↑ K2↓ K4编辑/返回”。新模块：`adjust_panel_overlay`、`adjust_panel_keys`、`scene_speed_request`；`media_adjust_control` 改为只由面板驱动；邮箱 24→39 位。
- **中文字模**：61 个字（宋体 16×16，与场景 FONT.BIN 同字体）由 `tools/make_panel_font.py` 生成 `panel_font_rom.v`，放 2 块 BRAM9K；8 px 半格排版。改字只改脚本字符串再生成。
- **SW1/SW2**：01、10 当作 00，原 mode 1/2 调节去掉；左上 B/C/V 数值和场景左上 SPEED 字样都不再显示。
- **状态栏/字幕开关**：接到情景面板、图例、字幕条和宣讲旁白（s1-local.1 只接了旧图片模式）。
- **音量 200%**：`pcm_master_volume` 21 档并削顶。
- **修复**：宣讲第 1 页语音播完后字幕残留。滚动原来只在“在播且正在画”的帧前进，第 1 页开头丢帧而结尾余量只有 5 帧；现在在播每帧都前进，播完后把剩下的文字滚完。

## 验收

- **板测**（用户确认，2026-10-23，s1-local.5）：“功能正常”，未提供逐项结果。此前 s1-local.1 板测发现状态栏/字幕开关在情景、宣讲画面无效（.2 修复）；用户另反馈宣讲第 1 页字幕残留（.5 修复）。.2、.3、.4 没有单独的板测结论，由 .5 一并验收。
- **本地**：面板按键手势、面板状态（11 项、速度请求、全部重置）、场景速度闭环、面板像素与滑入滑出、RTL 渲染中文预览；场景三帧开关比较（状态栏/字幕互不影响）；场景 OSD 8 张卡逐像素和 24 个变异体、换卡 4 次；宣讲旁白（含短语音尾滚、隐藏帧同步）和生产 top 旁白；音量 21 档逐样本含削顶；按键 1 ms 计时 12 项和 4 个变异体；波形单元和生产 top 逐像素；SD 引脚级启动；复位审计（新增模块的复位都来自复位同步寄存器）。
- **限制**：
  - SD 时钟域时序余量仍小：每轮 7 个种子通常只有 1 个通过（本版 Seed 11），最差路径都在 SD 域原有逻辑。以后改动要多跑种子。
  - 宣讲第 1 页实际丢几帧没有在板上测量；修复不依赖丢帧数量。
  - 遗留旧测试台：`mountain_scene/run_m5_unit.ps1` 的 `tb_m5_scan`、`run_m5_text.ps1`、`audio_vis/run_gate.ps1`、`disaster_selector/run_mode_key_equivalence.ps1`、`publicity_mode/run_m5.ps1` 在 main 上本来就跑不过，与本版无关。
