# S2 日志验收更正（2026-10-07）

用户对 s2-local.1 反馈“相关测试通过”，此播放功能反馈保留。但所附串口日志证明事件输出存在错误：正常翻图时 E/P 跟随图片编号，SCAN_START/LOAD 假事件出现，S 始终为零，缺少真实重扫输出。

日志摘录（不是完整日志）：
```
COMMIT     T=0000AA3B I=1 S=00000000 E=2 P=2 A=0 D=0000000000000000
SCAN_START T=0000AA3B I=1 S=00000000 E=2 P=2 A=0 D=0000000000000000
ERROR      T=00019543 I=2 S=00000000 E=7 P=F A=1 D=0200B295B29511FF
```

根因：旧顶层把复用数码管显示码作为事件/错误码，扇区固定零，重扫未接入，初始化成功在复位时伪造。旧串口测试仅等待空闲，不能支持原文关于字节和上下文验证通过的结论。先前助手误读日志并创建、推送 e75ba93 和 s2-board.1，这是错误的日志验收判断。

旧 local.1/board.1 标签和 bit 保留，不移动、不删除；不能作为日志正确性的证据。旧验收表中逐项通过的扩展结论被本更正取代。新 local.2 未上板、未上传；S3 暂缓，实验构建不作为交付。

修正：控制域直接观察真实初始化、扫描、加载、重试、跳过、显示确认、重扫和模式事件；使用真实任务图片/扇区/BMP错误码。新增播放器上下文计分板、重扫计数检查、独立 8N1 字节接收和队列满测试。首次修订的启动行长度错误被接收测试检出，修复后重跑专项并重新完整 TD 构建；只交付最终 v054_s2fix_final 产物。

完整基线七套 BMP、三组像素交接、八项既有回归，以及三组真实解析器重扫交接和 UART 专项通过。TD Setup +0.168ns、Hold +0.019ns；警告类型未增加。快启与暂停续扫尚未交付。
