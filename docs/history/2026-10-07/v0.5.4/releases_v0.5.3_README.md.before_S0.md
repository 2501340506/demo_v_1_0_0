# v0.5.3 `bmp_read` LUT 优化：本地候选

候选 v0.5.3-local.1；仅修改 bmp_read.v 生产逻辑。等待用户上板，未上传 GitHub，未建立 board/正式标签。

## 变更

- BMP 签名、planes、bit_count、compression 保存逐字节匹配标志，保留高字节检查和复位值语义。
- 扇区完整性使用 511/512 常量比较；保留最后字节与结束同拍的处理。
- 扇区数量使用商与余数进位，保留零长度和最大 32 位文件长度行为。
- 扫描复用读地址；头扇区后保留加载读地址，移除两份重复 32 位地址锁存。
- 端口、动态宽高、BMP 支持范围、超时、扫描跳过、错误处理保持原行为。其他模块、PLL、约束不变。

## 实测

同一 TD 6.2.168116 / EG4S20BG256，high-fanout high、timing ultra、post-place high、默认 seed，基线与最终候选均在独立目录构建。

| 指标 | 本次重建基线 | 最终候选 | 变化 |
|---|---:|---:|---:|
| bmp_read 综合 LUT | 875 | 820 | -55（6.3%） |
| bmp_read 综合寄存器 | 692 | 559 | -133 |
| bmp_read 布局 LUT | 822 | 704 | -118（14.4%） |
| bmp_read 布局 ripple | 287 | 276 | -11 |
| bmp_read 布局寄存器 | 707 | 581 | -126 |
| 顶层综合 LUT | 4529 | 4460 | -69 |
| 顶层布局 LUT | 4647 | 4571 | -76（1.6%） |
| 顶层布局寄存器 | 3412 | 3280 | -132 |
| BRAM / DSP / PLL | 4 / 4 / 1 | 4 / 4 / 1 | 不变 |
| Setup WNS | -0.115 ns | +0.107 ns | 候选通过 |
| Hold WNS | +0.004 ns | +0.004 ns | 通过 |

原工作区历史综合报告为 870 LUT，单独保留，不与本次重建基线 875 混用。旧已验收 I/O seed 3 报告为 Setup +0.148 ns / Hold +0.011 ns；新默认 seed 基线的负时序不覆盖旧版验收记录。候选报告无负端点，覆盖率 99.90%；既有工具告警保留。

最终源码：七套 BMP 专项（完整 307200 像素、头部、扫描、像素、超时、恢复、上层超时）、三组真实解析器异步交接、八个既有回归入口。编译/仿真零错误零警告；TD 综合、布局布线、bitgen 完成。

最终日志在 v0.5.3-local.1/simulation/final/；面积和时序见 timing/demo_phy.area、demo_pr.timing、syn_demo_gate.area；最终构建日志名称含 v053_final。其余日志为早期试验，不替代最终证据。源码快照 sources/，清单 sources.txt。bit 为 629624 字节，已与最终输出逐字节核对。

复现入口 diagnostics/lut_bmp/README.md。用户 GUI 工程原有单 PLL 引用缺失已原样保留，隔离构建使用归档清单。
