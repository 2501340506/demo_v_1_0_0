# 版本产物目录

当前开发：[v0.5.4 S1 UART启动行](v0.5.4/README.md)，本地通过、待用户上板，未上传。

正式版本使用 `releases/vX.Y.Z/`。属于该版本的阶段候选放在正式版本目录内，并保留完整标签名作为子目录名，例如：

```text
releases/
  v0.4.0/
    README.md
    demo.bit
    v0.4.0-s1-local.1/
    v0.4.0-s2-local.1/
    ...
```

`v0.1.3`、`v0.1.4` 等是各自独立的正式版本，不归入其他版本。Git标签名称不受目录调整影响；历史文档和工程快照应引用嵌套后的路径。
