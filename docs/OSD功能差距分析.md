# OSD 功能差距分析（2026-10-10）

基线：已发布 v0.9.1。核对范围：第九讲 Markdown、同目录 6 个参考 RTL、当前生产 OSD/顶层及播放控制。只做静态分析，不改 RTL、不重建 bit。

## 当前能力与缺口

| 功能 | 当前状态 | 说明 |
|---|---|---|
| PIC/MAN/AUTO/ERR 状态条 | 已实现 | 视频域首个有效像素锁存状态，整帧保持 |
| 固定英文滚动 | 已实现 | 编译期文本，默认每帧 1 像素，窗口/位置/步进参数化 |
| 黑色半透明底条 | 已实现 | 每通道减半，显式字形命中保色，非任意 Alpha 混合 |
| 固定中文标语/中英混排 | 未实现 | 当前仅 5×7 英文字模，无汉字字库和中文编号渲染 |
| 任意中文输入 | 未实现 | 参考代码也只有预置 9 字，不是通用 UTF-8/GBK 字库系统 |
| UART 在线修改/查询/开关字幕 | 未实现 | 当前顶层只有 uart_tx 日志，无 uart_rx、命令解析与回复仲裁 |
| 运行时字幕帧提交 | 未实现 | 当前文本为综合常量；状态 CDC 已有，不等于文本 CDC 已有 |
| 字幕掉电保存/启动恢复 | 未实现 | FPGA bit 的 Flash 启动已验收，但没有字幕配置持久化；参考 SAVE 只是请求接口 |
| MM:SS 时间显示 | 未实现 | 参考 timestamp_osd 按 60 帧计秒，是累计时间而非真实日期/RTC |
| 亮度/音量/周期/缩放参数行 | 未实现 | 参考 promax 可显示参数；不意味着对应图像/控制功能已实现 |
| 任意透明度/彩色层混合 | 部分实现 | 当前只有固定黑色约 50% 底条，字形不透明替换 |
| 运行时速度/位置/颜色/开关 | 未实现 | 当前多为编译参数或固定颜色，不能在串口/按键即时调整 |

相关项目能力：音频模块有 volume 输入，但顶层固定 128；AUTO 间隔为编译参数 AUTO_PLAY_MS=3000。亮度/对比度和图像缩放未见生产处理链，不应把参数行显示当作实际调节能力。上述是本课涉及的关联差距，并非对全部其他课程的完整审计。

## 中文功能的真实范围

参考 promax_text_overlay.v 的 93–120 行内置 CN_GLYPH_0..8，每字 16×16、256 位，9 字共 2304 位（288 字节原始点阵）。它以字节最高位区分中文，再取低 4 位查字模，使用 18×18 字符单元。不是 Unicode 字库。

subtitle_uart_controller.v 使用 0x80..0x88 编排固定短语；cn_phrase_match 逐字节匹配一条 9 字中文短语的 UTF-8 序列，SUB=CN 切换同一预置内容，其他普通文本路径只接受可打印 ASCII 并将小写转大写。96 位容纳 12 个单字节内部字符槽，不是 16 个字符，也不是任意 12 个 UTF-8 汉字。参考 glyph 图样与短语是否一致仍需渲染确认，不能仅凭命名认定视觉正确。

当前 scroll_text_overlay 只有 TEXT 参数和英文 osd_font_5x7；直接把中文字符串写进 TEXT 不会生成汉字。需要新增汉字点阵、内部编号与渲染选择，并同步计算字符宽度、滚动周期和底条范围。固定中文无需 UART 或文本 CDC；在线改字幕才需要接入接收器、完整文本暂存、带确认的跨域传输和帧边界更新。

## 建议顺序

1. 固定中文/中英标语：只内置实际要用的字，采用 16×16 点阵，可用统一 18×18 单元容纳中英；复用现有滚动、帧事件与字形 active，调整底条高度。先渲染字库预览，再测完整滚动、边界、原图透传和 TD。具体标语待用户选定。
2. 在线字幕：增加 UART RX 及命令、与现有日志的 TX 仲裁；先支持 ASCII 和已安装字库中的汉字。完整消息写入暂存，保持数据到确认，再在帧边界提交。不要直接照搬课程无确认 toggle，以免连续更新覆盖或丢失。
3. 时间显示与参数面板：时间优先使用已知时钟计秒或按实际帧率设计；音量和周期先落实控制再显示。参考时间模块硬编码 60 帧，不能直接当精确时钟。
4. 按需增加字幕保存和更多字库；任意汉字、任意 Alpha 单独立项，避免将小型固定字幕扩成完整文字系统。

课程正文与配套代码存在版本差异：正文部分仍称没有滚动/Alpha，配套 promax 已有滚动及不透明底色，本项目 v0.9.1 则已实现滚动和半透明底条。以实际接入的生产代码为准，不按课程名称或旧说明判缺失。
