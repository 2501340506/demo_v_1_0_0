# 灾害 SW3 操作与板测

SW3 对应 C6，拨上为 1；KEY3 仍为复位。四宫格按行排列：滑坡、泥石流、山洪、地震。KEY1 前一个、KEY2 后一个、KEY4 确认。黄色框为焦点，灰色图表示该场景不可用，不能确认。

上电 SW3=1 或再次从 0 拨到 1，请求菜单；正在读取、切页或播放音频时等待安全交接。四张首图按顺序加载，每个场景还会校验其余三张图，因此加载期间需要等待。菜单暂停音频及自动推进。

确认后从所选灾害第一阶段、非预警、AUTO 关闭开始，公共参数和情景速度保留。SW3 保持 1 不会重复打开。确认后暂显示全屏，下一次实际拨动 SW1/SW2 后恢复对应页面。按键交接必须先释放再按。

未确认时拨回 SW3=0，恢复原应用、页面、参数、速度及 AUTO，当前讲解或阶段从头恢复。参数页或原预览页也按此规则恢复。

## 卡目录

根目录完整资源集仍优先供正常应用启动；菜单明确选择使用对应子目录，不受根目录优先规则影响。目录按真实 VFAT 长名匹配，不依赖生成的短名或目录顺序。

| 位置 | 名称 | 目录 | 图片 |
|---|---|---|---|
| 左上 | 滑坡 | 情景模式/landslide_village | PIC1–4.BMP |
| 右上 | 泥石流 | 情景模式/debris_village | PIC1–4.BMP |
| 左下 | 山洪 | 情景模式/flood_village | PIC1–4.BMP |
| 右下 | 地震 | 情景模式/quake_village | PIC1–4.BMP |

每组 PIC1 为菜单首图；BMP 头 byte6 为灾害类型 1–4，byte7 为阶段 1–4，必须与目录及文件名一致。四阶段缺失、损坏、读失败或类型不符时，该场景不可用。原根目录旧编码继续兼容。可选 SND1–4.PCM、FONT.BIN、TEXT.BIN 按原规则加载；切换资源集清除旧有效标记。宣传应用另支持“宣讲模式”目录中的 EDU1–4.BMP、VOI1–4.PCM 和可选 FONT/TEXT。

本任务仅读取 G:\，未改写原卡。软件测试卡保存在 diagnostics/output 中，不能用其短测试音或传输测试 FONT/TEXT 代替正式内容。

## 待执行的实板检查

使用 releases 中固定候选 bit，记录实际标签、卡内容、显示器、操作及观察结果。以下全部仍待用户确认，软件仿真不代替板测。

1. SW3=0 冷启动原卡，核对宣传播放、四阶段、预览、参数、音量、字幕、预警及数码管 SD 调试页。
2. SW3=1 冷启动，等待四图完成，检查图与中文名称一一对应、等比例完整显示、黄色焦点前后循环。
3. 分别确认四类灾害，逐阶段检查 16 张图、灾害图层及对应声音；确认从第一阶段、非预警、AUTO 关闭开始，参数与速度保留。
4. 保持 SW3=1 不应重开；0→1 重新选择。在宣传、情景、参数页及预览页分别进入菜单并取消，检查页面、AUTO、参数和速度恢复，以及讲解/阶段重播。
5. 读取或切页中拨 SW3，检查事务结束后进入；按住确认键或翻页键交接，释放前不得触发 AUTO、参数调整或切应用。
6. 确认后检查全屏保持，实际拨动 SW1/SW2 后恢复对应页面；取消应恢复原页面。
7. 用独立测试卡检查缺图、坏图、错类型场景为灰色且不能确认，其他场景可用；检查根目录完整资源优先及旧根目录卡兼容。不要破坏原卡制作负例。
8. 最后恢复正常卡，核对原全屏及阶段预览缓存未被菜单破坏，音画联动、自动推进和 SD 数码管仍正常。
