# FAT32 文件系统升级 v0.7.0

## 范围与基线

执行用户确认的 FAT32 升级方案。资料目录原件只读；固定根目录 PIC1.BMP～PIC4.BMP，允许缺图，按编号形成紧凑播放列表。支持 FAT32 MBR/直接引导、完整根目录簇链、碎片文件和目录项真实文件大小。保持 24 位 BMP、当前尺寸、按键、轮播、音频、双缓冲及重扫恢复。不扩展子目录、LFN、文件写入和图片数量。

开发分支 `feature/fat32-filesystem` 从当前 main 建立，隔离工作目录为主工作区的 `diagnostics/output/fat32_worktree`。用户原工作区的 TD 工程、best_result、历史候选工程和个人记录不纳入提交。回退标签 `v0.6.0-bmp211-s3-board.1`，固定 bit 为 `releases/v0.6.0-bmp211/s3-local.1/demo.bit`。

## 接口与实现约定

- `sd_sector_adapter`：sector 请求/地址/忙/字节/索引/完成/错误接口，对接现有 sd_card_top。锁存 LBA，保持底层请求直到完成/失败；完成晚于最后字节；失败也完成；512 字节校验及无进展超时。S1 以单次请求桥接旧 BMP 电平接口，等待旧请求撤销，避免重复读。
- `fat32_volume_scanner`：MBR 四个主分区中首个 0x0B/0x0C 或 LBA0 直接引导；BPB 动态布局、活动 FAT；完整根目录扇区和簇链；普通文件属性按位过滤；目标缺失不是卷故障。
- `fat32_file_streamer`：按簇链输出字节及偏移，目录项大小限制输出。读足即结束，不强制末簇立即 EOC。必要的簇范围、提前 EOC、读失败和遍历上限检查，不加入复杂修复分支。
- `fat32_bmp_reader`：扫描后按编号预检头部与目录项大小；复用 bmp_header_check 和 bmp24_decoder。先取得 SDRAM 写确认，再启动流与解码；空闲 ready、保持 scan_done、单次 load_done/error 分开。解析失败停止新请求并排空当前扇区。
- `sd_card_bmp`：存储簇号/大小，诊断地址仍为物理 LBA。成功提交必须等待文件、解码、SDRAM 写入全部完成。保持外部 3 位错误和 UART 包格式；内部 8 位 FAT 原因区分介质故障与坏文件。旧扫描范围参数兼容保留，FAT32 不使用。

## 验证与交付

S1 重点检查完整扇区、末字节与完成同拍、短传输、无正常结束的失败、超时、连续请求、复位和旧请求撤销。运行真实 BMP/异步缓冲与重扫交接，相关控制、SD 恢复、解码、音视频及启动回归。TD 检查实际资源、Setup/Hold 和 bitgen，不以仿真代替板测。

S2/S3 覆盖根目录非簇 2、跨扇区/簇、缺图/空目录、属性过滤、连续/碎片文件、不同簇大小、大地址、非整扇区文件尾及真实截断。逐字节、逐像素核对；坏链、坏图和重扫不得提交残帧。测试卡由用户准备，不自动格式化或删除卡内文件。

正式候选放 releases/v0.7.0/，只备份新增和修改源码；完整构建放 diagnostics/output/。每阶段更新 HANDOFF、必要说明和 CHANGELOG。结项归档 docs/history/<完成日期>/fat32-filesystem/。
