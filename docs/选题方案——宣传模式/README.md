# 选题方案——宣传模式

日期：2026-10-16。文档版本：v1.3，M0完成，M1 PC完成、内容待审，M2模块完成、生产未启用，M3–M6待实施。

在安路 EG4S20 多媒体系统上增加“专业科普性宣传模式”，与现有“地灾情景演示模式”组成两个应用模式。KEY4 短按保持 AUTO，长按 ≥1 秒切换应用模式；拨码负责参数与预览操作页。

| 文档 | 用途 |
|---|---|
| [01_方案书.md](01_方案书.md) | 应用定位、四页科普内容、交互、演示与验收目标 |
| [02_技术实现.md](02_技术实现.md) | 双模式架构、同卡素材、缓存切换、音频完成判定与实现接口 |
| [03_实现里程碑.md](03_实现里程碑.md) | M0–M6 分步执行、验证门槛及可复制的会话启动提示 |

参考资料为 [原选题方案](../选题方案/01_方案书.md)。实施事实以 [项目交接](../../HANDOFF.md)、[执行规则](../../执行规则.md) 和当前生产源码为准；原方案中的热插拔、冷启动秒数等早期设想不作为已实现能力。

M0固定硬件输入为 `v0.17.0-m6-local.1`（`2c78c3a`），仍待整机板测；正式回退为 `v0.16.0`。本组文档此前已在e71f86a纳管；新功能分支 `feature/science-publicity-mode` 从该文档备份提交建立，目标 `v0.18.0`。M1已制作[四页草稿与工具](../../tools/publicity/README.md)，16项PC验证与逐字节复现通过，见[M1证据](../../diagnostics/publicity_mode/M1_VALIDATION.md)。测试音不是正式配音，专业审阅/录音/听审仍待完成。M2已修改scanner/reader，默认关闭，108份仿真/回归及独立综合完成，见[M2证据](../../diagnostics/publicity_mode/M2_VALIDATION.md)；生产未启用，无bit/local/board标签、未发布正式版，也不增加前序验收结论。

继续实施请从 [v0.18.0 阶段计划与按键矩阵](../专业科普宣传模式分阶段修改计划.md)、[实际接口清单](../宣传模式接口清单.md) 和 [最新交接](../../HANDOFF.md) 开始。M0计划标签为 `v0.18.0-plan.1`，下一阶段M3安全切应用等待实施指令，无生产bit时不建local/board标签。
