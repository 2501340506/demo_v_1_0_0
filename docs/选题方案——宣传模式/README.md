# 选题方案——宣传模式

日期：2026-10-16。文档版本：v1.0，待实施方案。

在安路 EG4S20 多媒体系统上增加“专业科普性宣传模式”，与现有“地灾情景演示模式”组成两个应用模式。KEY4 短按保持 AUTO，长按 ≥1 秒切换应用模式；拨码负责参数与预览操作页。

| 文档 | 用途 |
|---|---|
| [01_方案书.md](01_方案书.md) | 应用定位、四页科普内容、交互、演示与验收目标 |
| [02_技术实现.md](02_技术实现.md) | 双模式架构、同卡素材、缓存切换、音频完成判定与实现接口 |
| [03_实现里程碑.md](03_实现里程碑.md) | M0–M6 分步执行、验证门槛及可复制的会话启动提示 |

参考资料为 [原选题方案](../选题方案/01_方案书.md)。实施事实以 [项目交接](../../HANDOFF.md)、[执行规则](../../执行规则.md) 和当前生产源码为准；原方案中的热插拔、冷启动秒数等早期设想不作为已实现能力。

当前参考输入为 `v0.17.0-m6-local.1`（`2c78c3a`），仍待整机板测；正式回退为 `v0.16.0`。新功能拟规划为 `v0.18.0`。本组文档已按用户 GitHub 备份要求纳入 `docs/选题方案——宣传模式/`，尚未执行宣传模式 M0、修改 RTL、创建新功能分支或发布版本；正式实施时重新核实基线。
