# 选题方案——宣传模式

日期：2026-10-16。文档版本：v1.1，M0 计划完成，M1–M6 待实施。

在安路 EG4S20 多媒体系统上增加“专业科普性宣传模式”，与现有“地灾情景演示模式”组成两个应用模式。KEY4 短按保持 AUTO，长按 ≥1 秒切换应用模式；拨码负责参数与预览操作页。

| 文档 | 用途 |
|---|---|
| [01_方案书.md](01_方案书.md) | 应用定位、四页科普内容、交互、演示与验收目标 |
| [02_技术实现.md](02_技术实现.md) | 双模式架构、同卡素材、缓存切换、音频完成判定与实现接口 |
| [03_实现里程碑.md](03_实现里程碑.md) | M0–M6 分步执行、验证门槛及可复制的会话启动提示 |

参考资料为 [原选题方案](../选题方案/01_方案书.md)。实施事实以 [项目交接](../../HANDOFF.md)、[执行规则](../../执行规则.md) 和当前生产源码为准；原方案中的热插拔、冷启动秒数等早期设想不作为已实现能力。

M0 固定硬件输入为 `v0.17.0-m6-local.1`（`2c78c3a`），仍待整机板测；正式回退为 `v0.16.0`。本组文档此前已在 e71f86a 纳管；新功能分支 `feature/science-publicity-mode` 从该文档备份提交建立，目标 `v0.18.0`。本次只完成 M0，未改 RTL、未构建 bit、未发布正式版，也不增加前序验收结论。

继续实施请从 [v0.18.0 阶段计划与按键矩阵](../专业科普宣传模式分阶段修改计划.md)、[实际接口清单](../宣传模式接口清单.md) 和 [最新交接](../../HANDOFF.md) 开始。M0 计划标签为 `v0.18.0-plan.1`，下一阶段 M1 为四页内容与 PC 工具，无独立 bit 时不建 local/board 标签。
