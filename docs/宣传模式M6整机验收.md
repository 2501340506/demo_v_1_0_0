## 2. 操作

拨码顺序为 `{SW2,SW1}`。上电00，完整EDU优先宣传第1页。按键短按后松开；跨拨码/切换忙中按住的键先松开再按。

| 页面/应用 | KEY1 | KEY2 | KEY4 |
|---|---|---|---|
| 00宣传 | 上一页，首尾循环 | 短下一页；长≥2秒重扫 | 短AUTO开关；长≥1秒切情景 |
| 00情景 | 短预警开关；长≥1秒循环1X/2X/4X | 短下一阶段；长≥2秒重扫 | 短AUTO开关；长≥1秒回宣传/COMPAT |
| 00 COMPAT | 上一张 | 短下一张；长≥2秒重扫 | 短旧图片AUTO；长≥1秒请求情景 |
| 01 | 当前项减 | 当前项加 | 短B↔V，长不切应用 |
| 10 | 当前项减 | 当前项加 | 短C↔V，长不切应用 |
| 11 | 前一焦点 | 短后一焦点；长≥2秒重扫 | 按下提交全屏；再按回四宫格；长不切应用 |

01/10的KEY1+KEY2在100ms组合窗口恢复当前项默认值。B/C默认128、范围0–255、步进16；V默认10、范围0–10、步进1，显示0–100%。无掉电保存；参数及情景速度跨应用保留。参数页B/C/V优先，00仅情景显示SPEED；调速不改变讲解采样率。11只预览当前集，焦点移动不切讲解，提交/同页重提交重播；情景提交同步阶段/音效并退出预警。

宣传VOI每次页面提交从头播一次，结束D、静音保图。AUTO有效讲解必须消费完最后样本且完整显示至少5秒；本版四段都长于5秒，应听完才翻页。缺/坏VOI静音N/E，按5秒回退。01/10/11不自动切页/阶段，讲解可继续且完成锁存；回00宣传重新等5秒，情景等完整终态帧。跨应用回目标第1页、关闭AUTO/预警。重扫按卡资源重新选启动应用；ERROR中00短KEY4重试、长KEY4切有资源的另一应用、00/11长KEY2重扫。

## 3. 板测顺序

| 项目 | 实际操作及应观察的结果 |
|---|---|
| 完整素材 | 两村分别四EDU前进/后退/回环，四段全部听完且一次，无旧测试音；最终HDMI文字、OSD与可视化无遮挡，电视距离可读 |
| 宣传AUTO | 00短KEY4，连续四页回环，句尾完整后才翻；停止AUTO只停后续推进；V=0仍能在相同进度完成并翻页 |
| 参数/身份 | 两应用各做00→01→10→11→00，B/C/V加减/饱和/恢复，公共参数保持；参数值对应画面/音量，非00不自动推进 |
| 预览 | 当前集四宫格、无效占位、焦点循环、提交及同页重播；情景提交同步阶段/音效、退出预警，不串图 |
| 情景双村 | 四阶段、终态完成后AUTO、居中红色缩放预警和警报、黑色放大文字、1X/2X/4X、FONT/TEXT |
| 双向切换 | 00长KEY4往返，持键不反复触发，松开不误开AUTO，首图/音频配对，无旧bank/旧EOF；重载中输入无串扰 |
| 负例 | 独立缺VOI2卡第2页N/静音；奇数VOI2卡E/静音，两者AUTO可恢复；短音卡VOI1为2秒测试音，要等满5秒 |
| 旧卡/缺资源 | old_scene为旧格式PIC/SND/FONT/TEXT，进入COMPAT，无EDU不伪称宣传；原PIC/BGM卡也保留测试，缺目标切换拒绝不坏当前图；缺EDU2、纯EDU无PIC分别验证 |
| 故障/重扫 | 用能重现的坏文件或读取失败记录现象、ERROR和恢复动作；恢复文件后重扫/复位，两应用正常；无需为造故障带电拔卡 |
| 复位 | 换卡后复位到新内容首帧，参数默认，启动应用符合卡资源；冷启动不依赖下载器 |

现成负例在 `diagnostics/output/publicity_m6_media01/`，参见内容包README。old_scene不包含BGM，仅验证旧命名/COMPAT；原有PIC/BGM卡另测。纯EDU、缺图在另一个新目录/独立卡准备，保留原包，不改正式整卡。

## 4. 连续运行≥40分钟与计时

将同一固定bit烧入Flash并执行工具校验，完全断电后上电独立运行。记录显示设备、卡型号/容量、供电、候选/内容版本、实际开始和结束时间。至少连续40分钟，期间做两模式往返和AUTO、参数/预览；记操作时间点及任何花屏、黑屏不恢复、静音、断句、卡死/重启。中途复位或掉电须如实说明，不能把多段累加成一次连续运行。未测项目保持待测。

使用手机录像或秒表并记录方法/精度。原始读数逐次填写，可重复测量以判断波动；不虚构次数或均值。

| 指标 | 起点 | 终点/补充 |
|---|---|---|
| Flash冷启动 | 完全断电后电源接通 | 首个完整稳定宣传画面；分别记录两村卡，声音开始另列 |
| 宣传→情景 | KEY4有效长按达到1秒阈值 | 首个完整稳定情景画面；也可录像记“开始按下→首帧”总时长，明确包含1秒持键，不能与阈值口径混称 |
| 情景→宣传 | 同上 | 首个完整稳定宣传画面；同样区分持键总时长与阈值后重载 |
| 换卡复位 | 新卡插稳后释放复位 | 新村首个完整稳定画面；两方向各记，人工换卡总耗时另列；若断电换卡，单列上电时间及复位条件 |

建议反馈格式：候选/内容版本/卡/电视；四页图文与四音完整听审结论；功能通过/未测/异常；连续开始__结束__共__分钟、期间操作__；每项时间“卡/方向、起止口径、方法、每次读数”；故障复现与恢复；是否确认本候选总体通过。发布确认在全部约定验收完成后单独给出。本次不推定发布授权。
