# 宣传模式 M2：双资源发现与四槽映射

日期：2026-10-16。输入提交 8a90155；原目录、feature/science-publicity-mode。
硬件输入仍为未获整机验收的 v0.17.0-m6-local.1，正式回退 v0.16.0。
个人问题记录、旧候选、TD 工程和本机状态不纳入修改。

## 范围与门槛

本阶段扩展 scanner → reader 实际模块链路，默认 SCAN_PUBLICITY=0。
生产 sd_card_bmp 不开启新参数；不提前实现 M3 应用入口、缓存失效或音频会话。
专项与旧接口回归、默认关闭逐周期比较、启用参数的独立 TD 综合通过后只提交。
无生产 bit，不建立 m2-local/board 标签，不继承旧板测结论。

## 接口约定

- EDU/VOI 独立四位 mask、128 位 clusters/sizes，槽 0 在低 32 位；reader 同时导出 PIC 原表。
- 新文件必须为大写短文件名且非目录/卷标/LFN；EDU 簇号合法且 size≥54，VOI 簇号合法且 size 非零偶数。首次满足基本元数据条件的目录项获槽；BMP 格式另由预检决定，不因后续同名文件替换已发现项。原 PIC/SND/BGM/FONT/TEXT 语义不变。
- 参数开启时扫描整个根目录直到零目录项或 FAT EOC；沿用链错误/遍历上限出口，不因旧文件齐全提前退出，不等待可选 VOI。
- scan_start 物理重扫并锁存 resource_publicity；map_start 仅在 ready、两扇区客户均空闲且已有成功扫描几何时接受，锁存目标并复用原两表重新预检，不重扫 FAT 目录。两请求同拍 scan_start 优先，忙时请求不排队。
- scan_done 沿用粘滞语义，接受新扫描/映射后清零；scan_error 是独立脉冲，须捕获，不能只在 scan_done 时采样。scan_found_slot 返回原槽号；mapped_valid 是通过 BMP 头预检的原槽掩码，scan_found_total 仅为数量；仍须完成且无错误才可加载。
- LOAD_BY_INDEX=1：PIC 保留 found_slot 压缩索引兼容；EDU 使用固定页号，缺 EDU2 不把 EDU3 压成第 2 页。无效索引/未完成映射拒绝并报告 load_error，无写请求；活动表在一次扫描/映射/加载期间保持。
- map_start 之前，上层必须完成视频、预取、预览、音频停止和缓存失效；本模块不管理四 bank 的归属。M3 才把请求接入生产。VOI 仅传递元数据，M4 才播放/判断自然结束。
- 启用参数时，取消物理扫描会复位扫描器并使元数据/映射失效，须重扫；取消预检保留原始表，但使当前映射不可加载，须重映射/重扫。取消文件保留映射并排空扇区；取消事务不报告 load_done/load_error。上层仍须等 ready 且两扇区客户空闲，不把模块内换表当作整机安全切应用。
- 所有新增输入均受默认关闭参数隔离；旧命名端口例化继续有效，无新增帧缓存。
