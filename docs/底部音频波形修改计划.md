# 底部音频波形（v0.20.0）

基线：147ef7d，继承 v0.19.0-s2-local.1 的生产 RTL/bit；回退为该固定候选。原目录分支 feature/bottom-audio-waveform。将圆环改为随实际音量变化的底部竖条波形，仅宣讲（宣传）模式显示，情景模式不显示。

## S1：实现及本地候选

- 保留实际 HDMI PCM 采样、96 点历史、快速上升/缓慢回落和原两拍视频延迟，将圆环改为透明背景紫色竖条。
- 640×480 底部安全区 x=248..631、y=464..477：96 条、间距4像素、宽2像素、最大14像素。已有宣讲页正文到 y=386、提示文字到 y=435、滚动字幕带 y=440..463，版本文字到 x=232/y=477；该区与现有全部文字不相交。参考图仅取竖条样式，不复制绿色背景或水印。静音柱高为0。
- 以已提交的像素域应用身份为准：仅 PUBLICITY_ENABLE 且 app=1、有效画面、非预览/菜单显示。情景 app=2 和旧图片 app=0 均旁路。
- 专项：实际 PCM 握手、正负/左右声道峰值、静音、回绕、帧快照；全画面逐像素、模式门控、字幕/版本文字区域和两拍时序；生产 top 最终 RGB/时序与关闭波形的参考比较。
- 相关回归及完整隔离 TD 构建，审阅资源、Setup/Hold、TNS、约束及实际告警。通过后固定 releases/v0.20.0/s1-local.1/demo.bit，提交并建立 v0.20.0-s1-local.1。没有合格 bit 不建 local 标签。只备份变化源码，不覆盖用户 TD 状态及个人记录，不改 TF 卡。

## S2：实板验收

用户烧录固定候选，检查宣讲四页大小音量/静音跳动、文字不遮挡、情景/预警无波形、双向模式切换/预览/菜单、音频和原功能。收到该候选明确通过反馈才记录 board 并推送阶段标签；整机/Flash 实测按实际记录。正式发布和合并 main 等用户确认。
