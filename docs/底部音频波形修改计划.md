# 底部音频波形（v0.20.0）

基线：147ef7d，继承 v0.19.0-s2-local.1 的生产 RTL/bit；回退为该固定候选。原目录分支 feature/bottom-audio-waveform。将圆环改为随实际音量变化的底部竖条波形，仅宣讲（宣传）模式显示，情景模式不显示。

## S1：实现及本地候选

- 保留实际 HDMI PCM 采样、快速上升/缓慢回落和原两拍视频延迟；生产使用80点历史，模块默认96点保持兼容，波形透明背景、紫色。
- 按用户追加要求删除宣讲四图上的资料来源及版本文字，清除原圆环占位区。波形覆盖整幅640像素宽图片底部：80条，每8像素一组、宽3像素，y=452..479、最大28像素，静音柱高0。来源记录保留在资料元数据中。
- 宣讲滚动字幕上移至y=424..439，半透明带y=420..443；图片提示上移至y=396、文字实际结束于y=416，与波形不相交。情景和旧图片字幕位置保持原值。生成四张新EDU BMP和实际PCM动图预览，保留历史素材及声音文件。
- 以已提交的像素域应用身份为准：仅 PUBLICITY_ENABLE 且 app=1、有效画面、非预览/菜单显示。情景 app=2 和旧图片 app=0 均旁路。
- 专项：实际 PCM 握手、正负/左右声道峰值、静音、回绕、帧快照；全画面逐像素、模式门控、字幕/图片文字区域和两拍时序；生产 top 最终 RGB/时序与关闭波形的参考比较。
- 相关回归及完整隔离 TD 构建，审阅资源、Setup/Hold、TNS、约束及实际告警。通过后固定 releases/v0.20.0/s1-local.1/demo.bit，提交并建立 v0.20.0-s1-local.1。没有合格 bit 不建 local 标签。只备份变化源码，不覆盖用户 TD 状态及个人记录，不改 TF 卡。
