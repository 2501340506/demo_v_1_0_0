## 板级操作

| 检查 | 操作及通过条件 | 实际结果 |
|---|---|---|
| 10轮断电重启 | 移除下载器连接，使用正常独立供电；每轮真正断电再上电，检查自动首图、编号及音频 | 待用户反馈 |
| 10轮运行中复位 | 每轮等待重新初始化完成，检查首图及音频恢复，再进行下一轮 | 待用户反馈 |
| AUTO连续30分钟 | 连续自动播放，无卡死、花屏或异常提示音 | 待用户反馈 |
| 100次有效翻图 | 在可接受操作的状态下翻图，检查画面、编号、提示音；快速连按遵循现有请求合并、有限挂起规则，不要求每次物理按键都产生新图 | 待用户反馈 |
| MAN/AUTO与切换 | 手动翻图、自动播放和来回切换正常，模式行为与S2一致 | 待用户反馈 |

可一次反馈实际完成的轮数、运行时长及异常；若仅回复整体通过，则只记录整体确认，不补造逐项测量记录。

## 问题与后续

发现问题时保留当前候选，记录发生于冷启动、复位、翻图或模式切换，以及画面、编号、音频表现和恢复方式。返回相关阶段定位；若生成新bit，重新完成受影响阶段及Flash验证。

已知全局时序未收敛：67个负端点，包括64个SDRAM接口和3个旧内存内部端点，后者最差−0.084ns；本次板测不替代静态时序结论。SD底层恢复、免复位热插拔仍不在本版范围。

用户明确确认S4通过后才建立S4 board标签并进入S5：沿用最终bit发布、更新文档、历史归档、合并和统一上传。当前不创建正式标签、不上传、不结项归档。
