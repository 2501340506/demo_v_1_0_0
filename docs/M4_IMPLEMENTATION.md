# M4 实施约定（2026-10-15）

输入为 M3 local.1（4aab2ba），在原目录 feature/mountain-escape-classroom 上开发。用户明确授权先做 M4 本地实现；M1/M3 板测、M2 目视仍待确认。回退为已板测 v0.16.0。本阶段目标 v0.17.0-m4-local.1，必须对应专项、回归、TD 正时序和固定 bit；不提前发布 board 或推送。

## 模式入口

核实 mode_key_control / switch_mode_control：{SW2,SW1}=00 图片、01/10 调节、11 预览，均已占用。因此保留四个模式，在 00 中以 KEY4 长按 1 秒切换场景子模式；短按 KEY4 在释放时切换 AUTO。场景子模式中 KEY2 短按下一阶段、KEY1 切科普/预警、KEY4 短按 1×/2×/4×；KEY4 长按或拨码离开 00 退出。KEY2 长按 2 秒仍重扫。切换模式期间持键不生成新操作。须扫描到四张有效图片并完成首图提交才允许进入；缺图卡保持原图片操作。FONT/TEXT 和预警边框、速度 OSD 属 M5。

## 控制与时钟

scenario_fsm 放在 SD 控制域，复用现有缓存、转场和错误处理。实际接收的 PCM 计数在像素域累加，以 Gray 计数同步到 SD 域，逐个消费，不直接同步 sample_valid 脉冲；帧事件用 toggle。每 1600/800/400 个样本 t 加一，239 饱和；无音频每两帧加一。hazard 参数经握手 CDC，再于首有效像素选择并保持整帧一致。

切阶段同时请求画面转场和 fade_mute。画面黑场提交须等音频增益归零或音频不运行；实际图片提交时更新 stage，转场结束后停止并排空旧音频、选择新槽并启动。首个新样本实际被接收后再淡入并运行时间轴。部分 SND 缺失按槽回退 BGM；两者皆无则使用帧计时。失败保留旧图、恢复音频，避免永远静音。

## 工具与验证

工具复用 make_audio_corpus.py 转换为 48kHz/单声道/有符号16位小端。示意村用明确标注的占位音效；不把占位音效当成旁白关键词同步已验收。保留旧图像输出和用户音频，生成到新目录。

验证覆盖模式手势、四阶段/预警/速度/饱和/无音频回退、fade 与背压、目录 SND/重复/缺失、真实 PCM 停止排空重启、生产接线、原 PCM/预览/完整系统回归，最后 TD 构建。所有失败输出保留，最终证据和资源实测另记。
