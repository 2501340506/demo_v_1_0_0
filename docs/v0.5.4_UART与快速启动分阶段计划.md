# v0.5.4 UART可观测性与首图快速显示

2026-10-07。基线为当前v0.5.3代码，分支`feature/v0.5.4-uart-fastboot`。

## 课程对照与范围

课程五项基础增强已经实现：严格BMP头校验、错误码及一次重试/有限跳过、可信BMP快跳、无进展超时、扇区和像素完整性检查。双缓冲显示确认、写取消、SD协议超时及手动重初始化也已存在。后续不重复重写。

当前缺少首图优先显示和UART事件日志。参数已部分集中，本轮仅集中新增参数。OSD、UART接收命令、Flash配置持久化、FAT、独立解码器、任意尺寸/负高度/缩放及PLL升频不纳入本轮。

原始连续扇区没有真实文件EOF，足量旧数据不能靠像素计数识别。快跳不能加速普通MP3。640×480/24位/正高度BMP每行无需填充。现有未完成事务超时停止并等待手动恢复，不强行重试。

课程fast_boot_gate基于四帧预加载，不能直接接入当前按需双缓冲；需要暂停扫描、加载、续扫。课程恢复模块默认两次重试，本项目继续一次。写完成/显示确认/取消等待先增加诊断，不凭假设增加自动复位。

## 实现契约

- UART：D12、LVCMOS33、115200、8N1，仅发送。控制域100MHz，868拍/位，按参数缩减计数位宽。新增顶层uart_tx，无新增诊断CDC。
- S1仅输出一次`BOOT v0.5.4-s1-local.1\r\n`，复位后重新输出。启动行不等待SD初始化，便于无卡诊断。
- S2输出启动、初始化、扫描、加载、重试、跳过、实际显示提交、错误及手动恢复事件；S4增加暂停/续扫。记录毫秒时间、图片、扇区、现有错误码、等待阶段及SD失败快照。使用事件快照队列，不反压播放；满队列记录丢失计数并提示，不逐扇区打印。
- S3在完整扇区边界暂停，保存续扫位置和累计数；新增暂停请求/确认及续扫接口，scan_done只代表全扫描完成。生产快速启动暂关闭。
- S4找到首候选后加载；成功提交即显示并续扫，失败重试一次后继续找后续候选。扫描前后SD读取串行、显示并行。扫描结束前忽略普通翻图和AUTO、不积累请求，长按重扫有效。后台扫描失败保留旧图并沿用手动恢复。分别记录首图提交和扫描完成时间。
