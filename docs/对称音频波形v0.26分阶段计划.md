# 对称音频波形（v0.26.0）

基线：v0.25.0（main 6a154aa），回退为 v0.25.0 正式 bit。功能分支 feature/symmetric-waveform。把宣讲模式底部的紫色单向竖条改成参考截图那种白色、中线上下对称、中间高两边低的波形，下面加一层蓝色渐变。情景模式和旧图片模式仍然不显示。

## 用户确认的取舍

- 位置：留在底部（方案 A），不动字幕、图片提示和宣讲 BMP 素材，SD 卡不用换。
- 柱数和疏密：由实现方按画面尺寸决定。
- 颜色：白色柱，和参考图一样；底下加蓝色渐变。

## 几何和数据

- 波形带 y=448..479（32 行），中线在 463/464 之间；字幕半透明带结束于 y=443，中间留 4 行空隙。
- 80 个槽位，每 8 px 一个，柱宽 4 px（槽内 x=2..5），沿用 pixel_x[9:3]，不用除法。
- 中间两根显示最新的历史值，向左右两边依次变旧，左右镜像。levels 模块只保留 40 条历史（BAR_COUNT=40），模块本身不改；overlay 读地址为 `slot<40 ? slot : 79-slot`。
- 包络：按离中心的距离 e=0..39 取 4/5 位权重 w=round(2+14·cos²(πe/80))，中心 16、最外侧 2；半高 `hh=((h·w)>>5)+1`，范围 1..15。
- 静音也画半高 1 的 2×2 小圆点；最外一行只点亮槽内 x=3..4，形成圆头。
- 蓝色渐变只在波形带内、只在门控打开时出现：k=(y-448)[4:2]（0..7），`out = rgb - rgb·k/16 + 蓝·k/16`，最底部混入约 44% 蓝色。柱子为不透明白色 ffffff。
- 门控、两拍视频延迟和模块接口都不变，top 只改 BAR_COUNT。
