## 合同与基线

用户已确认：PC 转换为 48kHz、16bit、有符号小端单声道 PCM，复制为 FAT32 根目录 BGM.PCM；独立循环背景音乐，切图不重启，左右同样本，音量 128/256。无音乐回退原图片琶音和提示音，有音乐不混提示音。仅音频的卡也可播放。

基线 main/ff1c138、v0.11.0；总回退 releases/v0.11.0/demo.bit。原目录 feature/pcm-background-audio 分支开发，保留现有两个 detached worktree、用户文件、best_result、旧候选。禁止批量删除。

首版不做 WAV 硬件解析、播放列表、播放控制、音量持久化、音频 OSD/可视化、转场音量联动；保持字幕、计时、按键、拨码、单 PLL 和 HDMI 封包链。

## 实现合同

- 扫描器保留 PIC1.BMP～PIC4.BMP 输出，新增 audio_found/audio_first_cluster/audio_file_size。不能找到四图即提前结束，需找到全部目标或正常目录结束。
- 图片与音频各有独立 FAT32 streamer，共享一个扇区 adapter 和 SD 驱动；支持碎片文件。请求必须明确接受并锁存地址，整个扇区响应只交给 owner。低水位音频优先，其他请求按扇区轮转。
- 扫描暂停音频；图片取消不清除音频事务；全局重扫停止两个客户端并收尾在途扇区，再同步清空音频。
- pcm_stream_player 写侧 100MHz、读侧 25MHz；4096×16bit BRAM，13bit 含回绕位指针，源域寄存格雷码后两级同步。同步 RAM 读后暂存，48kHz 累加器节拍及 8 项输出 FIFO，valid/ready 背压期间保持样本。
- 预填充 2048 样本，低水位 1024，补充目标 3072；数据扇区启动前保留 256 样本空间，FAT 读取也需仲裁但不占 PCM 空间。正常等待不触发物理读卡超时。
- 按文件长度读取，EOF 从首簇继续，不清循环缓冲，不播放扇区填充。短文件循环预填充；空文件和奇数长度不可播放。音频簇链访问上限单独覆盖 FAT32 文件大小。
- 欠载输出零并计数；读失败退出音乐、收尾后回退琶音，重扫重试。复位/重扫采用跨域停止清空握手，不能单侧清指针。
- 复用现有 HDMI 桥双输入及锁定选择逻辑，未选中琶音消费并丢弃以免溢出。切换在样本握手边界执行。
- Python 工具调用 FFmpeg 生成普通 PCM 文件并报告大小、样本数、时长，不写裸盘、不格式化。提供确定性测试样本及试听示例；源文件首尾听感不连续不做交叉淡化。
