# v0.15.0 亮度、对比度与总音量调节

基线及总回退：v0.14.0；分支 feature/brightness-contrast-volume；原目录开发。

## 操作合同

00/11维持图片/四宫格原操作；01默认亮度、10默认对比度，KEY4短按释放切换该画面参数与音量，长按一秒不切项。01/10的KEY1减、KEY2加，不连发、不重扫；100ms双键恢复当前项默认值。切模式取消未完成手势，释放后重新操作。

亮度/对比度0–255，默认128，步长16，饱和；总音量0–100%，默认100%，步长10%。参数跨切图、重扫和模式保留，复位清除，无持久化。01/10不强制退出AUTO，KEY4的MAN/AUTO操作仅在00。

01/10显示 B:128 C:128 V:100%，起点(8,32)，当前项黄色，其余白色，半透明底条；其他模式隐藏。

## 实现合同

复用按键消抖，参数整束请求/应答邮箱跨域，在VS下降沿帧事件锁存。

每通道 bright=min(255,(pixel*brightness)>>7)，result=clamp((((bright-128)*contrast)>>>7)+128,0,255)。四级流水：亮度乘法、限幅中心差、对比度乘法、偏移限幅。RGB/同步/坐标/相关控制同延迟。处理在video_delay后、转场和边框前；圆环及文字后叠加。空画面保持黑色，图片缓冲内补边一起调节。

音源mux后、HDMI桥前增加16位立体声valid/ready总音量级。Q16系数表0–65536；100%精确透传，0%精确静音。单拍弹性寄存；增益每个接收样本最多改变256，同步左右声道。静音继续消费样本。原琶音volume=128不改，圆环取最终音频。

不改变频率、引脚及放宽时序约束。不增加UART调参、持久化、音量放大或周期菜单。
