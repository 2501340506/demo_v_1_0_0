# v0.18.0 M5 双模式操作与板测

候选为 `v0.18.0-m5-local.1`；上板使用 [固定 bit](../releases/v0.18.0/m5-local.1/demo.bit)，不要取 TD 运行目录中的同名文件。M5 本地验证及构建数据见 [验证记录](../diagnostics/publicity_mode/M5_VALIDATION.md)，板上结果写入 [候选记录](../releases/v0.18.0/m5-local.1/BOARD_RESULT.md)。

开发回退：用户总体确认的 `v0.18.0-m4-board.1`，复用 [M4 bit](../releases/v0.18.0/m4-local.1/demo.bit)。正式回退仍是 [v0.16.0](../releases/v0.16.0/README.md)。M5 本地通过不代表板测、正式内容或 M6 整机验收已完成。

## 1. 准备与上电

1. 在 FAT32 卡根目录放置 [M1 包](../tools/publicity/geohazard_basics/generated/manifest.json) 的 `EDU1.BMP`–`EDU4.BMP`、`VOI1.PCM`–`VOI4.PCM`，以及一个完整情景包的 `PIC1.BMP`–`PIC4.BMP`、`SND1.PCM`–`SND4.PCM`、`FONT.BIN`、`TEXT.BIN`。可选 `BGM.PCM` 用于旧卡及缺 SND 回退。参考 [示意村](../tools/scenes/m6_demo/generated/manifest.json) 或 [山洪村](../tools/scenes/flood_village/generated/manifest.json)，两套 PIC/SND/FONT/TEXT 分别测试，不混用。
2. 使用大写 8.3 短文件名，文件直接放根目录。PCM 为 48kHz、单声道、s16le 裸数据，不添加 WAV 文件头。保留原卡和原素材，缺失/损坏测试使用独立卡或新目录。
3. 拨码按 `{SW2,SW1}` 读数设为 **00**，加载 bit，换卡后复位。完整 EDU 卡优先进入宣传第一页；没有完整 EDU 时回退 PIC 普通播放（COMPAT），不把旧图片叫作宣传内容。四 PIC 齐全时可进入情景；无目标资源时拒绝切换并保留当前应用。
4. M1 四 VOI 是 **2/6/8/10 秒测试音，无人声**。只能验证图音配对、播放一次、音量和停留，不能据此验收正式讲解或专业内容。正式配音、来源/内容审阅留 M6。

## 2. 完整按键矩阵

按键均低电平按下；短按后松开，长按达到阈值只触发一次。切换拨码或应用忙期间按住的键应先松开，再重新按下。

| 拨码/应用 | KEY1 | KEY2 | KEY4 |
|---|---|---|---|
| 00 宣传 | 上一页，首尾循环 | 短按下一页；长按 ≥2 秒重扫 | 短按 AUTO 开/关；长按 ≥1 秒切情景 |
| 00 情景 | 短按进入/退出预警；长按 ≥1 秒循环 1X/2X/4X | 短按下一阶段；长按 ≥2 秒重扫 | 短按 AUTO 开/关；长按 ≥1 秒回宣传或 COMPAT |
| 00 COMPAT | 上一张 | 短按下一张；长按 ≥2 秒重扫 | 短按原普通图片 AUTO；长按 ≥1 秒请求情景 |
| 01 任意应用 | 当前项减 | 当前项加 | 短按 B ↔ V；长按不切应用 |
| 10 任意应用 | 当前项减 | 当前项加 | 短按 C ↔ V；长按不切应用 |
| 11 任意应用 | 前一个焦点 | 短按后一个焦点；长按 ≥2 秒重扫 | 按下提交选中页为全屏；全屏后再次按下回预览；长按不切应用，整个按压只触发一次 |

01/10 中同时按 KEY1＋KEY2（既有 100ms 组合窗口内）恢复当前项默认值。B/C 范围 0–255、默认 128、步进 16、上下限饱和；V 范围 0–10、默认 10、步进 1，显示为 0–100%。参数在两应用间共同保留，复位恢复默认，无掉电保存。调整音量不改变音频采样率；情景速度只作用于推演，不给宣传讲解调速。

## 3. 显示与自动播放

- 01/10 显示 B/C/V 真实值，选中项黄色，其余白色；SPEED 不覆盖参数。00 情景显示 SPEED，00 宣传不显示 SPEED。
- 右上标识 `EDU` / `SCENE` / `COMPAT` 及页码 `1/4` 等。宣传状态栏另显示 `A`（AUTO）/`M`（手动），以及讲解状态 `W` 等待、`V` 播放、`D` 正常完成、`N` 缺失、`E` 错误。重载显示 BUSY，失败显示 ERROR/NO SET；以实际屏幕状态及资源为准。
- 宣传每次真正提交页面（含预览同页重提交）重新从头播放对应 VOI，单次结束后静音。仅移动预览焦点不切图片/讲解。
- 宣传 AUTO：当前页完整淡入、音频启动握手完成后最少停留五秒；有效 VOI 还必须实际消费最后源样本，留出后续安全帧后才翻页。缺失/错误使用静音加最短停留回退。2 秒测试音应等满下限；6/8/10 秒测试音应播完才翻页。
- 01/10/11 **不自动翻页或切阶段**；当前音频可继续播放，其完成状态保留。回 00 宣传重新等待五秒，情景需保留完整终态帧后才自动推进。进入另一应用关闭该应用 AUTO，回到目标第一页、非预警，公共参数及情景速度保留。
- 11 只显示当前资源集，未完成/无效槽显示占位。情景提交预览页同时更新图片、阶段和对应音频，推演从头开始；预警中提交普通阶段会退出预警。同页提交也重播。

## 4. 建议板测顺序

| 项目 | 操作与观察 | 结果记录 |
|---|---|---|
| 卡与候选 | 记录 bit 标签、卡包/村名、电视/显示器及连接方式 | 待测 |
| 宣传手动 | 四页前进、后退、首尾循环；音频与页号配对且一次；同页预览重播 | 待测 |
| AUTO | 四测试音分别检查五秒下限/长音播完；跨四页回环；停止 AUTO | 待测 |
| 参数 | 两应用分别在 01/10 选 B/C/V、加减、饱和、组合恢复；观察数值、实际画面和音量；音量零仍能 AUTO | 待测 |
| 身份保持 | 两应用各走 00→01→10→11→00；SPEED 优先级、图层、音频和公共参数保持 | 待测 |
| 非00门控 | 开 AUTO 后停留参数/预览至当前讲解或推演结束；保持当前页，回00重新等下限/终态帧 | 待测 |
| 当前集预览 | 两应用的四宫格内容、焦点环绕、提交与再进入；情景选中同步阶段音效、同页重播、预警退出 | 待测 |
| 情景两村 | 分别换示意村与山洪村卡并复位；四阶段、终态AUTO、预警红字/警报、1X/2X/4X、FONT/TEXT 中文 | 待测 |
| 连续切换 | 00长KEY4两方向切换，长按保持只切一次，松开不误开AUTO；重载中输入无串扰 | 待测 |
| 缺/坏VOI | 独立卡分别缺VOI2、VOI2奇数字节；第2页N/E、静音、AUTO能回退；其他页正常 | 待测 |
| 缺图/旧卡 | 缺EDU2、纯EDU无PIC、旧PIC/BGM卡：应用选择/拒绝提示合理，不显示旧bank，不死等 | 待测 |
| 故障恢复 | 用可重现的坏文件/读取失败记录ERROR，再恢复文件并重扫/复位；不要求带电拔卡 | 待测 |
| 重扫 | 00/11长KEY2重扫，首图重新显示；切换忙中按住KEY2应释放后重按才重扫 | 待测 |
| 复位/持续运行 | 复位参数默认；M6至少40分钟及冷启动/双向切换/换卡计时记录实际数据 | 待测 |

重扫会回到按卡资源重新选择的启动应用。ERROR 时可 00 短 KEY4 重试，或长 KEY4 请求有资源的另一应用，或 00/11 长 KEY2 物理重扫；目标不存在的拒绝不能损坏当前应用。换卡后复位，重扫不能替代物理 SD 热插拔恢复。

板测反馈请写具体候选、卡、操作、现象与是否可重复。有异常可复用 M4 bit 回退。未测项保持待测，用户总体确认只记录原话，不补次数/时长。M6另记录 ≥40 分钟、Flash完全断电到首完整画面、长按阈值到两方向首完整画面、换卡释放复位到首完整画面的原始读数。
