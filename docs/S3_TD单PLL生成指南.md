# S3：用 TD 6.2.1 生成指定单 PLL

本次只生成 PLL 文件，后续由 Codex 接入生产工程并验证。目标器件为 **EG4S20BG256**，输入为 **50 MHz**。

操作入口依据本机《TD_User_Guide_V6.2.pdf》第 3.1.2 节（PDF 第 44–49 页）。手册截图使用其他器件，输出数量和可选项以 EG4S20BG256 实际界面为准，不套用截图中的器件或参数。

## 1. 打开正确工程

1. 启动本机 TD 6.2.1。
2. 选择 **Project → Open Project…**，打开：

   `D:\My_Program\anlogic_program\demo_v_0_0\TD_project\demo.al`

3. 确认工程名 `demo`，器件 **EG4S20BG256**。不要停留在 `NoFamily::NoDevice` 状态；`File → Open` 不是打开工程的入口。

## 2. 新建 PLL

1. 选择 **Tools → IP Catalog**。
2. 在 **Primitive IP → Clock → PLL** 中双击 PLL。
3. 模块名称填写 **`sys_pll_s3`**，生成目录填写：

   `D:\My_Program\anlogic_program\demo_v_0_0\user_source\ip_source\s3_single_pll`

4. 使用 **Verilog** 输出，保留配置文件 `.ipc`。如目录尚不存在，可在路径选择窗口新建。

使用新名称与新目录，保留当前已验收的 `sys_pll.v` 和 `video_pll.v`。不要打开现有 `user_source/ip_source/pll.ipc` 改参数：该文件的器件是 PH1A90SBG484。

## 3. 设置输入、反馈和控制端口

界面文字可能略有区别，按下表含义设置：

|项目|设置|
|---|---|
|Input frequency / 输入频率|50 MHz|
|Feedback mode / 反馈模式|Normal|
|反馈时钟选择|CLKC0 / C0|
|反馈路径（如可选）|C0 外部反馈，最终生成代码应为 `CLKC0_EXT`|
|C0 Buffer / BUFG option|BUFG，用于反馈及 100 MHz 控制时钟|
|Reset / Enable reset|启用，生成 `reset` 输入|
|Lock / PLL lock|启用，生成 `locked` 输出|
|动态移相、动态配置|关闭|
|Standby / Power down|关闭|
|展频 / SSC（如有）|关闭|
|Bandwidth|Medium，模拟参数由 TD 计算|

这里的“外部反馈”是 **PLL 原语之外，经 FPGA 内部 BUFG 返回 PLL**，不需要增加开发板引脚或飞线。最终应形成 C0 → BUFG → `fbclk` 的反馈路径。

其余未涉及选项保留工具默认值。如有输出同步复位选项（Clock reset / Sync），保持关闭；本项目由顶层的五域复位同步器负责同步释放。

## 4. 设置五路输出

选用 **Clock frequency / 频率设置**，启用 C0–C4，逐路填写。频率单位选择 MHz，相位单位选择 deg，占空比填写 50%（若界面用比例，则填 0.5）。

|输出|频率|相位|占空比|用途|
|---|---:|---:|---:|---|
|C0 / CLKC0|100 MHz|0°|50%|SD／控制域、外部反馈|
|C1 / CLKC1|40 MHz|0°|50%|SDRAM 控制|
|C2 / CLKC2|40 MHz|**172.8°**|50%|SDRAM 移相采样|
|C3 / CLKC3|25 MHz|0°|50%|像素、现有音频逻辑|
|C4 / CLKC4|125 MHz|0°|50%|HDMI 串行|

C1 周期为 25 ns，C2 相对 C1 的目标移相为 `25 × 172.8 / 360 = 12 ns`。填写 **正 172.8°**；不要改为 180°、−172.8°或其他近似值。C3、C4 均填 0°，保持现有像素／串行的相位关系。

C1–C4 的额外 BUFG 选项先保留默认（现有包装仅显式给反馈输出加 BUFG），由后续实现和时序检查核对时钟资源。

不要手填旧工程中的 `GMC_GAIN`、`ICP_CURRENT`、`KVCO`、分频和粗细相位原语参数；这些交给当前器件的 TD 生成器计算。

## 5. 查看实际结果并生成

1. 填完全部输出后点击 **Show Details**（如有），核对工具算出的实际频率、相位和可实现状态。
2. 确认实际输出仍为 **100 / 40 / 40 / 25 / 125 MHz**，相位为 **0 / 0 / 172.8 / 0 / 0°**。工具显示更多小数位可以；若实际值发生舍入或替换，先停在此处。
3. 保存输出设置页和 Details 页截图，便于核对实际计算结果。
4. 点击 **Finish**，确认文件写入新目录。
5. 若询问是否加入当前工程，选 **否 / No**。本次交付生成文件，后续由 Codex 一起修改包装、顶层、工程清单和仿真，避免同时编入新旧 PLL。

**若 TD 报组合无法实现、相位不能输入、输出不足或无法生成：保留具体报错和设置截图，不修改既定频率／相位。** 这时还不进行 S3 集成。

## 6. 生成文件快速核对

用文本编辑器打开生成的 `.v`，只检查，不手动修参数：

- 文件头中的生成器版本对应本机 TD 6.2.1；内部完整版本号可能显示 `6.2.168116`。
- 时钟摘要应对应上表五路输出。
- 有 `refclk`、`reset`、五个时钟输出和一个锁定输出。端口具体名称以工具为准，后续可由包装适配。
- 使用当前 EG4 器件对应的 PLL 原语，预期为 `EG_PHY_PLL`。
- 反馈配置预期为 `.FEEDBK_MODE("NORMAL")` 和 `.FEEDBK_PATH("CLKC0_EXT")`，C0 经 BUFG 回到 `.fbclk(...)`。
- 复位启用，预期 `.PLLRST_ENA("ENABLE")`；锁定输出由 `.extlock(...)` 引出。

原语内部的 `CPHASE` / `FPHASE` 是编码参数，不等于界面上的角度数字，**不要把其中某个字段直接改成 172.8**。若生成结果与上述目标不同，把文件和截图交回核对即可。
