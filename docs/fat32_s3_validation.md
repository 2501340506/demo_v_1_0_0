# FAT32 S3 生产接入验证

状态：S3 本地完成，候选 v0.7.0-s3-local.1 待上板。固定 bit 为 releases/v0.7.0/s3-local.1/demo.bit。核心 42 场景、包装器 42 素材加 5 模式、最终全部 16 个验证入口通过。TD Setup +0.104 ns / Hold +0.014 ns；8890 LUT、5686 寄存器、4 BRAM、2 DSP。

## 行为与接口

生产 sd_card_bmp 改用 fat32_bmp_reader，启动后先扫描 FAT32 根目录，再按 PIC1～PIC4 顺序读取候选的第一个扇区做头预检。复用 bmp_header_check，24 位、当前分辨率、未压缩 BMP 且像素区不超过目录项大小才进入紧凑列表。缺图或坏头跳过，编号仍是播放列表位置。

图片表存 first_cluster 和 file_size；旧 SCAN_START_SECTOR/SCAN_MAX_SECTOR/SCAN_TARGET_COUNT 参数保留声明，但 FAT32 固定四个短文件名路径不使用这些旧扫描参数。SPI、SDRAM、显示提交、按键、轮播和音频模块没有替换。

ready 是初始化完成且空闲的电平；scan_done 保持至下次扫描/复位；load_done/load_error 是互斥单周期脉冲。加载等待 write_req/write_req_ack 后再启动文件流和解码器；文件流成功且解码器成功后才报告完成，控制器继续等待 SDRAM 完成及显示确认。

解码拒绝会禁止后续扇区请求、排空已开始的事务并复位流读取器。SD 失败/无进展超时映射外部错误 2，文件链损坏/短扇区映射 3，BMP 格式拒绝为 1；扫描失败进入现有停机恢复。内部 fat_error 保存 8 位原因，UART 包不扩展。地址字段记录最近实际请求的物理 LBA，LOAD 事件发生在首次文件请求前，可能仍显示上一次预检 LBA。

复位和长按重扫沿用取消写入、复位解析器、重新初始化 SD 的流程。恢复期间保留已显示帧；不提交残帧。UART 启动版本文本仍是历史版本，板测以固定 bit 路径识别候选。

## 验证覆盖

- 核心重新验证：布局/地址计算分拍后重跑全部 42 个确定性场景，字节、请求轨迹和像素逐项比较。
- 包装器：同一 42 个素材覆盖卷布局、活动 FAT、完整根目录、缺图、碎片、高 LBA、真实截断、提前 EOC、读失败和文件尾。另测不匹配尺寸、32 位格式、头内短长度、写握手超时、最后字节/结束同拍及连续字节。
- 生产回归：坏图重试/跳过、无进展超时、迟到完成、真实像素与异步帧读写、读写中重扫、无卡恢复、显示确认及音频事件；慢速介质模型记录复位代次，避免漏掉短复位脉冲。
- 系统：按键/轮播、缓冲交接、音频、HDMI 数据包/视频对齐、HDMI S6、启动及复位；BMP 解码器、SD 协议及扇区适配器、UART。

运行入口：diagnostics/fat32/run_core.ps1 与 diagnostics/fat32/run_s3.ps1。后者串行执行，不能与共用仿真库的单项脚本并行运行。
