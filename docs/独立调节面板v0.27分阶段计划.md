# 独立调节面板（v0.27.0）

基线：v0.26.0-s1-local.1（板测通过，已合入 main 39167c2）。功能分支 feature/adjust-panel。新增拨码开关 SW4（C5）：拨上即拉出一块调节面板，任何模式下都能调参数；拨下收回，按键恢复原来的模式行为。版式参考 Pixio OSD（左分类、右条目），颜色沿用项目 OSD：底色 102030、白字、高亮/数值条蓝 3c82f0。

## 用户确认的取舍

- 开关：新增 SW4，引脚 C5（LVCMOS33，无上拉，同 SW3）。
- 可调项：现有亮度/对比度/音量，加波形、功能开关、全部重置。
- 版式：简化两栏（LUT 余量小，不做斜角三栏和侧边条）。

## 交互

- SW4 拨上：面板 8 帧从右侧滑入；菜单（SW3）正在占用按键时等菜单退出再接管。拨下：滑出，按键归还。
- 光标态：KEY1/KEY2 上下移动条目（10 项循环），左栏高亮当前分类；KEY4 短按进入编辑。
- 编辑态：KEY1 减 / KEY2 加（开关项 KEY1=关、KEY2=开）；KEY4 短按返回；KEY1+KEY2 同按恢复当前项默认。
- 重置项：KEY4 长按 1 s 恢复全部默认。
- 面板打开时主按键通路看到“按键松开”，不会翻页、重扫、切 AUTO。
- s1-local.2 起：SW1/SW2 的 01、10 当作 00，原 mode 1/2 调节去掉，只能用 SW4 调。

|---|---|---|---|

| AUDIO | VOLUME | 0..20（0..200%）/ 10 | pcm_master_volume，超过 100% 削顶 |

| | HEIGHT | 0..3 / 3 | 柱高 ×(n+1)/4，3 = v0.26 |

| | SCROLL | ON/OFF / ON | 旧图片滚动字幕；情景底部字幕条；宣讲旁白字幕；含半透明带 |

| RESET | HOLD K4 | 动作 | 全部恢复默认 |

## 实现

- `sd_card_bmp`：SW4 去抖后 `panel_owns`，独立 `adjust_panel_keys`（自带去抖+手势），与原手势 OR 后送出；主通路和菜单的按键在面板占用时强制为松开。
- `adjust_key_gestures`：加 `hold_select`（KEY4 按住满 1 s 当拍发出）。
- `media_adjust_control`：panel=1 时按条目/焦点改参数；新增端口都在原端口之后。
- `media_adjust_cdc`：宽度参数化，24 → 38 位，新位放高位，原切片不变。
- `adjust_panel_overlay`（adjust_osd_overlay.v）：336×200，x=296、y=120；两级寄存器渲染（面板整体右移 2 px，视频延迟不变），叠在全部 OSD 之上、菜单之下；数字复用参数 OSD 的 BCD。
- `audio_ring_overlay`：末尾加 `wash_level` 端口。

## S2 板测反馈（s1-local.1）及修复

- 反馈：OSD、SCROLL 两项没效果；要求去掉 SW1/SW2 的 01/10 调节模式；音量最大 200%。
- 原因：两个开关只接到旧图片模式的状态行和滚动字幕，情景（`scene_text_overlay`）和宣讲旁白（`publicity_subtitle_overlay`）没接。
- 修复见 [s1-local.2](../releases/v0.27.0/s1-local.2/README.md)：情景面板/图例/字幕分别受 OSD/SCROLL 控制，宣讲旁白受 SCROLL 控制；01/10 映射为 00；音量 21 档、削顶；邮箱 39 位。新增 `diagnostics/adjust_panel/run_scene_gates.ps1`。

## s1-local.3：场景速度、中文面板

- 用户要求：场景播放速度放进面板；面板顶部去掉 SW4、标题居中，底部 K1↑ K2↓，英文改中文，字模用占 LUT 少的方式存。
- 速度：新分类“场景”，条目“速度”（1X/2X/4X）。速度仍归 `scenario_fsm`，面板经 `scene_speed_request` 闭环发原有换档键。
- 字模：61 字宋体 16×16 放块 RAM（`panel_font_rom.v`，生成脚本 `tools/make_panel_font.py`），文字 8 px 半格排版。见 [s1-local.3](../releases/v0.27.0/s1-local.3/README.md)。

## s1-local.4：去掉场景左上角 SPEED

- 用户要求删除场景模式左上角的 SPEED 字样。`adjust_osd_overlay` 不再画任何东西，只给面板提供十进制数字。见 [s1-local.4](../releases/v0.27.0/s1-local.4/README.md)。
