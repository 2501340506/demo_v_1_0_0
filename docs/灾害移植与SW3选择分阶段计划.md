2026-10-18，用户授权实施。原目录分支 `feature/mountain-disaster-selector`，基线 `7e3ac02`。先记录计划，再修改 RTL。保护个人记录、TD 工程运行状态、best_result、旧 worktree 及 G:\ 卡内容。

- 计划标签 `v0.19.0-plan.1`；两阶段分别使用 `v0.19.0-s1-local.N`、`v0.19.0-s2-local.N`。不移动历史标签，未获用户板测确认不建立 board 标签，不发布正式版或合并 main。
- 基线固定 bit 为 `releases/v0.18.0/uart-s1-local.1/demo.bit`：14092 LUT、9530 寄存器、46 BRAM9k、2 BRAM32k、13 DSP，Setup +0.040ns、Hold +0.019ns，两项 TNS 为 0。该候选板测待验收；已确认的硬件回退为 M5 board.1，正式回退 v0.16.0。
- 在 diagnostics/output 中隔离构建；候选只冻结实际修改源码、bit、必要配置和报告。逐字节比较，不生成哈希。同步 GitHub 当前功能分支和本任务标签。

## S1：选择性移植

保留当前 32 位像素通路、双应用、字幕、音频及 scenario_fsm 的速度、预警和音画联动。新增独立命名的四类灾害图层、BMP 头类型识别；旧编码继续走原图层，普通图及缩略图保持原色。RGB、同步、坐标和身份统一对齐，类型仅随成功加载及实际显示提交生效，失败保持当前图层。移植工具和素材独立命名，不覆盖现有同名脚本或场景。临时时间源只用于专项仿真。UART 两项默认关闭，数码管 SD 调试页保留。

逐像素检查四类各阶段、旧编码、流水对齐和缩略图旁路，运行双应用等受影响回归，完整 TD 构建并审阅实际资源和时序后固定独立候选，再进入 S2。

## S2：SW3 四宫格菜单

SW3=C6，拨上为 1；KEY3 仍复位。扫描 FAT32 实际长目录名及跨簇目录，不依赖短名或顺序。菜单行优先顺序：滑坡 landslide_village、泥石流 debris_village、山洪 flood_village、地震 quake_village，均在“情景模式”下，以 PIC1 为首图。确认读取该目录 PIC1–4，按原规则读取可选音频和 FONT/TEXT，清除上一集标记。宣传支持“宣讲模式”；各应用完整根目录资源优先。缺损或名称/类型不符的场景灰色占位且禁止确认，其他场景仍可选。

菜单外框、2×2 分区、黄色焦点，每格完整等比例 256×192 图，下方固定中文字模居中。KEY1 前一个、KEY2 后一个、KEY4 确认，按行循环，长按只执行菜单动作。SW3 上升沿或上电为 1 从任意应用/页请求，忙中安全结束事务后接管；期间停止音频和自动推进。确认从阶段一、非预警、AUTO 关闭开始，保留公共参数与速度；暂强制全屏，下一次 SW1/SW2 实际变化恢复原映射。SW3 保持 1 不重开，下一次 0→1 重开。未确认拨回 0 恢复原应用/页、参数、速度、AUTO，当前讲解/推演从头开始。模式交接必须释放按键再按。

SDRAM 菜单四槽从 1536000 开始，各 49152 字，不覆盖原全屏及预览。复用 SD/解码服务，新增缩略图写模式。显示描述符包含菜单、焦点、有效槽和身份，经现有握手于帧边界提交。

测试中文长名、目录乱序/跨簇、缺/坏图/读取失败、根目录旧卡，检查四首图、标签、循环、确认/取消、上电、忙中切换、按键隔离、缓存隔离。再完整 TD 构建，资源不超限、无 ERROR、Setup/Hold >0、两项 TNS=0；超限优先优化新增图层常数乘法及缓存控制，不移除现有功能。
