# v0.29.0 场景底图与泥石流特效 分阶段计划

基线：v0.28.0（`e6e68e5`，main）。分支：`feature/scene-art-debris-v029`。回退：v0.28.0 bit 加原卡 `情景模式/`。

## 范围

- 地震 PIC3：底图上的房屋重绘为倒塌、损坏，加低空灰尘（静态，画在底图里）。其余区域保持原图像素。
- 泥石流掩膜：
  - PIC3/PIC4 沟床从溪水出雾处开始，并贴合溪水；
  - 冲过石桥以后，扇区下方整片铺到底边；
  - PIC2 泥流冲过公路和小桥，流出画面；
  - PIC1 物源区黄框贴合沟床。
- 泥石流特效（`hazard_v3.slurry` / `hazard_layer_v3.v`）：
  - 半透明泥色加浪头带的效果（和山洪太像）换成不透明的浑浊泥浆：值噪声向下游流动，噪声峰值处是石块，加稀疏的泥粒和碎屑，龙头是深色；
  - 发生阶段：8 px 格，每帧 2 px；灾后阶段：4 px 格，每帧 1 px。
  - RTL 复用这两个阶段空闲的噪声单元和现有调色板项，不新增 ROM。
- 不动：其他灾害的效果、文字、配音、FONT/TEXT/SND。

## 阶段

S1（唯一阶段）：源码、仿真、TD 构建 → `v0.29.0-s1-local.N` → 上板 → `v0.29.0-s1-board.N` → 正式版 `v0.29.0`。
