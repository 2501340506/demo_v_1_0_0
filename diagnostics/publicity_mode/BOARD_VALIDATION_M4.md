# 宣传模式 M4 板测步骤

候选：`v0.18.0-m4-local.1`。只烧录固定交付 `releases/v0.18.0/m4-local.1/demo.bit`，不要使用诊断构建目录中的可覆盖文件。当前文件是待执行清单，不表示板测通过。

## 卡与基线

- 开发回退为已获用户总体确认的 M3 `v0.18.0-m3-board.1`，复用 [M3 bit](../../releases/v0.18.0/m3-local.1/demo.bit)。正式回退为 v0.16.0。换卡后复位。
- 双模式卡在 FAT32 根目录放 [M1 宣传包](../../tools/publicity/geohazard_basics/generated/manifest.json) 的 EDU1–4.BMP、VOI1–4.PCM，以及原场景包 PIC/SND/FONT/TEXT。文件用大写8.3短名，禁止给裸PCM加WAV头。
- M1 四 VOI 是 2/6/8/10 秒测试音，无人声；只能验收播放、配对、单次和停留，不能写成正式配音/旁白听审已通过。正式配音及专业内容审阅仍属后续任务。
- 准备独立测试卡/新目录：完整双模式、缺 VOI2、VOI2 奇数字节、旧 PIC/BGM 卡。保留原卡及素材。读卡失败可按实际可重现方式记录，不要求带电拔卡。

## 操作与观察

| 检查 | 步骤与应见结果 |
|---|---|
| 四页单次 | 00 启动宣传第1页，AUTO关闭；每页对应音频播一次后静音、画面保留。KEY2短按下一张、KEY1上一张，均从头播放目标页，不串前页句尾 |
| AUTO | KEY4短按开/关；短音页完整淡入后至少约5秒才翻；6/8/10秒页等声音正常结束才翻。4→1回环。关闭AUTO不打断当前声音，只停止后续自动翻页 |
| 手动优先 | AUTO快到期时按上一/下一张，只处理当前有效手动请求；长按KEY4一秒只切应用，不额外切AUTO |
| 零音量 | 01/10中KEY4切V，降到0；音频会话仍推进。回00重新等至少5秒，已播完页可翻。提高音量后音高正常、无旧句尾重放 |
| 参数保持 | 音频播放中转01/10：画面应用保持、音频继续，AUTO不翻。等结束再回00，重新等待约5秒；B/C/V保持。场景速度手势不改变宣传轮播 |
| 预览 | 11移动焦点不换讲解；KEY4提交焦点后才播放该页，提交同一页也从头重播。回00后重新计最短停留 |
| 缺/错讲解 | 缺VOI2第2页静音、N；奇数VOI2为红色E，均允许AUTO按约5秒回退；不借用BGM或警报，不能显示正常完成D |
| 双模式往返 | 00 KEY4长按一秒进情景，KEY1短预警/长调速、KEY2下一阶段和情景AUTO保持；预警警报后切回宣传，从第1页重播、AUTO关闭。B/C/V和情景速度保留，无旧EOF触发跳页 |
| 重扫/旧卡 | KEY2长按两秒重扫，旧会话不误报新页完成。旧PIC/BGM卡保持COMPAT循环音频及旧AUTO，四PIC齐全可进情景；缺EDU不冒充宣传 |
| 句尾和连续操作 | 留意每页末音完整、无额外循环、无持续杂音；连续前后翻、参数往返和切应用后无卡死。硬件不直接注入FIFO反压，该项的精确保证取专项仿真，板上只记实际听见/看见的结果 |

00宣传标题末尾：A/M为自动/手动，V播放、D正常完成、N无讲解、E错误（红色）、W等待。完整OSD整理仍属M5。300帧tick约为五秒，实际秒数受板上帧率影响；从完整淡入后计，音频握手等待可使停留更长。

请在固定候选 `BOARD_RESULT.md` 回填真实现象、次数、卡内容、电视和烧录方式；未测写未测。M4功能确认不自动构成M6 ≥40分钟、Flash冷启动/换卡计时或正式内容验收。
