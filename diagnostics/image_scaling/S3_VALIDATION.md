# S3 四宫格生产接入验证

基线为已板测通过的 `v0.14.0-s2-local.1`，分支 `feature/image-scaling-thumbnails`。S3 尚未板测。

## 实现与时序调整

加载时双写：原四个 640×480 bank 保留，320×240 紧凑缩略图使用字地址 1228800–1535999。两套 FIFO 以 64 字突发仲裁，两者排空后才提交缓存完成。BMP 底向上输入取偶数列、奇数流行，再由 writer 翻转，对应屏幕偶数坐标。

预览描述使用独立请求/应答，包含预览标志、焦点、图片数、完成位图与实际 bank 映射；reader 在帧重载时锁存，按实际读请求推进地址。预览状态不产生图片提交事件，重扫等待预览退出应答。

未改时序约束。为切断报告中的长路径，字幕校验等价优化、数码管源域下降沿暂存、扫描响应整束流水、FIFO 可写余量寄存、FAT 校验分阶段、BMP 范围模式按已解码行计数结束。缩放输出新增两像素缓冲，隔离下游背压，done 等待该缓冲排空。音频低水位请求寄存一拍。
