# S2 全屏缩放验证

本阶段生产启用多尺寸等比最近邻，输出 640×480；11 模式四宫格属于 S3，尚未接入。基线与回退 v0.13.0。最终构建 scale_s2_attempt5，系统仿真仍在运行，尚未固定候选或得到板测结果。

## 完整物理实现

scale_s2_attempt5 的最终布线报告：Setup +0.107ns，Hold +0.035ns，STA 覆盖率 99.97%。资源：15716 LUT、8260 寄存器、41 BRAM9K、10 DSP、1 PLL。所有资源在器件容量内。

约束未改。时序审计分类及数量与 v0.13.0 的 s2-local.2 一致：无缺失时钟、无组合环、无无效约束、无没有对应路径的约束；保留工具 dummy node 提示、9 个未设输入延迟端口、16 个未设输出延迟端口及 sd_miso 既有输入延迟提示。PLL 核查无缺失约束或频率不匹配。SDRAM 时钟 40MHz，SD 100MHz，视频 25MHz，HDMI 串化 125MHz。

## 失败历史与修正

- system1 显示欠载：缩放行重放提高瞬时写入密度，新增读 FIFO 半满以下的补充优先信号，阻止新的写突发，保持已发突发与刷新流程。
- mixed1/2 超时，mixed3/4 在大图黑边后存储超时。最初怀疑 FIFO 满计数回绕；448 字背压仍未解决，不能把回绕写为根因。probe1 实测 FIFO=64、writer CHECK、写计数 38336、帧长 307200，且无读/刷新阻塞；旧条件 FIFO>64 导致等待。修正为 >=64，保留 448 字背压余量后 mixed5/probe2 通过。
- attempt1 Setup -0.161ns / Hold -1.184ns；attempt2 +0.090ns / -0.028ns；attempt3 -0.527ns / +0.036ns；attempt4 -0.279ns / +0.022ns。均不可交付，attempt4 也不含最终 writer 修正。解码计数位宽/行长度预计算、FAT 下一簇检查及扫描候选判断流水后，最终 attempt5 通过。
- system2/3 主动结束，换为最终源码 system4；未完成运行不能计为通过。
- 旧 stability 入口缺少现有模块依赖，改用维护中的 four_bank 回归入口。hdmi1 行为通过但新增端口警告使 runner 失败，补齐测试连接后最终音频专项零警告通过。
