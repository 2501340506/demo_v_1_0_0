# M5 local.1 板测步骤（待用户验收）

下载本目录固定 `demo.bit`，对应 `v0.17.0-m5-local.1`。保留原卡；另备 FAT32 卡，将 `board_samples` 内 PIC1–4.BMP、SND1–4.PCM、FONT.BIN、TEXT.BIN 共十个文件放入根目录。换卡后复位。M4 已获总体反馈“暂无大问题”，本候选仍需重新板测；整机正式回退为 `releases/v0.16.0/demo.bit`，也可对比已验收 M4 bit。

1. 拨码 `{SW2,SW1}=00`，等待四图就绪后长按 KEY4 至少 1 秒进入场景。检查村名“示意村”、四阶段标题与字幕，KEY2 短按依次推进并回到阶段一；每次等转场完成再按。数码管对应显示 1、2、3、4。
2. 字幕依次为“持续降雨注意预警”“发现裂缝远离坡体”“滑坡山洪立即避险”“沿路线向高地撤离”。科普字幕从画面右侧滚入；检查中文方向、缺笔、半字、行错位和与底图的稳定性。标题位于 y=64，村名 y=88，字幕 y=444。
3. KEY4 短按依次改变速度，参数条显示 SPEED 1X/2X/4X，推演约 8/4/2 秒达到终点，PCM 保持原音高。检查原亮度、对比度、总音量参数仍可用。
4. KEY1 短按进入预警：第四阶段、SND4 循环、数码管 A、四周 8px 红框闪烁、固定文案“立即撤离前往高地!”。再次按 KEY1 回到阶段一科普，红框消失、正常字幕恢复。检查切换无残字或同步抖动。
5. KEY4 长按退出；拨码进入 01/10 调节、11 预览再返回。检查缩略图、手动切图、AUTO、转场、音频、UART 字幕与中文均正常。KEY2 长按至少 2 秒重扫后应可重新进入场景，资源与音频重新加载。
6. 另备缺 FONT/TEXT 的原 24bpp+BGM 卡，复位后验证原有功能和中文 case 回退。另测只有 FONT、只有 TEXT、两者齐全：只有 FONT 时旧中文可用，只有 TEXT 时回退旧文案；只有二者都有效才出现卡上场景文案。不要覆盖唯一的原卡素材。
7. 在测试副本移走 SND3、保留 BGM，确认第三阶段回退 BGM；全部 SND/BGM 缺失时场景仍按帧推进。检查预警和速度显示不依赖音频文件。

四段声音为 M4 原占位音效，不能据此认定旁白关键词已同步。请反馈候选版本、卡组合、实际通过项和异常；不预填运行时长或冷启动结果。M6 的第二张卡、40 分钟稳定性、Flash 与冷启动计时另行执行。
