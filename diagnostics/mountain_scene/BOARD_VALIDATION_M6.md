# M6 整机板测（待用户实测）

仅使用候选目录固定 demo.bit，记录候选标签。回退 releases/v0.16.0/demo.bit。准备两张 FAT32 卡，分别把 cards/demo_village 和 cards/flood_village 中十个媒体文件放到卡根目录；manifest.json 是说明文件，可不拷入。切勿把两村同名文件混放。换卡后复位，不需要重新综合或烧写另一份逻辑。两村均为虚构教学图；SND1–3 为节拍音效，SND4 为警报音，不是旁白。

## 按键与修复验收

拨码顺序为 {SW2,SW1}。00 为普通/场景；01/10 为原参数调节；11 为原缩略图。

| 操作 | 普通模式 | 场景模式 |
|---|---|---|
| KEY4 短按 | AUTO 开关 | AUTO 开关（恢复） |
| KEY4 长按 ≥1 秒 | 四图就绪后进入场景 | 退出场景 |
| KEY1 短按 | 上一张 | 科普/预警切换（松手触发） |
| KEY1 长按 ≥1 秒 | 原功能 | 速度 1X→2X→4X→1X；松手不切预警 |
| KEY2 短按 | 下一张 | 下一阶段；预警下不推进 |
| KEY2 长按 ≥2 秒 | 重扫 | 退出场景后重扫 |

进入场景继承普通模式 AUTO 开关。场景 AUTO 等 t 到终点且终态帧显示后才推进，四阶段循环；关闭 AUTO 则停在当前阶段终态，手动下一阶段仍可用。预警保持第四阶段与警报，不自动退出。退出场景后普通 AUTO 关闭，KEY4 短按可重新开启。速度影响动画计时，PCM 音高与播放速率保持原样。

1. 两张卡分别复位并进入场景：确认村名、底图、四阶段标题/字幕/路线/避险点均与卡对应。“山洪村”避险点在左侧高地，路线向西过桥；“示意村”在右上高地。
2. 检查标题 y=64、村名 y=112、字幕 y=416：黑色 32px 中文，字幕完整滚入，无乱码/缺笔/残字。分别走四阶段，数码管显示 1–4。
3. KEY4 短按开 AUTO：动画未完成时不得切阶段；每阶段终态可见后才转场；至少观察两个四阶段循环。中途关 AUTO、手动 KEY2 下一阶段、再开 AUTO 均正常。SPEED 不应被 KEY4 短按改变。
4. 长按 KEY1 调速，SPEED 显示 1X/2X/4X，动画约 8/4/2 秒到终点；松开不进入预警。短按 KEY1：预警语“立即撤往高地!”在画面中心、红色、含感叹号，32/64px 周期交替，8px 红框闪烁，SND4 警报连续循环，数码管 A。即使 AUTO 开启也不离开预警；短按 KEY1 返回科普第一阶段。
5. 音画转场无明显爆音/断帧；退出/进入、调节模式和预览来回切换、KEY2 长按重扫后均恢复，保持原音量/亮度/对比度调节功能。

## 稳定性与计时

- 同一候选写入 Flash，断开下载器运行 ≥40 分钟，记录开始/结束时间及实际分钟；期间覆盖 AUTO 循环、手动阶段、预警警报、两卡和旧功能，说明每卡/每模式的实际覆盖时长。换卡/复位会中断连续运行，应另做完整 ≥40 分钟连续段。
- 完全断电再上电，用录像/秒表从通电时刻到首个完整稳定画面计时（不是按复位，也不是 JTAG 下载后启动）；分别记录两张卡原始秒数、卡型号/容量和计时方法。建议每卡三次，实际做几次就填几次。
- 换卡耗时分开测：A→B、B→A，从“新卡插稳后释放复位”到新村首个完整画面。若测“开始拔旧卡”到新帧，另列总耗时，包含人工操作，不混作加载时延。记录具体计时起止点。
- Flash ≥40 分钟、完全断电冷启动及换卡计时为不同验收项，不能互相替代。
