# v0.13.0 S2 local.1：圆形音频可视化

状态：本地验证候选，尚未上板确认，未正式发布。基线 v0.12.0。

## 下载与效果

使用本目录 `demo.bit`（654,068 字节）。屏幕右侧偏下出现黑色圆环和96根白色圆头柱，圆心(520,310)，中间透出原图片。随实际HDMI音频跳动，静音逐渐回落；不会覆盖顶部状态、时间和底部字幕。

TF卡音乐格式沿用BGM.PCM（48kHz、16bit、小端、单声道）；无音乐文件时原琶音和提示音也驱动圆环。有有效图片时显示；无有效图片不显示。编译参数 `AUDIO_VIS_ENABLE=0` 可关闭，仍保留两拍视频延迟；独立于OSD开关。

预览见 `preview/music.gif` 和 `preview/music.png`：实际RTL仿真生成，使用本地音乐片段和与生产相同的幅度缩放，背景是测试图。不是板级截图。静音、弱音、强音、不同柱高参考见ring_0～ring_3.png。

## 本地验证

- 音频幅度/握手/静音/帧快照及几何像素专项通过；1,228,800个像素与独立几何参考一致。
- 所有OSD与圆环串接验证通过；1,695,744个区域外像素一致。生产HDMI桥9,279个音频样本逐项一致；21项回归和3项音频模块测试通过。
- 完整系统回归结果和模型边界见 `VALIDATION.md`；它覆盖既有图片/转场/PCM/OSD系统，新增圆环以专项串接测试验证。
- TD完整构建：Setup +0.101ns，Hold +0.004ns，覆盖率99.97%；14,858 LUT、7,928寄存器、34 BRAM9K、4 DSP、1 PLL，未放宽时序约束。
- ROM有综合器无驱动提示，但已推断为BRAM且综合后109,443个像素比对通过。厂商门级模型可选端口/类型警告及既有SDRAM ECO、局部时钟提示如实保留，详见验证记录。

## 上板验收

先下载本目录bit，观察以下实际使用场景：

1. 正常播放BGM时圆环随声音跳动，声音无断续；安静段柱条回落。
2. 手动/自动切图及转场正常，音乐不断，顶部状态/时间/底部字幕不偏移。
3. 移走BGM.PCM后重扫，图片琶音和提示音正常，圆环仍能响应；复位/重扫后正常恢复。

反馈时注明 `v0.13.0-s2-local.1` 和实际结果。确认S2通过后再对同一候选进行S3：持续播放20分钟、Flash烧录、完全断电再上电。反馈未覆盖的项目保持“未验证”。

## 回退与构建

回退使用 `releases/v0.12.0/demo.bit`；不需要改变TF卡格式。不要使用TD运行目录中会被覆盖的bit作为固定验收对象。

源代码仍在原项目目录功能分支 `feature/circular-audio-visualizer`。`sources/` 只备份相对v0.12.0变化的5个生产输入，其余由基线标签引用；`MANIFEST.md`列出工程输入与逐字节比较范围。几何ROM由 `tools/generate_audio_ring.py` 生成，初始化内容直接写入Verilog，不依赖运行目录下的外部ROM文件。
