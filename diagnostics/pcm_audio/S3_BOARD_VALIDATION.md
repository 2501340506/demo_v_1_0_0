# S3 上板验收

使用固定候选 `releases/v0.12.0/s3-local.1/demo.bit`。本地仿真和 TD 通过后才建立此候选；本记录不表示已上板。

## 准备音频

TF 卡沿用当前 FAT32 格式和 PIC1.BMP～PIC4.BMP。将音频转成 **48kHz、16bit、有符号小端、单声道**，以 **BGM.PCM** 放入根目录。

```powershell
python tools/make_audio_corpus.py "D:\music\input.mp3" "D:\music\BGM.PCM"
```

工具需要本机 FFmpeg；只写普通输出文件。将输出复制到 TF 卡即可。快速试听可使用 `releases/v0.12.0/s2-modules/samples/BGM.PCM`，这是 3 秒 440Hz 音调，配套 WAV 可在 PC 先试听。判断循环衔接建议再用一首较长的音乐。

## 本阶段检查

1. 上电后扫描、图片显示及音乐自动开始，左右声道相同，速度与音调正确。
2. 音乐播放时使用原按键手动前后切图、KEY4 开关 AUTO；两种转场、字幕更新、计时与四 bank 缓存行为正常，音乐不重启，也不混入切图提示音。
3. 听完至少一个完整文件循环，确认尾部没有被截掉；源文件首尾本身不连续造成的跳变不属于交叉淡化功能。
4. 长按 KEY2 重扫，确认停止旧音乐后重新扫描并自动播放。此处允许停止并重新预填充；普通切图应保持连续。
5. 移走 BGM.PCM 后重扫，确认恢复原图片琶音及提示音；仅保留 BGM.PCM 的卡也应自动播放。重扫无图片时保留上一张画面是原有行为。

反馈实际使用的候选、是否听到正确音乐、切图/循环/重扫结果及遇到的问题即可。S3 确认后再进入 S4：复用同一 bit 做持续播放（建议 20 分钟）、Flash 和完全断电冷启动，记录实际时长和结果。

阶段回退：`releases/v0.12.0/s1-local.1/demo.bit`（已验收，不支持 BGM.PCM）。总回退：`releases/v0.11.0/demo.bit`。
