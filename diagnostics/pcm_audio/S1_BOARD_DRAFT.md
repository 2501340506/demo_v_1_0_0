# S1 上板验收

本阶段只替换图片读卡入口的共享扇区服务，背景音乐尚未接入。TF 卡沿用 v0.11.0 的 FAT32 图片卡，不需要准备 BGM.PCM。

上板只能使用最终固定的 `releases/v0.12.0/s1-local.N/demo.bit`，不要使用会被覆盖的构建目录文件。总回退为 `releases/v0.11.0/demo.bit`。

请验证：

1. 上电能找到并显示原有图片，显示及原琶音正常。
2. 手动前后切图、连续切图、AUTO 切图正常；手动淡出淡入、AUTO 黑底水平揭示保持原行为。
3. 重扫后能恢复图片播放，没有卡在读卡或黑场。
4. 当前“胆子肥嘟嘟的 FPGA ”字幕、UART 字幕修改、右上角计时正常；提示音只随实际图片提交触发。

反馈候选编号及实际结果；如有异常，提供当时操作和可见现象。S1 不要求把未执行的 Flash/长稳项目记为通过。确认后记录 board 标签并推送，再进入 S2。
