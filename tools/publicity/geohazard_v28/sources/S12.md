# S12：西藏吉隆"8·26"泥石流（2026，警示案例）
- 出处：新华网、新民网数据新闻、维基百科条目（汇总官方通报）。
- https://www.xinmin.cn/2026jilong826/jilong-826.html ；https://zh.wikipedia.org/wiki/2026年中尼边境泥石流灾害
- 核对日期：2026-10-23。
- 采用事实：尼泊尔境内冰川断裂引发冰岩崩，转为泥石流，约 6–7 分钟冲击约 22 公里到达吉隆口岸，造成重大伤亡。
