# UART S1 板测步骤与真实结果

候选 `v0.18.0-uart-s1-local.1`，[固定demo.bit](demo.bit)。当前只有本地验证，未收到本候选板测反馈。使用既有双模式卡（[content.1整卡](../../../tools/publicity/geohazard_release/README.md)）即可，不用改卡或引脚；烧录前记下实际设备和素材版本。

1. 下载本目录bit，复位/冷启动，检查读卡首图及数码管；按原操作切换SD调试页，观察实际读卡状态，确认阶段号仍显示。
2. 宣传模式检查四页翻页、单次讲解及句尾、AUTO；00下KEY4长按切换应用，确认情景图片、TEXT.BIN中文、预警/警报和阶段切换。
3. 检查01/10参数调整、11预览及返回00，确认画面/音量和身份保持，双向模式切换正常。完整按键口径见[原操作说明](../../../docs/宣传模式操作与板测.md)。
4. 发送原UART字幕命令，画面应无变化；上电和操作时TX保持空闲高电平，串口不再输出日志/回复。
5. 记录异常、复现步骤及实际测试时长；如果合并执行M6验收，另按[M6整机清单](../../../docs/宣传模式M6整机验收.md)记录内容/完整听审、≥40分钟、Flash冷启动和原始计时，不以短测代替。
