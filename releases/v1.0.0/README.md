# v1.0.0 正式版

v1.0.0 是当前完整功能集的首个稳定大版本，用于比赛提交、作品演示和后续长期维护。功能与已完成上板验收的 v0.31.0 一致，不引入新的 RTL 或卡内资源变更。

正式固件：[demo.bit](demo.bit)，677358 字节。直接复用 v0.31.0 已板测通过的 Seed 3 固件，不重新构建。

**使用方式：Program Flash 后冷启动。卡不用换。**

## 主要功能

- TF 卡 FAT32 媒体扫描、BMP 图片显示、WAV/PCM 音频播放。
- HDMI 视频与音频输出、图片切换和淡入转场。
- 宣讲模式：四类地质灾害科普页面、中文滚动字幕、讲解音频和底部音频波形。
- 情景模式：滑坡、泥石流、山洪、地震四类场景，包含阶段动画、预警信息和旁白。
- 四宫格预览、灾害菜单、AUTO 播放、按键控制和数码管状态显示。
- SW4 中文参数面板，可调亮度、对比度、音量、波形、场景速度和 OSD 开关。
- 首次上电时讲解等待 HDMI 输出满 240 帧（约 4 s），避免显示器亮屏前漏掉开头。

## 硬件与工程

- FPGA：Anlogic EG4S20BG256。
- 工具：Tang Dynasty 6.2.168116。
- 工程入口：`TD_project/demo.al`。
- 顶层模块：`top_tf_hdmi_audio`（TD 工程内顶层名为 `top`）。
- Flash 加载时钟：16 MHz。

## 资源与时序

- 17777 LUT（90.70%）。
- Setup +0.252 ns，Hold +0.011 ns。
- STNS/HTNS 均为 0。
- 布局布线 Seed 3。

该设计接近器件资源上限，重新构建不能直接使用 TD 默认策略。正式构建使用面积优先综合、`more_lut_pair`、Seed 3 和高努力布局布线；完整参数见根目录 README 的 v1.0.0 构建说明。

## 升级与回退

- 从 v0.31.0 升级：功能和卡内容不变，只需按版本管理需要更新固件标签。
- 从更早版本升级：使用本目录 `demo.bit` 烧写 Flash，并按相应功能版本准备 TF 卡内容。
- 回退：重新烧写 [v0.31.0 demo.bit](../v0.31.0/demo.bit)。
