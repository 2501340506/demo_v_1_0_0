local.1 已获用户失败反馈：正常卡旧版可用，此版先 0 后 F，长按后仍失败。本候选用于读取板上失败位置，**不是已确认修复版，不进行完整 S2 验收或 Flash 固化**。双 PLL 和所有协议等待、CRC 条件不变。

请将 [demo.bit](demo.bit) 下载到 SRAM。出现 F 后，记录从左到右完整六位显示；再长按 KEY2 重试一次，记录第二组。

六位格式为 **`CC RR M F`**（中间无空格）：

|字段|含义|
|---|---|
|CC|最近执行的 SD 命令，十六进制|
|RR|该命令的 R1，FF 表示尚未收到有效响应|
|M|原来的模式 0–3|
|F|原来的失败指示|

例如 `00FF0F` 表示 CMD0 尚未收到有效响应；`08010F` 表示最近命令 CMD8、R1=01；`29010F` 表示 ACMD41 返回仍在初始化；`10000F` 表示 CMD16 返回 00；`11000F` 表示已到 CMD17 且命令返回 00，应转查扇区读取。`FFFF0F` 表示尚未记录任何命令。十六进制 A/b/C/d/E/F 按数码管字形显示。

正常非 F 状态仍按原面板显示。诊断寄存器在协议因初始化失败而复位后保留，在 KEY2 重初始化时重新采集。没有增加自动插卡检测、持久化或课程扩展功能；定位后撤除临时面板显示。

新增引脚级模型真实观察 MOSI、在 SCLK 下降沿驱动 MISO，卡状态不跟随 FPGA 复位。正常初始化、有效/错误 CRC、局部主机复位通过；仍未复现这张真实卡的失败，不以模型通过认定修好。其余构建/时序记录见 [BUILD.md](BUILD.md)。
