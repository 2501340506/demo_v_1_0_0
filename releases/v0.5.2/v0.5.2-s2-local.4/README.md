# v0.5.2-s2-local.4 — 显式启用 SD CRC 的验证候选

local.3 用户实际反馈：`11000F / 00001F / AEBC2F / 22003F`，表示 CMD17 成功，接收 512 字节后 CRC16 不一致（收到 0000，计算 AEBC）。这些信息不能单独证明 CRC 模式或采样错位是根因。

本版在 CMD16 后发送 CMD59(1)，成功后才报告初始化完成，并为每条命令计算正确 CRC7（包括不同地址的 CMD17）。CMD59 拒绝或超时报告 F，允许 KEY2 长按重新初始化。保持双 PLL、原 SPI 分频、原超时、严格 CRC16 及四页诊断。本轮只验证读卡播放链路，未实现写数据 CRC16，不提供写卡能力。

请通过 SRAM 下载 [demo.bit](demo.bit)，先观察正常卡是否出现首图。如果仍显示 F，请记录一轮四组六位显示：末尾 0F 为命令/R1，1F 为接收 CRC，2F 为计算 CRC，3F 为读取状态。`22003F` 为 CRC 不一致；`10xx3F` 为 token 超时。如果初始化的 CMD59 失败，命令页为 `3Bxx0F`。

若首图正常，再长按 KEY2 检查旧图保留、重新扫描、首图提交、回到 MAN 与单次提示音。结果填写 [板测表](BOARD_VALIDATION.md)。当前不是已验收修复，不固化 Flash、不上传、不开始单 PLL。
