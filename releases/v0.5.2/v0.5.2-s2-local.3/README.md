# v0.5.2-s2-local.3 — 读扇区失败诊断

用户 local.2 反馈：上电 `11000F`，长按 KEY2 后很快再次 `11000F`。这已排除“初始化未完成”：CMD17 的 R1 为成功 00，但后续读阶段失败。本版采集具体读失败与 CRC 信息，不是已确认修复版。

请用 SRAM 下载 [demo.bit](demo.bit)。出现 F 后观察约 8 秒，记录轮换的四组六位显示。每页约 2 秒，最后一位固定 F，倒数第二位为页号：

|显示格式|前四位含义|
|---|---|
|`xxxx0F`|命令号与 R1，应可对照上一版 `11000F`|
|`xxxx1F`|卡返回的 CRC16|
|`xxxx2F`|FPGA 对收到的 512 字节计算的 CRC16|
|`xxxx3F`|读状态摘要|

页号 3（末尾 3F）的前四位：`10xx` 表示 token 超时，xx 为最后读到的 token 字节；`2200` 表示已接收 512 字节但 CRC 不一致；`0200` 表示最近扇区 CRC 正确；`3xxx` 表示读取中及当前字节计数。若未进入数据阶段，CRC 页为 0000，不据此判定 CRC 错误。

例如测试中的错误 CRC 会显示 `11000F`、`D5951F`、`D5942F`、`22003F`。数码管 d/b 为小写形状。正常非 F 状态仍显示原模式与图片编号；失败时原模式位置临时改为页号，KEY2 长按恢复规则不变。

首个 SD 失败的诊断值会锁住，直到 KEY2 重初始化/外部复位才重新采集。保留实际 100 MHz SD 域及 SPI 分频、2 秒初始化、100 ms 响应、250 ms token、CRC 校验，不盲目改频率或关闭校验。

非全 FF 的引脚级扇区模型逐字节及 CRC 验证通过（独立已知向量 D594），仍未复现用户卡的问题。下一步依真实显示确定失败类型，暂不进入单 PLL，不固化、不上传。旧 bit 和标签保留。
