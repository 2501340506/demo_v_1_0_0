# v0.25.0 S5 候选：场景进度条、告警色块和图例（Seed 47）

候选 `v0.25.0-s5-local.1`，源码提交 `32d3eef`，构建 `lut25_hud_td_s47`。**需要上板。** 卡的内容不用换也能验证 HUD；图例要换新卡包 [s5-card.1](../s5-card.1/README.md)。

## 新功能

- **进度条和告警色块**（所有场景卡，不需要 TEXT.BIN）：场景模式左上角，一个 16×16 告警色块（x 8–23，y 40–55）和一条进度条（x 32–271，y 44–51）。进度条一个像素对应一个时刻 t，从左向右走满 240 像素就是这个阶段的结尾；已走部分用告警色，未走部分深灰。告警色按阶段：致因蓝、发生黄、后果橙，撤离和预警红。预警模式下 t 保持 239，进度条是满的，告警块红色。
- **图例**（TEXT.BIN 有 14 段时）：画面左下一行小字（y 384–399），前面是色块，例如“红 危险区  绿 撤离路线  亮绿 避险点”。避险点的色块慢闪。预警时不显示图例。
- **兼容：** 10 段的 TEXT.BIN（S2 的卡包和之前所有的卡）照常读，没有图例，但仍有进度条。**14 段的 TEXT.BIN 只有本固件及以后认**；旧固件会判定文字文件有错，场景里的字全部不显示。

## 本地结果

| 项 | S3 候选 s3-local.2（已上板） | 本候选 |
|---|---:|---:|
| LUT | 16750 | 16962（86.54%，计划上限 17250） |
| 寄存器 | 10012 | 10033 |
| BRAM9k / 32k、DSP | 53 / 2、12 | 53 / 2、12 |
| Setup / Hold (ns) | +0.156 / +0.011 | +0.055 / +0.019，STNS/HTNS=0 |

`scene_text_overlay` 从 261 涨到 455 LUT（+194），整机比 S3 候选多约 200 LUT。Setup 余量只有 +0.055 ns，比之前的候选小；最差路径是 SD 时钟域的 `menu ui → scenario_fsm` 采样计数，不在新增的显示部分（视频时钟域）。

**同源码的另外两个种子都失败：** Seed 43 Setup −0.107 ns，Seed 53 −0.517 ns。最差路径也都在 SD 时钟域（场景控制→缓存、缩放器），不在叠加层。所以这是布局波动，这个时钟域本来余量就不大；本候选是三个种子里唯一时序全过的，只有一个候选。若这个 bit 上板有问题，不要用 43/53 的 bit。

## 上板检查

1. 烧录本目录 [demo.bit](demo.bit)（SHA-256 `9b929d2b54114f2c0583ec5dce7d2cabedb9a4b52e5c04a1906b214dd6bd12f9`），**先用现在卡上的 S2 卡**（10 段）。
2. SW3 进场景：每个阶段左上角有告警色块和进度条，进度条随时间走满；色块颜色随阶段变；KEY2 换阶段后进度条归零重走；速度 2×/4× 下走得更快。
3. 短按 KEY1 进预警：进度条满、告警块红色，红字和红框照旧；再按退出。
4. 标题、字幕、旁白、AUTO 等旁白读完再换，仍然正常；宣讲模式不受影响，菜单、缩略图正常。
5. 再把 [s5-card.1](../s5-card.1/README.md) 的 24 个文件写到卡上（或先备份），检查图例：左下一行小字、色块颜色对、避险点慢闪；其他字不变。
6. 失败时记录：进度条位置、颜色、是否整个场景文字消失（可能是固件和卡不匹配）。

回退：[S3 候选 s3-local.2](../s3-local.2/demo.bit)；卡回退到 [s2-card.1](../../v0.25.0/s2-card.1/README.md)。
