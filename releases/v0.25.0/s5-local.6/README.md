## 修了哪些问题（对照参考项目 A 找出来的）

用真实 RTL 在滑坡卡的真实图片上渲染，和 A 的示意图逐像素比较，找出了下面几处不同，全部改掉后**四张示意图（STAGE1/2/4、WARN）都是 0 个像素不同**。渲染图在 [`diagnostics/lut_opt25/osd_preview/`](../../../diagnostics/lut_opt25/osd_preview/README.md)。

1. **字幕被截成了一句话。** A 的字幕是这个阶段的整段旁白（各句空两格，例如“持续强降雨，山坡吸饱了水。  黄色虚线框出的是滑坡隐患坡体。”），我之前因为固件每段只认 31 字，自己精简成了 15 字左右的一句。现在固件每段可到 255 字，卡上的字幕就用整段旁白。
2. **预警时的字和 A 不一样。** A 是把预警语放进底部字幕条里滚动（白字），我之前是在画面正中放 2 倍大的红字。现在和 A 一样：底部滚动预警语，告警色块也跟着闪，红框颜色改成 A 的 `ff2020`（原来是纯红 `ff0000`）。
3. **左上角的状态行。** A 在场景模式里不显示“PIC:1 MANU”这一行和它的暗底，我这边一直显示着。现在场景和宣讲模式里都不显示；普通相册模式保留（那里是它唯一的状态显示）。
4. 中央 2 倍字的缩放逻辑去掉后，LUT 反而比上一版少了约 230。

不变：右上角面板（告警色块、标题、进度条）、图例和色块、慢闪、页码标签隐藏、累计时间关闭、旁白与 AUTO。
