画面版式照参考项目的示意图（`demo_v_0_0/tools/scenes/landslide_village/out/osd/`）重做。真实 RTL 渲染出来的画面在 [`diagnostics/lut_opt25/osd_preview/`](../../../diagnostics/lut_opt25/osd_preview/README.md)，可以直接对照。

- **右上角面板**（半暗底，x 348–635，y 28–59）：左边告警色块（致因蓝、发生黄、后果橙、撤离红，预警时闪烁），右边白色 16 像素的阶段标题，标题下面是细进度条（一个像素对应一个 t，已走部分用告警色）。预警时标题位置显示村名。

- **预警**：画面正中仍是 2 倍大的红色预警语和闪烁红框（与上一版相同），图例保留，字幕条不显示。

- 字数限制随版式变了：标题和村名 ≤16 字，预警语 ≤19，字幕 ≤24。

## 本地结果

| 项 | s5-local.2（上一版） | 本候选 |
|---|---:|---:|
| LUT | 16845 | 17009（86.78%，计划上限 17250） |
| 寄存器 | 10025 | 10026 |
| BRAM9k / 32k、DSP | 53 / 2、12 | 53 / 2、12 |
| Setup / Hold (ns) | +0.151 / +0.011 | +0.057 / +0.011，STNS/HTNS=0 |

比上一版多约 164 LUT：半暗的面板和底条、16 像素字符都要逻辑。LUT 在上限以内。

**同源码的种子结果：** 8 个种子里 29、7、13 时序通过（Setup +0.131、+0.057、+0.046 ns），43（−0.017）、53（−0.115）、59（−0.347）、61（−0.185）不过，47 布线失败。失败的最差路径都在 SD 时钟域（状态机、页码状态跨时钟域寄存器、缩放器），不在新增的显示部分。SD 时钟域在这个设计里余量本来就小，所以只交付通过的种子，别用其他种子的 bit。
