# v0.25.0 S5 候选 2：HUD 移到右上角，关闭累计时间（Seed 43）

候选 `v0.25.0-s5-local.2`，源码提交 `2120bfd`，构建 `lut25_hud2_td_s43`。取代 [s5-local.1](../s5-local.1/README.md)（HUD 在左上角、累计时间还在）。与 [s5-local.3](../s5-local.3/README.md) 源码相同、只差布局种子，**先上板其中一个**。Hold 余量比 s5-local.3 大，先用这个。

## 相对 s5-local.1 的改动

- **进度条和告警色块移到右上角**：告警色块 16×16（x 368–383，y 8–23），紧挨着的进度条 x 392–631、y 12–19，一个像素对应一个 t，走满 240 像素是阶段结尾。告警色按阶段：致因蓝、发生黄、后果橙，撤离和预警红。其余（图例、10 段和 14 段 TEXT.BIN 的兼容）不变。
- **关闭累计时间**：原来在右上角的“分:秒”白色小字（x 500，y 8）去掉了，顶层参数 `TIMESTAMP_ENABLE=0`。**这个显示在所有模式下都有（宣讲、普通相册也有），所以在所有模式里都没有了**；要恢复改回 1。
