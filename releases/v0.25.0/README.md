# v0.25.0 — A 项目功能移植正式版

基线 v0.24.0。把参考项目 A（`demo_v_0_0`）里本项目还没有的功能移植过来：情景卡真人旁白和分阶段文字、旁白播完才自动换阶段、标注工具和制卡教程、场景 OSD（右上角面板、进度条、图例），以及 A 的按键计时减量。

正式文件：[demo.bit](demo.bit)，675020 字节，直接复用已上板通过的 [s5-local.8](s5-local.8/README.md)（源码 `01f3a18`，构建 `lut25_hud7_td_s13`，Seed 13），逐字节一致，不重新构建。SHA-256 `81bbf816064e956476e052f9c79af994431cff886a3257cd38f9c2c83c5e4221`。

卡：[s5-card.2](s5-card.2/README.md)（四个场景的 FONT/TEXT/SND1–4），已写入用户的 SD 卡。

## 资源与时序

| | v0.24.0 | v0.25.0 |
|---|---:|---:|
| LUT | 16926（86.36%） | **16796（85.69%）** |
| 寄存器 | 10081 | 10037 |
| BRAM9k / BRAM32k | 53 / 2 | 53 / 2 |
| DSP | 12 | 12 |
| Setup / Hold | +0.130 / +0.030 ns | +0.135 / +0.027 ns |

功能增加了，LUT 反而少 130：按键共用 1 ms 计时省 165，去掉累计时间和中央 2 倍预警字省下的逻辑抵掉了新 OSD 的开销。计划上限 17250 LUT。

## 改动

- **S1 按键计时**：去抖、长按、参数调节的所有计数共用一个 1 ms 计时（A 的 v0.18 做法），−165 LUT，手势不变。A 的另外三项减量在本项目无收益，未交付（[记录](../../diagnostics/lut_opt25/LUT_RECORD.md)）。
- **S2 情景卡旁白和文字**：四张灾害卡用 A 的村名、预警语、阶段标题和 36 句 MiniMax 录音；每句旁白放在第 t×1600 个采样点，与画面时刻对齐；第 4 阶段（预警时循环的 SND4）垫了压低的警报声。工具 `tools/mountain_port/make_card_narration.py`、`scene_audio.py`。
- **S3 旁白播完才 AUTO 换阶段**：PCM 流读完一遍时置一个标志，场景状态机在本阶段的 SND 还没读完时不让 AUTO 走。KEY2、预警、没有 SND 的阶段、宣讲模式不变。
- **S4 标注工具和制卡教程**：`tools/mountain_port/annotate_scene.py`（可打包成 exe），新增“卡文字与旁白”窗口和“安装到 SD 卡”；[使用说明](../../docs/场景标注工具使用说明.md)、[滑坡卡教程](../../docs/滑坡卡制作教程.md)。
- **S5 场景 OSD**：照 A 的版式重做，真实 RTL 渲染与 A 的示意图逐像素一致（[预览](../../diagnostics/lut_opt25/osd_preview/README.md)）：右上角半暗面板（告警色块、标题、进度条）、左下图例（带色块）、底部整段旁白字幕；预警时面板显示村名、底部滚动预警语、红框和色块闪烁。去掉了右上角累计时间、“SCENE/EDU/COMPAT n/4”页码标签，以及场景和宣讲模式里左上角的状态行（BUSY/ERROR/NO SET 等故障提示保留）。
- **修复**：换场景后第一张图的图例缺字。FONT/TEXT 加载比一帧还短，视频侧看不到有效标志掉下来，新场景又从阶段 1 开始，解析器就沿用了上一个场景的文字段位置；现在每次加载完成都翻转一个代号，叠加层据此重新解析。

## 验收

- **板测**（用户确认，2026-10-22，s5-local.8 + s5-card.2）：
  - 四张灾害卡的旁白都能听到，字幕与阶段一致；
  - AUTO 等旁白播完才换阶段；
  - 预警下 SND4 循环、红框闪烁；

  - 冷启动出图 5 s；

- **本地**：场景 OSD 独立参考模型逐像素比对（3 套卡）和 24 个变异体；换场景测试 4 次切换；场景状态机与 v0.24 逐拍对比（16 种参数 × 120 万拍）和 4 个变异体；按键 1 ms 计时与 v0.24 逐拍对比和 4 个变异体；PCM 流标志测试；宣讲字幕单元测试；SD 引脚级启动仿真与 v0.24 一致；复位审计（SD 命令模块、读卡器解析器的复位仍由寄存器驱动）；约束与 v0.24 逐字节一致；标注工具测试 15 项、场景文字测试 3 项。
- **限制**：
  - SD 时钟域的时序余量小：同源码 5 个种子里 1 个不过（Seed 31，Setup −0.923 ns），之前几轮也常有种子不过，最差路径都在 SD 时钟域，不在新增逻辑里。以后改动要多跑几个种子。
  - 冷启动 5 s，这是第一次实测（v0.23 计划的 ≤2 s 目标从未测过；A 项目为 4 s），本版没有针对启动时间做改动。
  - 几个旧测试台还连着 v0.24 已删除的端口或缺端口（`tb_rescan_key`、`tb_preview_keys`、`tb_m3_scan_bounds`、`tb_audio_scan`），与本版无关，未修；`four_bank/run_system.ps1` 缺原语库（v0.24 遗留）。
  - 教程“从头做一张滑坡卡”没有人按步骤在窗口里完整走过一遍。
