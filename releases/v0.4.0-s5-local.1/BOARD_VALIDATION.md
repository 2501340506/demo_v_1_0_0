# S5上板验收（待用户验证）

下载本目录固定[demo.bit](demo.bit)，标签v0.4.0-s5-local.1。直接沿用已经通过S3/S4的六图测试卡，不需要删图或换素材。

## 1. 正常使用回归

复位或上电，仍只显示4张good图。MAN上一张/下一张、连续按键，再切AUTO观察至少两轮；正常图无缺失、无半帧，编号和提示音时机正常，持续正常读卡不出现F。

## 2. 已有画面后制造读卡异常

1. 切回MAN，等待一张图稳定显示，记住当前画面和编号。
2. 拔出TF卡，再按一次下一张，观察数码管末位及画面。需有新的读图请求才会触发等待超时，MAN空闲时拔卡本身不会立刻报错。
3. 若底层读卡无进展，约500ms后末位应显示F（人工观察可等1～2秒）；原画面完整保留，不应产生新图提示音。
4. 出现F后再按上一张/下一张或切AUTO，F和旧画面应保持，不应继续加载。插回卡也不要求自动恢复。
5. 插好卡后复位或重新上电，确认能回到正常显示。若遇到此前已记录的SD初始化问题，记录实际表现；本阶段没有修复底层初始化/热插拔。

拔卡的底层表现取决于控制器。如果实际返回完整坏头或短扇区，可能出现E或d，它们分别属于头错误/像素不完整；请反馈实际字符，不把它们当作F超时通过。如果始终正常翻出新图、切成半帧，或卡住却不出现任何错误，也请直接反馈。仿真已经分别注入各等待的超时，板级测试用于确认真实卡异常时的可见行为。
