## 上板使用

烧录本目录固定demo.bit，并把card中的四个EDU BMP替换到现有媒体卡中原EDU文件所在位置（现有宣传目录或根目录）。保留现有VOI1–4.PCM、FONT/TEXT和情景媒体。只更新固件仍会看到旧图上的来源/版本文字；只更新图片不会获得新波形。本次没有写入任何外接盘。

上板核验四页正常讲解、大小音量和静音、字幕不被遮挡、情景及预警无波形、双向模式切换、预览/菜单及原音频功能。实板反馈之前不建立board标签，不发布正式版或合并main。

GIF使用原讲解PCM片段的32样本峰值生成，用于预览位置和样式；未渲染运行时字幕，也未模拟RTL逐帧回落，不能代替实板录像。BMP底部为干净背景，由固件实时叠加波形。

TD bottom_wave_td02：17438 LUT、11737寄存器、36 BRAM9k、2 BRAM32k、14 DSP；Setup +0.106ns、Hold +0.037ns、STNS/HTNS=0。22项仿真通过，134个隔离源码文件逐字节核对一致。来源元数据仍保留在原内容资料中，仅移除了画面上的文字。

回退：恢复[旧固件](../../v0.19.0/s2-local.1/demo.bit)和[原四张EDU图片](../../../tools/publicity/geohazard_release/generated)。不继承此前版本的板测结论。
