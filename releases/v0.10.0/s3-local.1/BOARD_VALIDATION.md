# S3 MM:SS 上板步骤

下载本目录 `demo.bit`，对应 `v0.10.0-s3-local.1`。本阶段待用户板测；上一阶段回退为 `../s2-local.1/demo.bit`。

1. 复位后右上角应显示白色 `00:00`，区域 x=500..579、y=8..23，无新增底条。计时从视频域复位释放后开始，即使首图还未显示也会计时。
2. 观察时间持续递增，`00:59 → 01:00` 正确；复位后归零。按每 60 个视频帧计一秒，实际墙钟精度依赖帧率，无 RTC。
3. 同时观察左上状态、中英滚动字幕及原两条底条，不应互相覆盖，原图区域不受影响。
4. UART 仍为 RX F12 / TX D12、115200 8N1。发送 `SUB=hello`、`SUB=OFF`、`SUB=ON`、`SUB=CN` 和 `SUB?`；时间应持续计数，不因字幕隐藏、更新或查询而重启。
5. 手动切图、切换 AUTO、重扫保图，确认时间不重启，缓存切图及 HDMI 音频正常。

本地专项已覆盖 `09:59 → 10:00`、`59:59 → 60:00`、`99:59 → 00:00` 的真实帧事件计数；无须仅为重复该仿真等待 100 分钟，若进行了长时间板测请反馈实际时长。Flash、冷启动或长期稳定性只记录用户实际提供的结果。

`TIMESTAMP_ENABLE=0` 为编译期选项，本候选默认开启；关闭需重新构建，不是 UART 命令。只做累计 MM:SS，不支持校时、RTC、日期或掉电保存。

补充 S2 HEX 发送：终端切到 HEX 模式后发送 `53 55 42 3D 80 41 0D 0A`，不要增加 `SUB=` 文本前缀。成功后查询应返回 `SUB=1,02,8041`（若之前 OFF，首字段为 0）。未确认发送模式时的 ERR 不作为任意中文输入已实现的证据。

反馈功能、异常及实测时长。确认通过后建立 S3 board 标签，再以该已验收 bit 正式归档 v0.10.0。
