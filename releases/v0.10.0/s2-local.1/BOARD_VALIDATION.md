# S2 UART 在线字幕上板步骤

候选：本目录 `demo.bit`，标签 `v0.10.0-s2-local.1`。本地验证不等于板测通过。

1. 下载本目录 bit。保留正常 TF 图片卡，确认首图、默认中文 + FPGA 标语、状态条、切图和 HDMI 音频正常。
2. USB 串口使用 **3.3V TTL**：适配器 TX 接 FPGA **F12（RXD）**，适配器 RX 接 **D12（TXD）**，GND 共地。终端设 **115200、8N1、无流控**，每条命令追加 CR、LF 或 CRLF。
3. 发送一条命令并等待回复后再发下一条。正常启动/事件日志仍会出现，字幕回复为独立完整行。

| 发送文本 | 期望 |
|---|---|
| `SUB?` | 上电默认 `SUB=1,0F,808182838485868788204650474120` |
| `SUB=hello fpga` | `OK`；下一次可用帧边界更新为大写英文，并从右侧重新滚入 |
| `SUB=OFF` | `OK`；字幕与底部字幕条隐藏，状态条保留 |
| `SUB?` | `SUB=0,0A,48454C4C4F2046504741` |
| `SUB=ON` | `OK`；恢复原滚动位置 |
| `SUB=CN` | `OK`；加载课程 9 个汉字 |
| `SUB?` | `SUB=1,09,808182838485868788` |
| `SUB=123456789012` | `OK`；12 个字符可滚动 |
| `SUB=1234567890123` | `ERR`；原字幕不变 |
| `BAD` | `ERR`；原字幕不变 |
| `SUB=` | `OK`；清空字幕并隐藏底部字幕条 |

混合文本用终端的 HEX 发送（不要额外附加文本换行）：`53 55 42 3D 80 41 0D 0A`，即第一个汉字 + A。非法汉字编号测试：`53 55 42 3D 89 0D 0A`，应回复 ERR。不能直接输入通用中文 UTF-8；只有内部编号 80..88 有中文字模。

更新后观察字幕完整进入、移出、回绕；在滚动中手动切图、切 AUTO、重扫保图，位置应连续，音频应正常。复位后恢复默认 15 槽标语和开启状态，不保存在线配置。

查询返回控制域最新接受配置，可能早于屏幕实际应用；OK 表示已接受。文本最多 12 个内部字符，小写转大写；字库未覆盖的可打印符号显示问号。ON/OFF/CN 是保留命令。连续更新在 mailbox 忙时合并最新完整配置，主机正常使用一问一答；不是无界接收队列。

请反馈实际测试项、异常现象及运行时长。S2 板测通过后才建立 board 标签并进入 S3 MM:SS。

阶段回退：`../s1-local.1/demo.bit`（对应 S1 local.2 / board.1）；正式总回退：`../../v0.9.1/demo.bit`。
