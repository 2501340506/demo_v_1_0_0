# v0.10.0 正式版（2026-10-10）

三个阶段已完成用户功能验收：固定 9 汉字/中英滚动字幕、UART 在线字幕、右上角 MM:SS。S3 用户明确“运行20分钟，功能均正常”，实测时长 20 分钟。

正式下载：[demo.bit](demo.bit)。直接复用 v0.10.0-s3-local.1 / s3-board.1 已验收 bit，629,624 字节，逐字节一致；没有修改生产源码或重新构建。

- 中文：课程内置 0x80..0x88 共 9 个字，英文共用 5×7 字模。
- UART：RX F12 / TX D12，115200 8N1；SUB=ON/OFF/CN/文本、SUB?，配置完整传输并在帧边界生效。在线最多 12 槽，复位保留原 15 槽标语。
- 时间：右上角白色 MM:SS，每 60 视频帧加一秒，99:59 回绕；复位清零，切图和字幕更新不重启。
- 保留状态条、半透明底条、四 Bank、SDRAM、HDMI 音频和 RGB 零额外延迟。

使用方法见 [最终候选上板步骤](s3-local.1/BOARD_VALIDATION.md) 和 [UART 协议步骤](s2-local.1/BOARD_VALIDATION.md)。BOOT 的旧版本文字为沿用日志常量，不作为版本识别依据。

验证：时间完整 360,000 帧计数及 3,379,200 像素专项、关闭时间层零逻辑资源综合、21 项回归、真实 SDRAM 三层文字联合测试通过。TD Setup +0.102 ns、Hold +0.019 ns，覆盖率 99.96%；11,748 LUT、6,637 寄存器、4 BRAM、2 DSP、1 PLL。完整证据、工具警告和构建清单引用 [S3 固定记录](s3-local.1/README.md)，不重复复制全工程。

验收见 [S2](S2_BOARD_RESULT.md)、[S3 20 分钟结果](S3_BOARD_RESULT.md) 和 [最终验证](FINAL_VALIDATION.md)。S1 board.1 已确认功能正常，其正确 bit 保留在 s1-local.1/demo.bit，实际对应 local.2 / board.1；不改旧目录或标签。

范围限制：不支持通用 Unicode/UTF-8、任意中文、掉电保存、RTC/校时、参数面板、亮度/缩放。S2 原始 HEX 混排终端发送模式未单独确认；Flash、完全断电冷启动及超过 20 分钟运行未单独确认，不扩大整体验收结论。

归档：[计划与最终交接](../../docs/history/2026-10-10/v0.10.0/README.md)。总回退：[v0.9.1/demo.bit](../v0.9.1/demo.bit)；阶段回退文件继续保留。
