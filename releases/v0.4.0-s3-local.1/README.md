# S3可信BMP快速跳过

2026-10-05。**用户已确认S3上板通过，板级标签v0.4.0-s3-board.1；固定bit不变。** 标签`v0.4.0-s3-local.1`；下载[demo.bit](demo.bit)。S2已由用户确认全部测试通过并推送。

## 行为

不符合显示格式的BMP，若仍是可信的连续文件，则根据声明长度跳过整个文件。快跳范围：BM、DIB>=40、planes=1、正宽高且均不超过65535、未压缩24/32位、偏移不覆盖DIB、声明长度足以容纳按4字节对齐的所有行，且下一地址不超出扫描区间末尾后一扇区。

其余情况（非BMP、损坏头、长度不足、未知压缩/位深、跨度超界）继续逐扇区找，避免漏掉后面的好图。不会把普通MP3等非BMP文件当成可快速跳过的文件。S2黄色planes错误、紫色offset错误不属于快跳对象。

扫描地址与文件扇区数计算保留进位，避免长度/地址回绕。遇到快跳恰好结束于扫描边界，直接完成，不发越界请求。可显示图片仍沿用S2校验及原加载/双缓冲流程；S4像素完整性、S5超时尚未实现。

## 本地验证

- 14组扫描专项通过；相同testbench运行已验收S2解析器，实际请求数：800×600/24位样例2814→2，640×480/32位2402→2，带行填充3×100样例4→2，找到的后续好图扇区一致。[S3日志](simulation/scan_test.log) · [S2实测](simulation/scan_s2_test.log)。这不是整机启动倍数承诺。
- S2头专项22组、全尺寸307200像素RGB核对、7组恢复、6个控制回归均通过，零错误零警告。SD与存储用行为模型；未改音视频/缓冲子系统沿用已验收证据，没有本轮全量重跑。
- TD综合/布局布线/bitgen通过，3739 LUT、2846寄存器、4 BRAM、4 DSP、2 PLL。新增扫描域+0.106ns；全局Setup−6.565ns/TNS−296.409ns，Hold+0.003ns。64个SDRAM接口和3个未修改内存域负端点（最差−0.332ns）仍在，未全局收敛。[时序对比](timing_comparison.md)。
