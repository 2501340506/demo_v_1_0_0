# v0.26.0 S1 候选 1：白色对称波形 + 蓝色渐变（Seed 7）

候选 `v0.26.0-s1-local.1`，源码提交 `ae2ab98`，构建 `sym26_td_s7`，基线 v0.25.0。[阶段计划](../../../docs/对称音频波形v0.26分阶段计划.md)。

**卡不用换**：沿用 v0.25.0 的卡（s5-card.2）。字幕、图片提示和宣讲 BMP 都没动。

## 改了什么

宣讲模式底部的紫色单向竖条，改成参考截图那种波形：

- 波形带 y=448..479，中线在 463/464 之间，上下对称伸长。字幕带在 y=443 结束，中间空 4 行。
- 80 个槽，每 8 px 一个，柱宽 4 px，柱头是圆的。中间两根是最新的声音，往两边越来越旧，左右镜像。
- 包络是 cos² 形状：中心柱最高 ±15 px，最外侧只剩小点。静音时整排是 2×2 的小圆点。
- 柱子是不透明白色。波形带底下叠一层蓝色（3c82f0）渐变，从上往下混入比例从 25% 到约 87%。
- 只在宣讲画面、有效显示、有声音、不在预览或菜单时画。情景和旧图片模式不画，和以前一样。

源码：[audio_ring_overlay.v](source/audio_vis/audio_ring_overlay.v)，接口和两拍延迟不变。top 只有一处改动：电平模块的历史条数从 80 改为 40，左右共用（[top_tf_hdmi_audio.v](source/top_tf_hdmi_audio.v)）。电平模块本身没改。

预览（用 EDU1 和模拟的说话音量）：[底部放大](preview/EDU1_bottom.png)、[整幅](preview/EDU1_full.png)。
