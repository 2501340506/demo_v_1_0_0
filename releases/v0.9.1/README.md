# v0.9.1 — OSD 优化正式版

基线 v0.9.0。统一 OSD 坐标和帧事件，参数化固定字幕滚动，以显式字形命中保护文字，修复原图黄/红/白像素在半透明底条内未减半的问题。保留 RGB888、视频零额外延迟、四 bank 播放与音频行为。

正式文件：[demo.bit](demo.bit)，629624 字节，直接复用 [S3 已验收候选](s3-local.1/demo.bit)，逐字节一致，不重新构建。

- 本地：四类专项、真实 SDRAM 57 显示帧、21 项回归和完整 TD 通过；Setup +0.102 ns、Hold +0.014 ns，覆盖率 99.95%。9826 LUT、5924 寄存器、4 BRAM、2 DSP、1 PLL。
- S3：用户确认“功能正常，进入下一阶段”，对应 v0.9.1-s3-board.1。
- S4：用户确认“S4通过，运行20分钟，功能正常”。实际运行 20 分钟，按用户明确确认结项；不记录为原建议的 30 分钟，不补造单项次数。详见 [S4 记录](S4_VALIDATION.md)。
- 限制：无运行时字幕、UART RX、中文或时间戳；系统仿真保留 18 条既有模型/可选端口警告，时序审计保留既有分类。证据与变更源码见 [S3 说明](s3-local.1/README.md)。

回退：[v0.9.0 固定 bit](../v0.9.0/s3-local.1/demo.bit)。[最终归档](../../docs/history/2026-10-10/osd-optimize/README.md)。
