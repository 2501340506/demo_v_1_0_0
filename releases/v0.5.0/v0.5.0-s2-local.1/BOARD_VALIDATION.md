# S2 SRAM上板验证

状态：待用户确认。S1已由用户整体确认通过；本阶段只验证SDRAM就绪后启动扫描，没有执行Flash固化。

## 操作

1. 插入同一张正常测试TF卡，连接HDMI和音频设备。在TD选择SRAM方式，下载本目录[demo.bit](demo.bit)。
2. 等待启动扫描完成，确认首图及图片编号正常，首图提示音只出现一次、旋律正常；无花屏或持续黑屏。
3. KEY1/KEY2遍历四张正常图片，检查画面、编号、提示音和旋律对应。
4. KEY4切换AUTO，观察至少一轮四图轮播，再切回MAN。切换模式开关，确认原有按键与播放行为保持。
5. 完成5轮正常复位：每轮按下/松开复位后等待首图恢复，再进行下一轮，观察是否卡在初始化或扫描、是否残留旧图编号或多余提示音。

内部“SDRAM未就绪不能启动扫描”的顺序已经由本地仿真验证，不要求凭肉眼判断两拍同步。板上重点检查启动与播放无回退。

出现问题记录数码管状态、触发步骤和是否重新上电恢复；同卡同设备可用[S1已验收bit](../v0.5.0-s1-local.1/demo.bit)对照。SD底层协议恢复不在本次改动范围。
