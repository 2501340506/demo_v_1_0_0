## 行为变化

- `top`将`Sdr_init_done`经两级寄存器同步至SD时钟域，`rst_sd`清零。
- `sd_card_bmp`新增高有效`sdram_ready`输入，首次扫描同时等待TF初始化、解析器就绪和SDRAM就绪。
- TF与SDRAM初始化继续并行；等待SDRAM不复位SD控制器，不增加固定上电延时。
- 扫描后的加载、有限恢复、500ms无进展超时、帧提交、按键和音频保持既有行为。七个直接实例测试入口显式连接新增输入。

## 本地验证

- 真实顶层启动专项四场景：TF先就绪、内存先就绪、近同时、等待期间复位。独立参考检查两拍同步；未就绪无业务活动，就绪后只扫描一次。
- 负对照绕过新增门控，在提前扫描断言处按预期失败。该日志的一次Fatal是预期结果，不混入正向通过统计。
- S1五轮顶层复位专项重新通过，包含两PLL锁定顺序、停钟恢复、在途提交清除和音频重新启动。
- 七项稳定性专项（完整帧307200 RGB、恢复、头、扫描、像素、解析器超时、上层超时）、真实异步交接三配置及八个既有回归入口本轮全部通过，正向编译/仿真零错误零警告。
- TD构建及资源/时序见随附报告。固定bit与最终运行产物逐字节一致；SDC、ADC、PLL频率和工程清单不变。

专项控制初始化完成电平，PLL/存储/FIFO使用行为模型，不代表物理TF初始化、SDRAM电气特性或Flash固化已验收。原SD初始化/免复位热插拔问题未纳入修改。
