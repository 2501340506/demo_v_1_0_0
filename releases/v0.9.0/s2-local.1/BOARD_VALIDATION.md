# S2 上板验证

使用本目录 [demo.bit](demo.bit)，回退使用 `../s1-local.1/demo.bit`。S2 只验收滚动字幕，底条尚未实施。

1. 上电并加载已有图片，确认左上角 S1 状态条仍清晰；首图提交后，底部出现白色 `ANLOGIC FPGA IMAGE PLAYER`。
2. 观察字幕从右侧进入，向左每帧平滑移动，完整离开左侧后重新从右侧进入；字幕限定在 X=[8,632)、Y=[444,460)，不覆盖画面边界。
3. KEY1/KEY2 切图、KEY4 切换 AUTO/MAN，检查字幕连续滚动、不因图片提交或后台预载重启；原图号、ERR、提示音保持 S1 行为。
4. 长按 KEY2 重扫，检查旧图保留期间字幕继续滚动；新首图提交后仍连续。无首图时字幕不显示。
5. 使用黑、白或高对比图片观察字幕像素清晰度；本阶段没有底条，颜色是白色。记录实际显示器边缘裁切情况。

请反馈候选 `v0.9.0-s2-local.1` 的字幕内容、进入/退出/回绕、切图连续性、无首图门控和原功能结果；未测试项目写明未测。确认通过后建立 `v0.9.0-s2-board.1`，再实施 S3 半透明底条。
