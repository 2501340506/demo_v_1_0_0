# v0.9.0 S2 local.1：滚动字幕

固定上板文件：[demo.bit](demo.bit)，629624 字节。[上板步骤](BOARD_VALIDATION.md)。S1 `v0.9.0-s1-board.1` 已通过，S2 等待用户板测；半透明底条留在 S3。

## 本次效果

在已通过的左上角状态条后加入固定英文字幕 `ANLOGIC FPGA IMAGE PLAYER`。白色 5×7 字体横纵放大两倍，字幕区域为 X=[8,632)、Y=[444,460)，每个 VS 下降沿移动 1 像素，从右侧进入，完全退出左侧后循环。首图未成功提交前保持关闭；切图、AUTO 和重扫保图不重启，复位重新开始。区域外 RGB、消隐、状态条、图片、音频及串口行为保持不变。

本阶段没有半透明底条；`OSD_ENABLE=0` 可旁路全部 OSD，`SCROLL_ENABLE=0` 仅旁路滚动层。
