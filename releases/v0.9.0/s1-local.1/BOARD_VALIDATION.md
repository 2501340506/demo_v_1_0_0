# S1 上板验证

使用本目录 [demo.bit](demo.bit)，不要使用 TD 运行目录中可能被覆盖的文件。本次只验收状态 OSD；滚动和半透明底条尚未实施。

1. 通过现有下载方式加载候选，使用原来的 640×480 BMP 测试卡。检查左上角文字清楚、图像位置及颜色正常；首图出现后显示 PIC:1、MAN、ERR:00，正常文字为黄色。
2. 图片模式下 KEY1/KEY2 切图，观察编号与当前实际图片一致，不应先跳到后台加载图片或晚一帧闪动。每次实际切图仍提示一次。
3. KEY4 切到 AUTO，再切回 MAN，检查状态文字及原轮播正常；背景预载不应改变显示编号。
4. KEY2 长按 2 秒重扫，检查旧图与编号保留到新首图完成，恢复后 MAN/ERR:00 正常。用已有缺图/无图测试卡观察 ERR:01 红色；若已显示过图片，旧图仍保留。尚无首图时编号显示“-”。
5. 按原有通信失败测试方式检查 ERR:02；恢复正常卡并重扫后错误消失。ERR:03 已做加载失败仿真，如没有现成失败素材，记录该单项未测，不必为此损坏正常文件。

请反馈候选名 `v0.9.0-s1-local.1`、文字/图号、MAN/AUTO、重扫/错误和提示音的实际现象；没测试的项目直接说明未测。S1 不要求提前完成 S4 的 Flash/冷启动/30 分钟专项。

用户确认该候选通过后，记录实际反馈、建立 S1 board 标签并推送相关分支/标签，再进入 S2 滚动字幕。失败则保留本候选，最小修复后生成新的 local 编号。

回退：[v0.8.0 固定 bit](../../v0.8.0/s3-local.1/demo.bit)。
