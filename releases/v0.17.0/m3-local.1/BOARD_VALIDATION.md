# M3 上板验收（待用户执行）

只下载本目录固定的 `demo.bit`，候选 `v0.17.0-m3-local.1`。M1 尚无板测反馈，本次按用户指令推进 M3 本地实现，不代表 M1 已通过；整机回退仍用 `releases/v0.16.0/demo.bit`。M1 的固定候选也保留，可用于定位加载链路与图层差异。

1. 原24bpp卡：首帧、四图、上下切换、自动轮播、缩放、四宫格焦点/预览/返回正常；不应出现灾害染色或绿色闪点。检查亮度/对比度/音量调节、转场黑场/擦除、音频环、字幕/时间戳及提示音，返回预览后画面和声音恢复。
2. 把 `board_samples/PIC1.BMP`–`PIC4.BMP` 复制到另一张 FAT32 卡根目录，可保留原BGM；换卡后复位。M2的四张图底图相同，但T不同。使用原图片模式手动切图，每图停留至少一轮（480帧，约8秒）。
3. PIC1：底图不染色，高地避险点绿闪；PIC2：裂缝从坡顶沿折线出现；PIC3：蓝色覆盖沿沟谷扩大；PIC4：绿色撤离路线从村庄通向高地。对照 `board_samples/overview.png` 与 `expected/` 原尺寸图；前沿亮/暗有变化，t到239后回到0循环。
4. 切换到另一图时推演从0开始。进入四宫格时灾害层旁路，缩略图保持底图及焦点框；回到全屏后推演从0开始。自动轮播继续按原规则切图，每次切图重启当前图的推演。
5. 避险点亮相为纯绿、暗相恢复底图；普通24bpp和缩放黑边均不着色。闪烁随阶段约为2/4/6/8Hz，避险点约1Hz（以约60Hz帧率计）。画面不应错行、错色、花屏或出现OSD位置偏移。
6. 换回原24bpp卡并复位，确认旧卡功能仍正常。若异常，记录候选标签、卡/图号、操作顺序和现象，再回退已验收v0.16.0。

M3仅有临时帧驱动时间源，未接入音频同步FSM、SND1–4、预警模式、FONT/TEXT。用户未提供的次数/时长/单项结果不补填；确认前不建立board标签、不推送。本候选若失败，保留原候选并出local.2。明确确认本候选后再记录实际板测范围；不倒填未经测试的M1板测结论。
