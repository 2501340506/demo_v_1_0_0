# S2上板验收

状态：**用户确认全部测试通过**。下载本目录[demo.bit](demo.bit)，标签`v0.4.0-s2-local.1`。

## 操作与预期

1. 先用此前正常的TF卡，确认首图、上一张/下一张、首尾循环、KEY4 AUTO/MAN、图片提示音正常；颜色和上下方向正确。
2. 解压[测试图片](board_samples.zip)，将5张BMP放入干净测试卡，保持原项目要求的文件连续存储且位于扫描范围内。正常应只显示红、绿、蓝3张；黄色planes=2、紫色像素偏移与扩展DIB重叠，应被扫描排除。
3. 红图使用标准40字节DIB，绿图为108字节V4，蓝图为124字节V5。三图白条均在上方、黑条在左侧；切图顺序取决于实际扇区顺序，不以文件名排序作断言。AUTO应仅轮播有效图片，提示音随实际显示提交。
4. 无可用图片测试只放两张错误图。扫描结束后不应提交图片或产生首图提示，保持现有首图前输出。扫描时拒绝头不显示E；E仅表示已登记图片的加载头失败。

原始扇区扫描可能找到已删除文件的BMP头；仅删除文件不保证“无可用图”，该项需使用没有旧有效BMP残留的测试卡。S2仍逐扇区扫描坏图/空区，未找到4张会扫至范围末尾，因此混合卡或无图卡启动可能较慢；不要以S3快跳或S5超时标准验收本阶段。

无需用拔卡制造错误：SD底层恢复仍延期。若异常可恢复下载[S1已验收bit](../v0.4.0-s1-local.1/demo.bit)。
