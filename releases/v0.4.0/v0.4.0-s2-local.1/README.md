2026-10-05。**用户已确认S2全部测试通过，板级标签v0.4.0-s2-board.1；固定bit不变。** 固定下载[demo.bit](demo.bit)，本地标签`v0.4.0-s2-local.1`。

## 修改

生产RTL仅修改bmp_read：读取DIB大小与planes，扫描/加载共用完整头校验。要求BM、DIB至少40字节、planes=1、完整32位宽高匹配期望正值、24位未压缩、像素偏移不早于DIB结束且小于声明文件长度、声明长度足以包含整图。

标准54字节头和V4/V5扩展头均支持；不增加负高度、其他尺寸、压缩格式或文件系统。计算使用32位像素数、34位字节区间及33位DIB结束位置，分拍寄存，避免加法溢出与校验长路径。

扫描拒绝的头不登记为图片；已登记图片加载时头不合法，沿用S1的E提示、一次重试及旧图保留。长度声明不足归ERR_HEADER，并非S4的运行中像素完整性检测。S3快跳、S4像素计数及S5超时尚未实施。
