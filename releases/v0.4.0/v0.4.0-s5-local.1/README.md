## 行为

扫描、加载图头、等待SDRAM写应答、读取像素，均使用默认500ms无进展计时。有有效字节/扇区结束/相应写应答即重新计时，不限制完整扫描或整图总耗时。参数按时钟先除1000再乘毫秒换算。

超时后撤销请求，停止像素输出，数码管末位锁存F，保留旧画面/编号；禁止新加载、重试与显示提交，直到复位。迟到字节、结束、写应答和写完成均不能恢复。扫描用独立scan_error，不伪装成加载失败，不产生首图提示。写应答等待超时也停止，避免与迟到写任务混用。

这是BMP事务等待保护；不修SD初始化、命令响应和热插拔恢复。未初始化时仍不启动本计时器；已初始化后BMP请求卡住可被超时阻断。解析已成功之后的最终SDRAM写完成/显示确认等待不在本阶段计时范围内。

## 本地验证

- timeout：真实解析器8项，分别覆盖扫描/读头/写应答/部分像素/已收全字节但无结束的超时、迟到信号屏蔽、长扫描、慢速持续数据、截止拍数据优先和复位恢复。
- timeout_control：真实解析器+上层6项，扫描超时无首图或音频；已有画面后图头/写应答/像素超时保留旧画面、编号、提交事件，MAN/AUTO不能发新加载；内存先完成但源无结束仍不提交，复位后恢复。
- 原全尺寸307200像素、8像素、8恢复、22头、14扫描、S2旧解析器对照、真实异步双缓冲3配置，以及全部8既有入口通过，ModelSim零错误零警告。复用S4联测脚本产生的s4_handoff_*日志是本次S5 RTL重跑结果。
- TD综合/布局布线/bitgen通过；3944 LUT/2890寄存器/4 BRAM/4 DSP/2 PLL。SD域+0.133ns、内存域+0.021ns；全局Setup−6.565ns、Hold+0.004ns，64个原SDRAM接口违例保留。

[simulation](simulation)保存日志。仿真使用SD/FIFO/存储行为模型，超时阈值缩短；不等价于物理卡测试。原始扇区没有文件EOF，足量旧数据仍不可识别。
