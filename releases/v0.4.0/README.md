## 修改

- BMP头校验：DIB、planes、完整32位宽高、位深/压缩、偏移及声明长度。
- 成功/失败事件与有限恢复：已结束的头错误或短扇区重试一次，MAN保留旧图，AUTO/首图按候选表有限遍历。
- 结构和长度可信但不支持显示的BMP快速跳过，其他逐扇区搜索。
- 限定像素范围，精确307200像素，短扇区报d；解析成功且本次写完才提交显示、编号及音频事件。
- 500ms无进展超时覆盖扫描/读头/写应答/像素等待；F锁存、保留旧图、停止新加载和提交，复位退出。

保留640×480、24位未压缩、正高度BMP、连续原始扇区读取、双缓冲及已有音视频功能。

## 固定产物与验证

bit为629624字节，直接复制已验收S5候选并逐字节比较一致；生产RTL、工程及约束与S5候选一致，无重新构建。工程/约束、源清单、TD报告随本目录保存；其中源清单和时序对比保留S5构建来源。

[S6全回归证据](v0.4.0-s6-local.1/README.md)：全尺寸RGB参考及头/扫描/像素/恢复/超时专项、真实异步缓冲3配置、8个既有入口全部通过，零错误零警告。SD/FIFO/存储使用行为模型。

TD资源3944 LUT、2890寄存器、4 BRAM、4 DSP、2 PLL。SD域+0.133ns、内存域+0.021ns；全局Setup−6.565ns/TNS−294.297ns、Hold+0.004ns，64个SDRAM接口违例仍在，全局未收敛。见[timing_comparison](timing_comparison.md)。

## 已知边界

SD初始化/命令响应、免复位热插拔恢复仍延期；未初始化时BMP超时尚未启动。源解析结束后的最终内存写完成/显示确认等待不在本轮超时范围。原始扇区无真实文件EOF，截断后返回足量旧数据不能检测，像素计数不证明文件内容完整。

S5用户已确认拔卡请求后F、旧画面保留、无多余音频、停止保持、插好卡后复位/上电恢复。用户肉眼估计F在500ms以内，不视为精确计时证明。S6为整体通过反馈，未补造测试明细。
