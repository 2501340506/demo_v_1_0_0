# v0.27.0 S1 候选 3：中文面板 + 场景速度（Seed 11）

候选 `v0.27.0-s1-local.3`，源码提交 `edcb6c0`，构建 `adj27d_td_s11`。在 [s1-local.2](../s1-local.2/README.md) 基础上加了两项用户要求。**卡不用换**。

## 改了什么

1. **场景播放速度放进面板**：新增“场景”分类，条目“速度”，显示 1X / 2X / 4X；不在场景画面时显示 `--`。编辑态 K1 降一档、K2 升一档（到 1X / 4X 为止），K1+K2 同按或“全部重置”回到 1X。速度仍然由场景控制器保存，面板只是代替原来的 KEY1 长按发出换档，所以 KEY1 长按在场景里照样能用，两边显示一致。
2. **面板改中文**：
   - 顶部去掉“SW4”，标题“参数调节”居中。
   - 底部提示：光标态“K1↑ K2↓ K4编辑”，编辑态“K1↑ K2↓ K4返回”（居中）。
   - 分类：画面 / 声音 / 波形 / 场景 / 功能 / 重置；条目：亮度、对比度、音量、显示、高度、渐变、速度、状态栏、字幕、淡入、全部重置；开关值显示“开 / 关”，重置项显示“长按K4”。
3. **中文字模放在块 RAM 里**：面板用到的 61 个字（宋体 16×16，和场景 FONT.BIN 同一字体；数字和 K、X、% 等半角）由 `tools/make_panel_font.py` 生成 `panel_font_rom.v`，综合成 2 块 BRAM9K。字形本身几乎不占 LUT；文字按 8 px 半格排版（半角占一格、汉字占两格），所以“200%”“K1”这类不会被拉开。面板不再使用 5×7 英文字库。改字只要改脚本里的字符串重新生成，不用手写点阵。

预览（真实 RTL 渲染）：[光标态](preview/panel_cursor.png)、[编辑速度](preview/panel_edit.png)、[波形 / 功能 / 重置 / 画面四页](preview/pages.png)。

条目编号变化：速度 6、状态栏 7、字幕 8、淡入 9、全部重置 10，共 11 项循环。

## 本地结果

| 项 | s1-local.2 | 本候选 |
|---|---:|---:|
| LUT | 17464（89.10%） | 17594（89.77%），+130 |
| 寄存器 | 10270 | 10272 |
| BRAM9K | 53 | 55（+2，面板字模） |
| Setup / Hold (ns) | +0.136 / +0.003 | +0.113 / **+0.012**，STNS/HTNS=0 |

面板 LUT 主要花在“这一格显示哪个字”的选择逻辑上（TD 报表里记在 `font` 名下的 325 LUT 就是这部分，ROM 本体是两块 BRAM）。如果以后 LUT 不够，可以把字符串表也搬进 BRAM，预计再省 200 左右。7 个种子里只有 11 时序通过（3/5/47/53 Setup 不过，13/29 Hold 差 0.006～0.008 ns），最差路径仍在 SD 时钟域原有逻辑。

## 上板检查

1. 烧录 [demo.bit](demo.bit)（677348 字节），卡不用换，SW4 先拨下。
2. SW4 拨上：标题“参数调节”居中、没有“SW4”；文字都是中文、清楚不缺笔画；底部提示随光标/编辑切换“编辑 / 返回”。
3. 进场景画面，面板“场景 → 速度”：K2 升到 2X、4X，K1 降回；看场景时间推进确实变快变慢；KEY1+KEY2 回 1X。拨下 SW4 后 KEY1 长按换速，再拨上看面板显示是否跟着变。不在场景画面时显示“--”。
4. 其余同 s1-local.2：OSD/字幕在三种画面的开关、音量到 200%、SW1/SW2 01/10 等于 00、全部重置、滑入滑出。
