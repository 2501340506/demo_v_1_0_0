# v0.27.0 S1 候选 5：宣讲旁白字幕残留修复（Seed 11）

候选 `v0.27.0-s1-local.5`，源码提交 `4a27188`，构建 `adj27f_td_s11`。在 [s1-local.4](../s1-local.4/README.md) 基础上修一个问题。**卡不用换**。

## 问题和原因

用户反馈：宣讲模式第一张图的语音播完后，字幕残留在画面上。

- 旁白字幕每页的滚动速度是按语音长度算好的，让整段文字**恰好在语音结束前**滚出画面；现在卡上的数据只留了 1～7 帧余量（第 1 页 5 帧，约 0.08 s）。
- 原来只有“语音在播 **且** 这一帧字幕正在画”时滚动才前进一步。进入宣讲模式时，第 1 页的语音比画面和字幕数据先开始，开头有几帧字幕还没画上，这几帧就没走。
- 丢的帧超过 5 帧，语音结束时字幕还没滚完；语音一停滚动也停，剩下的字就定在画面上。第 2～4 页是在宣讲模式已经就绪后才开始，基本不丢帧，所以只有第 1 页明显。

## 改了什么（`publicity_subtitle_overlay`）

1. **语音在播的每一帧都前进**，不管这一帧字幕画没画（字幕开关关着、预览中、画面还没提交），保证字幕和语音同步。
2. **语音播完后把剩下的文字继续滚完**：按同样速度滚到整段离开画面为止，不会停在中间。暂停（菜单）时照旧停住不动。
