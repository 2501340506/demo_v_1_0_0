# v0.12.0 S3 local.1：PCM 背景音乐候选

基线 v0.11.0（ff1c138），功能分支 feature/pcm-background-audio。本地仿真及完整 TD 通过，**尚未上板确认**；不是正式版 v0.12.0。

上板使用本目录 [demo.bit](demo.bit)，629,624 字节。构建为 pcm_s3_attempt5，87 个工程输入与当前源码逐字节一致；本目录 bit 与构建输出逐字节一致。

FAT32 根目录的 **BGM.PCM** 自动预填充并循环播放，支持碎片簇链，48kHz、16bit、有符号小端、单声道；左右同样本，固定 128/256 音量。切图、AUTO 和转场不重启音乐。缺少或不可播放的音频回退原琶音；读失败后回退，重扫重试。仅音频卡也可播放。

## 验证

- 生产 HDMI 桥专项：9,279 个样本逐项比较，覆盖重扫、错误回退、短文件、无音频和仅音频新启动。
- 完整系统：582 帧、472,955 个 PCM 样本、5 个播放会话，无欠载或溢出；手动/AUTO、两种转场、四 bank、重扫、图片错误恢复、字幕 UART 及计时通过。
- 42 个 FAT32 图片用例、21 项回归、3 项音频独立专项通过。归档 68 份通过日志；系统保留 18 条既有模型/可选端口警告。
- TD：Setup **+0.100ns**，Hold **+0.004ns**，覆盖率 **99.96%**；13,204 LUT、7,282 寄存器、12 BRAM9K、4 DSP、1 PLL。未放宽约束。保留既有 SDRAM ECO 位置、局部时钟布线及 BRAM 工具提示，详细报告在 reports。

按 [上板步骤](BOARD_VALIDATION.md) 验证播放速度、切图连续性、循环及重扫。确认 S3 后，再复用同一 bit 做 S4 持续播放、Flash 和完全断电冷启动。

## 范围与回退

裸 PCM 不含采样率元数据，请用项目 tools/make_audio_corpus.py 和 FFmpeg 转换；本目录 tools 中也保留入口。3 秒 440Hz 试听样本见 [S2 samples](../s2-modules/samples)。不支持 WAV 头解析、播放列表或播放控制；源文件首尾不连续不做交叉淡化。空文件和奇数字节文件不可播放。重扫会停止并重新预填充；重扫无图保留旧画面是原有行为。

阶段回退：[S1 已验收 bit](../s1-local.1/demo.bit)。总回退：[v0.11.0](../../v0.11.0/demo.bit)。changes 仅备份相对基线实际修改的 10 个生产文件，完整临时输出保留在 diagnostics/output。
