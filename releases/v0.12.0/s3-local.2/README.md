# v0.12.0 S3 local.2

最终构建 `pcm_s3_reset_retry2`：Setup +0.117ns、Hold +0.002ns，覆盖率 99.97%；13,470 LUT、7,300 寄存器、12 BRAM9K、4 DSP、1 PLL。时序审计分类与 local.1 一致，未修改约束；既有工具提示保存在 reports。代码修正提交 `58d749e`，旧 retry1 构建不作为候选。

基线为 `v0.12.0-s3-local.1`。SD 初始化单轮 2000ms 超时后，复位命令与 SPI 模块，保持恢复窗口 1024 个 SD 系统时钟，再以 11 个 FF 字节（88 个 SPI 时钟、CS 高）重新从 CMD0 初始化。最多额外重试三次，耗尽后锁存 ERR:02；正常 ACMD41 轮询不触发整轮恢复。CMD59 的既有终止错误行为保留。

本候选仅修改两个 SD 生产文件，源码差异备份见 changes，输入逐字节核对及文件大小见 SOURCE_MANIFEST.md。5 项 SD 专项、21 项回归、PCM 生产接口测试通过；时序结果见 reports/final_timing.rpt。原系统 582 帧/472,955 个 PCM 样本验证沿用 local.1，未重复执行；该系统模型不能代替真实 SD 初始化测试。

交付文件：`demo.bit`。回退：`../s3-local.1/demo.bit`；总回退：`../../v0.11.0/demo.bit`。

这是初始化超时的受控恢复修复，尚未证明 ERR:02/37FF 的物理根因。无卡超时约 8 秒，不再是原来的 2 秒。local.1 的 20 分钟及 Flash 通过结果不自动适用于本候选；本候选尚待板测，不建立 board.2 或正式版标签。
