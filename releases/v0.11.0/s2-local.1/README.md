# v0.11.0 S2 local.1：AUTO 黑底水平揭示

2026-10-11 本地验证完成，待用户上板。基线为已确认功能正常的 `v0.11.0-s1-board.1`；本候选标签 `v0.11.0-s2-local.1`，不继承 S1 的板级验收结论。

## 使用

烧录本目录固定的 [demo.bit](demo.bit)，按 [上板步骤](BOARD_VALIDATION.md) 验证。手动保持 16 帧淡出、黑场提交、16 帧淡入；AUTO 恢复阶段改为从左到右每帧揭示 40 列，直到 640 列完整显示。右侧为黑底，没有旧图背景混合。首图和重扫首图直接显示，字幕、时间及提示音功能保留，默认字幕仍为“胆子肥嘟嘟的 FPGA ”。

AUTO 来源在请求实际接受时锁存，不随转场中的开关变化；忙时按键和重扫继续排队。像素效果位于全部 OSD 之前，不增加像素延迟或额外 SDRAM 读取。

## 实际验证

- wipe 专项：95,200 次像素检查，含边界 0..640、最后一列、有效区/消隐及 AUTO/手动交替。原 fade 专项 27,648 次 RGB 检查、player 专项 5 次提交通过。
- 21 项回归全部通过，零错误、零警告。
- 完整真实 SDRAM/OSD/UART/音频联合仿真：582 显示帧、2 次 AUTO 揭示、15 次手动淡变、17 个黑场、180,326,400 次转场像素检查；22 次提交与 22 次提示音一致。缓存命中、重扫、失败重试、超时后缓存切图通过。
- OSD/时间：587 帧边界及 246,539,248 次像素/消隐检查，4 组串口命令在帧边界生效。完整仿真零错误，保留 18 条既有模型/可选端口警告；脚本已检查没有其他类型警告。
- TD `transition_s2_attempt1`：Setup **+0.106 ns**、Hold **+0.021 ns**、约束覆盖率 **99.96%**；11,767 LUT、6,667 寄存器、4 BRAM、4 DSP、1 PLL。约束未修改，审计分类与 S1 一致。
- 物理报告仍有 3 条 SDRAM ECO 初始位置调整提示和 1 条 `ext_mem_clk_sft` 到 `U3/u2_ram/SDRAM_CLK` 局部布线提示。原始警告及约束审计保存在 reports；不将正时序裕量写成上板通过。
- 83 个工程/源码输入与 TD 快照逐字节一致；固定 bit 为 629,624 字节，与构建 bit 逐字节一致。仅备份相对 S1 board.1 改动的 5 个生产文件，见 [清单](SOURCE_MANIFEST.md)。实现提交为 `d4d99b0`。
