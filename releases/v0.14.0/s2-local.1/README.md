# v0.14.0 s2-local.1：全屏图片缩放

S2 功能板测通过。基线 v0.13.0；构建 scale_s2_attempt5。开发分支 feature/image-scaling-thumbnails。

[固定 bit](demo.bit) · [四张测试 BMP 和参考图](board_samples.zip) · [板测记录](BOARD_RESULT.md) · [验证记录](VALIDATION.md) · [输入清单](MANIFEST.md)

支持正高度、24 位、非压缩 BMP：宽不超过 1920 且高不超过 1080，或宽不超过 1080 且高不超过 1920。加载时采用最近邻等比缩放、居中黑边，输出保持 640×480；四个全屏 bank 地址及像素格式不变。图片 FAT 链上限 16384 簇，扇区缓存和 ready/valid 控制放大时的背压。读 FIFO 补充优先及整 64 字启动修正保障显示和间歇输入。

S2 仅接入全屏缩放；四宫格及 11 模式交互在 S2 板测通过后的 S3 接入。字幕、圆环、转场和音乐沿用全屏行为。大图首次加载需读取全部源文件，实际板级加载时间待测。

完整 TD Setup +0.107ns、Hold +0.035ns，STA 覆盖率 99.97%；15716 LUT、8260 寄存器、41 BRAM9K、10 DSP、1 PLL，约束未修改。详细功能结果及历史失败见验证记录。

bit 为 661052 字节，归档与构建产物逐字节一致；93 个工程输入与构建快照逐字节一致。仅归档相对基线变化的 14 个生产输入，未改输入通过基线引用。

回退：[v0.13.0/demo.bit](../../v0.13.0/demo.bit)。用户已确认本候选功能通过，记录 v0.14.0-s2-board.1；S3 继续四宫格接入。20 分钟持续播放、Flash 和完全断电冷启动留在最终 S4，不以功能板测替代。
