# S4：Flash、冷启动与持续播放

使用已通过 S3 板测的原文件：[s3-local.1/demo.bit](s3-local.1/demo.bit)。本阶段不改 RTL、不重建 bit；回退为 [v0.7.0/demo.bit](../v0.7.0/demo.bit)。

1. 按既有 TD 下载流程将上述文件写入板载 Flash，记录烧录是否成功。
2. 完全断电后重新上电，确认无需再次下载即可显示首图，后台补齐后手动切图、重扫及数码管状态正常；听取切图提示音。
3. 开启 AUTO 持续播放，建议至少 30 分钟，其间做几次手动切换和重扫，观察是否花屏、停住、编号错误或提示音异常。反馈实际运行时长，不以 UART 文件跨度代替。

请反馈：Flash 烧录结果、断电启动结果和实际次数、持续播放时长及现象、提示音情况；未测项目直接注明未测。

当前结果：均待用户反馈。确认实际结果后才完成 S4 发布归档，并复用本文件对应的原 bit 发布正式版。
