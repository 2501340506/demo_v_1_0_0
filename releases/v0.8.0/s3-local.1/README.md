# v0.8.0 S3 local.1：四 bank 帧缓存上板候选

下载：[demo.bit](demo.bit)，629624 字节，EG4S20BG256。请按 [上板步骤](BOARD_VALIDATION.md) 测试。此候选已通过本地验证及 S3 用户功能板测，见 [board.1 记录](BOARD_RESULT.md)。

## 行为

- 首图完整写入并提交显示后，按目录顺序后台补齐其余图片。
- 已缓存图片在下一次可用帧边界切换，不重新读文件；后台加载不阻塞缓存命中。
- 未命中请求等待当前加载收尾，再优先加载目标；同向合并、下一张优先及 3 秒 AUTO 保留。
- 重扫先完成在途显示交接、取消写入，再重建目录。旧画面保留到新首图提交；空卡、无图或失败也不覆盖旧显示 bank。
- 普通失败重试一次，后台仍失败则跳过；手动可重试，AUTO 自动跳过已知失败图。通信超时停止读卡，成功缓存仍可手动切换。
- 图片编号与提示音只随实际显示提交更新，后台完成不触发提示音。

沿用 100/40/25 MHz 控制/存储/像素域、64 字 burst、刷新保护、RGB 高 24 位、BMP 上下翻转及原视频延迟。不含转场、OSD、亮度或课程双 burst 在飞优化。

## 构建与本地验证

构建：`four_bank_s3_attempt1`，TD 6.2.168116，high/ultra/high 隔离构建；未写入用户 best_result。

| 项目 | 实际结果 |
|---|---|
| 最终路由 Setup / Hold | +0.126 ns / +0.003 ns |
| STA coverage | 99.95%，六个时钟覆盖 |
| LUT / 寄存器 | 9341 / 5882 |
| BRAM / DSP / PLL | 4 / 2 / 1 |
| 真实数据链路 | 57 个显示帧逐像素比对；14 次开始、10 次成功缓存、22 次提交与 22 次提示音 |
| 四图驻留 | 首轮仅 4 次文件加载；之后手动及 AUTO 无新增加载或扇区读取 |
| FAT32 | 42 个用例通过，含碎片、缺图、大地址、EOF 和失败恢复 |
| 相关回归 | 21 项通过，含播放器、按键、面板、SD 协议、HDMI、音频 CDC、启动和复位 |
| 读写端点故障 | 17 帧通过，覆盖短帧、源失败、取消、溢出、停滞、下溢及下一帧恢复 |

完整链路采用真实 FAT32/BMP RTL、厂商异步 FIFO、加密 SDRAM 控制器与 BL4 命令/DQ 模型，按物理数据读回检查四区地址、行边界、颜色和上下方向。仅卡端以扇区服务模型提供数据；SPI 引脚协议另有回归，不能把模型结果当作真实卡或 SDRAM 器件电气签核。

`check_timing` 分类计数与 S1 相同：无时钟 0、无路径约束 0、无输入延时 8、无输出延时 16；原有 PLL 本地反馈约束提示、SPI 输入延时提示及 4 类 dummy node 提示保留，无新增未解释的未约束路径。参见 [路由时序](reports/final_timing.rpt)、[资源](reports/demo_phy.area)、[约束检查](reports/check_timing.txt) 与 [S1 对照](reports/s1_check_timing.txt)。

物理端点仿真保留厂商可选空端口及加密 IP 常量告警（2685/2718/2121）；其余回归均为 0 Error/Warning。首轮系统测试 `system1` 因测试台提前计数而失败，修正测试台后 `system2` 通过，未因该问题修改 RTL。失败日志保留在 diagnostics/output，不作为通过证据。

## 源码与日志

相对开发基线 `1c68673`（生产 RTL 同 v0.7.0）仅归档 8 个新增或修改源码，以及必要工程与报告。68 项工程输入及工程配置已与构建快照逐字节核对；固定 bit 与构建原件逐字节一致，未重新生成。[源码清单](sources.txt) · [源码副本](sources) · [验证证据](evidence)。文本日志仅规范为 UTF-8 和去除行尾空白，原始工具输出保留在诊断目录。
