# v0.8.0 S1 上板测试说明

候选：`v0.8.0-s1-local.1`。下载：[demo.bit](demo.bit)（629624 字节，EG4S20BG256）。回退：[v0.7.0/demo.bit](../../v0.7.0/demo.bit)。

S1 只完成读写分离，仍为双缓冲，切图仍读取 SD 文件。四图驻留、后台预载、缓存命中不读卡属于 S3，不作为本次要求。全部板测结果待用户填写。

## 准备与下载

1. 使用可用 FAT32 TF 卡，根目录放入 PIC1.BMP～PIC4.BMP，均为 640×480、24 位 BMP。建议颜色明显不同，并带上下方向、边框或文字。
2. 接好 TF 卡、HDMI 和下载器，将 SW2 SW1 设为 00（图片模式）。
3. 按平时的 Tang Dynasty 下载流程，选择本目录固定 demo.bit，先下载至 SRAM。不要误选构建目录或 best_result 的其他 bit。
4. 按下表观察实际结果；未做的项目填写“未测”。
