# S8 上板验证：图片与音调联动

状态：待上板；未填入未经用户反馈的实测结论。候选标签 `v0.3.0-r2-s8-local.1`。

## 文件与准备

下载本目录固定[demo.bit](demo.bit)：`D:/My_Program/anlogic_program/demo_v_0_0/releases/v0.3.0-r2-s8-local.1/demo.bit`。使用S7已验证的板卡、HDMI线、可播放音频的显示设备及四张BMP的TF卡。先将接收设备音量调低。SW2 SW1=00，复位默认为MAN。

## 操作与预期

1. 上电/复位：扫描和首图尚未显示时静音。第一张真正出现后，应只有一次约100ms的较高提示音（设计1.5kHz），然后进入图片0旋律；不能漏掉首图提示，也不能持续提示。
2. KEY2逐张向后翻，每张停留至少2秒，观察编号0→1→2→3→0；KEY1反向检查0→3→2→1→0。每次实际换图一次提示，随后播放对应旋律；只按下但画面尚未改变时应保持原旋律。四组分别为C大调上行、A小调、五声音阶、高低交替，每音约250ms，六音循环约1.5秒。图片0和2首音相同，应听完整循环比较。
3. 快速多次按KEY2，再混合KEY1/KEY2，包含加载期间按键：允许按既有规则合并挂起请求；提示次数跟随实际换图次数，不跟随按键次数。加载等待时不抢先变调，不发生声画编号错配。
4. KEY4进入AUTO，观察至少两轮四图轮播；四个拨码模式下AUTO仍工作。再切MAN并做手动翻图，确认图像、数码管和模式操作正常。非图片模式下KEY1/KEY2不应凭空改变声音。
5. 连续运行至少10分钟，期间重复手动/AUTO和复位。确认左右声道都能听到、音量一致，无持续杂音、明显断音、卡住提示音或画面异常。相位连续不代表保证完全无瞬态声；若明显爆音，记录触发动作。
6. 无卡复位检查首图前持续静音，再断电恢复原卡。加载失败保持旧图和旧旋律已由仿真覆盖；若有备用坏图测试卡，可补做板测。不要求修改唯一一份正常图片或热拔卡。

耳听只能近似确认100ms/250ms及提示音高低；精确频率和时长由样本仿真验证。若接收设备只有单声道，请注明，不能据此认定双声道逐项通过。
