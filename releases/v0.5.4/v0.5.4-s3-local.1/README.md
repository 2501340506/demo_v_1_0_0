# v0.5.4-s3-local.1：扫描暂停与续扫接口

**板测失败：首图花屏，回退S2恢复正常。未上传，不可作为通过候选使用。**基线为已验收 `v0.5.4-s2-board.2`。

解析器新增暂停请求、暂停确认、保存的续扫地址和续扫控制。在完整扇区处理完毕后暂停，保留图片计数和下一扫描位置；暂停时可加载图片，加载成功或格式失败后仍可续扫。扫描完成与暂停分开，新扫描及复位清除旧上下文。

生产工程固定暂停/续扫输入为0，本阶段保持完整扫描后才显示首图。首图快速显示、后台续扫调度和按键策略在 S4 实现。UART启动行改为 `BOOT v0.5.4-s3-local.1`，仍为 D12 / 115200 / 8N1；事件含义沿用已验收 S2。

本地验证全部通过：连续扫描与暂停/加载成功或失败/续扫比较读取地址、图片位置及数量；覆盖单拍申请、发现事件申请、坏图快跳、结束边界、长暂停、新扫描和复位。七套BMP、三组像素异步交接、三组真实解析器重扫交接、八项既有回归及UART逐字节接收通过。专项使用4×2真实解码，生产640×480由既有回归覆盖；S4仍需按计划补全尺寸调度端到端验证。

TD完整综合/布局/bitgen：Setup +0.100ns，Hold +0.019ns，覆盖99.92%；5901 LUT / 3747寄存器，4 BRAM / 4 DSP / 1 PLL。没有新增负时序及警告类型。既有PLL/SDRAM告警保留，完整报告在 timing/，仿真日志在 simulation/。

bit 629624字节，逐字节等于隔离构建产物；75个构建源码/约束文件逐字节核对。按用户要求只备份13个新增/修改代码及测试脚本，不复制全部源码；未修改代码、工程和约束从S2基线取得。覆盖 changes/ 到基线工作副本即可还原改动，文件清单见 files.txt。

首次专项测试将“扫描事务暂停”误等同于“任何读取都不能发生”，导致暂停期间正常加载被测试断言拒绝；修正为只检查扫描扇区后通过，并补测真正暂停状态的复位清除。最终RTL未因该测试断言改动。失败日志保留在diagnostics/output/v054_s3_scan_resume，发布包只收录最终通过证据。
