## 行为

D12，115200、8N1、无流控，仅TX。每次复位释放后输出一次：

```text
BOOT v0.5.4-s1-local.1
```

行尾为CR/LF。运行在100MHz控制时钟，868拍/位，实际约115207.37 baud（+0.0064%）。不等待TF初始化，正常运行不重复输出；按钮复位或PLL重新锁定后重新输出。启动行仅表明控制时钟及UART启动，不表示SD/SDRAM初始化成功。

播放逻辑、BMP解析、SDRAM双缓冲、音频及恢复行为均沿用基线。当前阶段不输出翻图/错误事件，也不改变首图等待策略。
