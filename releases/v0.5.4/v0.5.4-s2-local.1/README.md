# v0.5.4-s2-local.1：UART事件日志

2026-10-07。本地候选，等待用户上板；未上传，未建立board标签。S1同一bit已由用户确认通过；本候选加入S2 UART事件日志，尚未实施扫描暂停和快速启动。

UART D12仍为115200、8N1、只发送。复位后输出S2版本行，随后按事件输出ASCII记录，格式为`EVENT T=毫秒 I=图片 S=扇区 E=错误 P=阶段 A=AUTO D=SD调试`，每行明确发送数值0D、0A。事件使用8项快照队列；队列满时保留丢失计数，空闲后输出DROP记录。日志不参与播放器反压，不逐扇区输出。

事件包括初始化、扫描/加载状态、提交、错误、重扫和等待阶段。当前扇区上下文在顶层控制器尚未统一公开时为0；S3/S4会把暂停位置和真实候选扇区接入。S2不改变播放、错误恢复、SDRAM或音频时序。
