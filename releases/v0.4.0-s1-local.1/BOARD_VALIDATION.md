# S1上板验收

状态：**等待用户确认**。固定候选：[demo.bit](demo.bit)，标签v0.4.0-s1-local.1；器件EG4S20BG256、顶层top。

1. 使用此前正常的TF卡与显示/音频设备下载本候选，确认首图正常、方向与颜色正确，出现一次首图提示音，编号正确。
2. MAN下分别按KEY1上一张、KEY2下一张，检查首尾循环；连续快速按键，检查显示不撕裂、编号在实际换图后更新、每次提交仅一次提示。
3. KEY4切AUTO，观察至少两轮图片；再切回MAN确认停止自动切换。切换四个拨码模式，确认预留模式不产生新的手动翻图请求，已有请求能完成。
4. 正常插卡情况下做5轮上电/复位，并运行音视频10分钟。记录是否正常启动、卡住的数码管值和发生时机；既有SD初始化偶发卡0不作为本阶段已修复项目。

S1加载错误采用仿真中“扫描后破坏图头”验证。不要通过拔卡来强行制造E：底层读卡可能卡住且本阶段尚无超时。普通坏图在扫描时就被排除，也不能证明加载恢复路径。
