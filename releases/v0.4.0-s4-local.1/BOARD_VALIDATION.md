# S4上板验收（待用户填写）

候选：本目录[demo.bit](demo.bit)，标签v0.4.0-s4-local.1。请下载固定文件，不使用后续TD输出目录中的bit。

## 操作

1. 直接沿用已验证的S3六图测试卡，无需删图或重新制卡；应仍只显示4张good图，顺序、方向、色彩正确。下载后复位，首图稳定出现后编号更新并提示一次。
2. MAN下分别上一张/下一张，循环一遍4张图；画面完整，编号与实际显示对应，提示音不提前、不重复。
3. 连续多次按下一张，再交替按上一张/下一张，特别在图片加载期间按键。每次按键保持原20ms消抖要求；加载期间同向请求会合并，不要求每次按键都单独翻图。观察无半帧、旧新图拼接、闪错图，停止按键后能稳定显示。
4. KEY4切AUTO，至少观察两轮4张图，再切回MAN翻图；无卡住、缺图、编号或提示音提前变化。

短扇区、迟到写完成和失败重试已由仿真注入验证，本次不需要制作截断文件或拔卡测试。原始扇区读取可能读到删除残留，截断文件并不能可靠制造短扇区。S5才加入等待超时。

## 请反馈

- 正常启动、4张good图完整、方向色彩：
- MAN及连续按键，无半帧/拼接/闪错图：
- AUTO两轮及切回MAN：
- 编号与提示音时机，无提前或重复：
- 其他异常：

当前板级结果：待用户验证。全局已有时序限制见[timing_comparison](timing_comparison.md)。异常可退回[S3固定bit](../v0.4.0-s3-local.1/demo.bit)，保留现有卡内容便于对比。
