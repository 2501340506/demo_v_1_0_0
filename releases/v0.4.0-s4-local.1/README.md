## 修改

只输出预期像素区间，640×480必须恰好输出307200个像素；文件尾附加内容不输出，也不继续读取纯尾数据扇区。每个已结束扇区必须收到512字节，短头/短数据扇区报d，沿用一次重试和有限候选恢复。扫描的短头扇区不登记。

末扇区结束后分拍排空RGB寄存器，再检查实际输出数和字节相位。显示切换需要解析明确成功及本次SDRAM写完成；新写应答前的旧完成事件不记入新任务，失败不改变编号/显示缓冲或触发提交提示音。复用现有新写请求清FIFO，不改内存控制器。

## 验证

ModelSim：全尺寸307200像素独立RGB检查、8像素专项、8恢复专项、22头专项、14扫描专项通过。真实解析器+异步双缓冲3组配置均20次提交、5次预期错误，0显示缓冲写冲突、0混合帧；全部8个既有入口通过。日志在[simulation](simulation)，零错误零警告。最终地址译码修改后复跑恢复、真实异步交接、控制和原缓冲测试。

TD综合/布局布线/bitgen通过，3817 LUT、2861寄存器、4 BRAM、4 DSP、2 PLL。SD域+0.107ns；全局Setup−6.565ns，Hold+0.011ns。仍有64个SDRAM接口和3个未修改内存模块负端点，全局未收敛；详见对比及原始报告。

测试中SD扇区、FIFO及SDRAM数据端口使用行为模型；完整像素不等于文件内容完整性。原始扇区没有文件EOF，截断文件若返回足量旧数据不能识别。S5超时尚未实现，本阶段不要求拔卡恢复。
