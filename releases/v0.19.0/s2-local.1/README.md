# v0.19.0 s2-local.1 灾害选择系统

本地通过、板测待验收。标签 `v0.19.0-s2-local.1`，原目录分支 `feature/mountain-disaster-selector`；基线 `7e3ac02`，S1 输入 `afffa80`。固定 [demo.bit](demo.bit)，679676 字节。

SW3=C6，拨上为 1，KEY3 仍复位。菜单四格为滑坡、泥石流、山洪、地震，各显示 256×192 首图和固定中文名称。KEY1 前一个、KEY2 后一个、KEY4 确认；灰色场景禁止确认。实际 VFAT 中文目录、任意短别名与跨簇扫描支持“情景模式”及“宣讲模式”，完整根目录资源保持优先；明确菜单选择采用对应子目录。

忙中等待安全交接，菜单停音频及自动推进。确认从第一阶段、非预警、AUTO 关闭开始，保留公共参数及速度，暂全屏直至 SW1/SW2 下一次实际拨动。未确认拨回 0 恢复原应用/页/AUTO并重启讲解或推演；保持 SW3=1 不重复打开。交接后释放按键再操作。原全屏/阶段预览缓存独立，旧编码、字幕、音频、参数、预警及数码管保留，UART 日志和在线字幕默认关闭。

完整 TD `disaster_s2_td_attempt35`：17525 LUT、11760 寄存器、57 BRAM9k、2 BRAM32k、14 DSP；Setup +0.047ns / Hold +0.030ns，STNS/HTNS 均 0，无 ERROR、完整 bitgen。120 份选定仿真、86 份编译/模型日志通过。详见 [验证](VALIDATION.md)、[清单](MANIFEST.md) 和 [实际审计](reports/AUDIT_REVIEW.md)。
