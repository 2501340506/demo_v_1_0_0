当前候选：[v0.5.4-s3-local.1](v0.5.4/v0.5.4-s3-local.1/README.md)，本地验证通过，待上板、未上传。S2 local.2已验收上传。

从S3起仅备份相对前阶段已验收基线的新增/修改代码和测试脚本，记录基线及文件清单；bit、报告、验证日志继续保留，不再复制完整源码。已有归档保持原样。

正式版本使用 `releases/vX.Y.Z/`。属于该版本的阶段候选放在正式版本目录内，并保留完整标签名作为子目录名，例如：

```text
releases/
  v0.4.0/
    README.md
    demo.bit
    v0.4.0-s1-local.1/
    v0.4.0-s2-local.1/
    ...
```

`v0.1.3`、`v0.1.4` 等是各自独立的正式版本，不归入其他版本。Git标签名称不受目录调整影响；历史文档和工程快照应引用嵌套后的路径。
