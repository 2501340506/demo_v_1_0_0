# S1 上板确认

候选：`v0.7.0-s1-local.1`，使用本目录 `demo.bit`。

状态：**待用户上板**。当前仅验证新增扇区适配层不破坏已验收播放链路，不验证 FAT32 功能；TF 卡沿用原有可正常播放的素材即可。

1. 下载候选后启动、复位，确认原有图片正常显示，无花屏或混帧，声音与实际切图同步。
2. 按现有操作切换上一张、下一张和 AUTO，确认顺序、轮播周期及模式切换保持正常。
3. 保持一张图显示，拔卡后请求切图，确认进入错误状态且保留当前画面；重新插卡，长按 KEY2 重扫，确认恢复正常图片与声音。
4. 用平时的方式持续轮播一段时间，反馈是否出现卡死、残帧或异常音频；只记录实际观察时长，不预填次数和结论。

反馈请注明候选名称及通过/失败项目；若失败，注明操作顺序和屏幕/数码管现象。串口版本文字尚未改变，不用它区分本候选。
