# v0.7.0-s1-local.1：扇区适配候选

日期：2026-10-08。状态：本地验证通过，等待用户上板；尚未建立 board 标签，尚未推送本任务分支。**这一阶段仍使用原 BMP 扫描方式，尚未接入 FAT32。**

## 使用与回退

下载本目录固定的 [demo.bit](demo.bit)，沿用原来的 TF 卡素材和接线。不要使用 TD 运行目录或 best_result 中可能被覆盖的文件。板测步骤见 [BOARD_VALIDATION.md](BOARD_VALIDATION.md)。

开发基线：`v0.7.0-plan.1`（从 main 建立独立 feature/fat32-filesystem）。硬件回退：`v0.6.0-bmp211-s3-board.1`，固定 bit 为 [BMP 2.11 S3](../../v0.6.0-bmp211/s3-local.1/demo.bit)。

## 改动

- 新增 sd_sector_adapter：请求与 LBA 锁存、字节/索引同步寄存、完成事件、读失败/长度校验和无进展超时。
- sd_card_bmp 将旧 BMP 接口接到适配器；旧请求未撤销前不重复接受，底层失败当拍撤销读请求，防止重复 CMD17。原 BMP 解析、按键、播放、音频提交和 SDRAM 双缓冲流程保持。
- 根据 TD 实际长路径，在 UART 日志中把字段选择与十六进制转换分隔到寄存器两侧；事件包和发送字节保持不变。
- 工程清单补齐已存在的 UART/BMP 解码源及新适配器，相关测试入口补齐依赖。

`sources/` 仅保存本阶段新增/修改的三个 RTL；其他文件引用基线仓库。`project/demo.al` 引用本包这三个源码及同一工作区其他依赖，不能脱离对应仓库独立使用。

## 实际验证

- S0：独立解码器两种尺寸共 32 场景；三组真实 BMP/异步帧读写基线通过。
- S1：扇区契约及实际 SD 驱动测试通过，覆盖失败无 end、CRC 失败、超时、短扇区、连续请求和复位恢复。
- 最终九个验证入口全部通过：扇区专项、真实像素交接、重扫交接、坏图恢复、超时、SD 协议、UART 逐字节接收、八项系统回归、启动就绪。三组像素/重扫测试均无混帧和缓冲碰撞。
- TD 构建 `fat32_s1_attempt6`：完整综合、布局布线和 bitgen 通过；Setup **+0.132 ns**，Hold **+0.035 ns**，STA 覆盖率 **99.93%**；6540 LUT、4216 寄存器、4 BRAM、4 DSP、1 PLL。
- 59 个工程输入文件与构建快照逐字节一致；629624 字节交付 bit 与该构建原 bit 逐字节一致。见 [PACKAGE_CHECK.txt](PACKAGE_CHECK.txt)。

完整必要证据位于 `reports/`、`evidence/`；之前被替代或时序失败的构建只留在本地 diagnostics/output/，不交付。
