# S3 板测（待用户确认）

请使用本目录固定的 demo.bit。无需烧录 diagnostics/output 或 best_result 中的其他产物。UART 启动版本行未改，不能靠旧版本文本判断烧录文件。

1. 使用明确的 FAT32 测试卡，根目录放 PIC1.BMP～PIC4.BMP，采用现有显示尺寸的未压缩 24 位 BMP。确认上电显示、数码管、音频、前后切换及轮播。
2. 仅放 PIC1、PIC3 时确认两项顺序播放；数码管和音频为列表位置 1、2。空目录、错误尺寸/32 位 BMP、明显截断文件不应提交图像。
3. 加载期间长按 KEY2 重扫，检查旧显示保留、重新初始化后恢复首图、无残帧及重复音频。检查读卡失败停机后重扫恢复。
4. 专用素材分别验证跨目录扇区/簇、碎片 BMP 和超过原扫描范围的文件。须保存实际目录项（名称、起始簇、大小）、FAT 链以及由卷布局算出的物理 LBA；大地址目标至少一个数据扇区 LBA > 131071。仅按复制顺序不能证明碎片。
5. 保存串口日志，注明候选路径、卡/素材及实际检查结果。未检查项目直接写“未测”。

不要求格式化现有使用卡。制卡及卡内文件调整由用户在已确认的测试卡上执行；此任务没有自动操作磁盘或卡内文件。

收到本候选的明确板测反馈后更新本记录、建立 board 标签并推送功能分支及本阶段标签；尚未板测前不合并 main 或发布 v0.7.0。
